# R3-C: Lemma I2 for all N

R3-C, 2026-11-24. Notation follows `R2/gglob_i.md`: n = P², P = p_1⋯p_N, s_k = n/p_k, z = Dy. In residue
coordinates, x = r + P·t with r, t ∈ ℤ_P, u_r(t) = z_{r+Pt}, and t is read in CRT coordinates (t_1, …, t_N).
Script: `round2/scripts/r3_i2_construct.py`.

**Verdict.** Lemma I2 holds for every N. Status: **[written proof]**, and the construction is implemented and
checked [computational]. G-glob′ (i) therefore holds unconditionally, with
Pr_𝒟[∀k certified] ≥ (16/729)^N = n^{−o(1)}.

## Statement (as in gglob_i.md)
Let y ∉ ⋃_k V_k. Then there is a set S ⊆ ℤ_n with:
- |S| ≤ 2N;
- no two cyclically consecutive points;
- for every k, points a, b ∈ S with a ≡ b (mod s_k) and z_a ≠ z_b (a "k-witness").

**About z ∈ V_k with y ∉ V_k.** This case cannot happen. gglob_i §0 shows z ∈ V_k ⇔ y ∈ V_k: if Dy is
s-periodic, then y_x − y_{x+s} = c for all x, and summing over an s-class gives p·c = 0.

The proof below uses only "z ∉ V_k for all k". It does not use Σz = 0, that P is a primorial, or that 2 | P.

## Facts
- **F1.** An s_k-class lies inside one residue class R_r. Inside R_r, shifting by s_k is t ↦ t + P/p_k, which
  changes only CRT coordinate k. So a k-witness inside R_r is the same thing as two points t, t′ that differ only in
  coordinate k and have u_r(t) ≠ u_r(t′).
- **F2.** Define K_r = {k : u_r is not invariant under coordinate-k shifts}. Since the shift groups commute, u_r
  is a function of t_{K_r} alone. So the coordinates in F_r := [N] ∖ K_r are free: a k-witness (k ∈ K_r) stays
  a k-witness when its F_r-coordinates are reset to any common value φ.
- **F3.** Primitivity means ⋃_r K_r = [N].
- **F4.** Two points x and x′ are consecutive (x′ = x + 1) only if their residues are consecutive, r′ = r + 1. In
  that case t′ = t + ε·(1, …, 1) in CRT coordinates, where ε = [r = P − 1]. In particular, points in the same
  residue class are never consecutive.

## Proof
Let I ⊆ ℤ_P be a minimum-size set of residues with ⋃_{r∈I} K_r = [N]. Then |I| ≤ N < P for N ≥ 2. (N = 1 is
trivial, since any witness pair works.) Assign each k to some r(k) ∈ I with k ∈ K_{r(k)}. Each k contributes one
witness pair, so |S| ≤ 2N.

**Case A: |I| = 1 (a hub).** There are no conflicts, by F4.

**Case C: every other case except Case B below.** Here either |I| = 2 with non-adjacent residues, or |I| ≥ 3.
- If r and r + 1 are both in I, then K_r ∪ K_{r+1} ≠ [N]. Otherwise {r, r+1} would be a smaller cover.
- So the two residues share a free coordinate m ∈ F_r ∩ F_{r+1}.
- Since I ≠ ℤ_P, the adjacent pairs in I form disjoint **paths** r_0, r_0+1, …, r_0+L in the cycle C_P.
- Walk along each path. For residue r, give every point of R_r a single free-coordinate vector φ_r (allowed by F2).
  At each edge (r, r+1) with shared free coordinate m, set (φ_{r+1})_m := (φ_r)_m + ε + 1 (mod p_m).
- Each variable (r, m) is constrained only by its predecessor on the path, so this is consistent. It works even
  when p_m = 2, because a path is bipartite.
- Then a point of R_r and a point of R_{r+1} differ, after the shift ε, in coordinate m. So by F4 they are never
  consecutive. Non-adjacent residues never conflict. ∎ (C)

This is exactly the "chain of adjacent private residues with p = 2" situation that gglob_i left open. The
translation argument does not need ≥ 3 values. A shared free coordinate on each edge is enough, and minimality of I
supplies one.

**Case B: I = {r, ρ} with ρ = r + 1 and no hub.** Put A = K_r and B = K_ρ. Then A ∪ B = [N], and the sets
A_o := [N] ∖ B and B_o := [N] ∖ A are both non-empty, because there is no hub. They are also disjoint.

*Option 1: r handles all of A, and ρ handles B_o.*
1. First choose ρ's witnesses, one pair per k ∈ B_o, with their free coordinates (A_o) set to 0.
2. Let Π be their projection to the B_o-coordinates. Then |Π| ≤ 2|B_o|.
3. Next choose r's witnesses with free coordinates B_o set to a common φ such that φ + ε ∉ Π. This is possible
   whenever 2|B_o| < ∏_{j∈B_o} p_j.
4. Then no point of R_r is adjacent to a chosen point of R_ρ, by F4.

The inequality 2|B_o| < ∏_{j∈B_o} p_j fails only when B_o = {k₂} with p_{k₂} = 2:
- if |B_o| = 1 and p ≥ 3, then 2 < 3;
- if |B_o| = m ≥ 2, then 2m < 2·3^{m−1} ≤ ∏ p_j.

*Option 2: the mirror image.* ρ handles all of B, and r handles A_o. This needs 2|A_o| < ∏_{A_o} p_j, which
fails only when A_o = {k₂}.

A_o and B_o are disjoint, so they cannot both equal {k₂}. One of the two options therefore works. ∎ (B)

This is the N = 2 translation argument of gglob_i §2(b), made uniform in N. Cases A, B and C cover every
possibility, so **Lemma I2 holds for all N**. ∎

**Remark.** The proof gives slightly more:
- S uses at most N residue classes;
- each k uses exactly one pair;
- S is found in poly(n) time.

## On |S| ≤ 2N versus cN
Thm I1 gives Pr ≥ 3^{−|S|}(2/3)^{|N(S)|} ≥ (4/27)^{|S|}.
- Any |S| ≤ cN still gives n^{−O(c/ln ln n)} = n^{−o(1)}.
- |S| = O(log n) would already give the n^{−O(1)} that G-glob′ (i) asks for.

So the constant 2 is not needed. The bound 2N is what the proof gives (one pair per prime).

## Computation [computational] (`r3_i2_construct.py trials seed p_1 … p_N`)
The script builds S by the proof (Cases A, B and C) and then checks it independently:
- no two consecutive points;
- |S| ≤ 2N;
- a k-witness for every k.

Input families:
- structured cylinder and one-coordinate functions on runs of adjacent residues, including the wrap;
- "private" chains (one prime per adjacent residue, one-coordinate point masses);
- sparse z;
- random sparse binary z.

| prime sets | trials each | non-primitive | result |
|---|---|---|---|
| (2,3), (2,5), (3,2), (3,5) | 2000 | 159–366 | all primitive instances verified |
| (2,3,5), (2,3,7), (2,5,3), (3,5,2), (3,5,7) | 2000 | 198–222 | all primitive instances verified |
| (2,3,5,7), n = 44100 | 400 | 51 | all primitive instances verified |

Cases B and C are both exercised, with 60–500 instances each. At N ≥ 3, every "private" chain lands in Case C.
