# R10-B: rows #a = 2q. Theorem N2 (containment form) and the equality form

Notation as in `r9_pcop.md`. Row N = {w : #a(w) = N}, γ(w) is the cyclic gap sequence, P is the set of primes, and 2P = {2q : q ∈ P}.
Region oo/eo/oe/ee = (#a mod 2, #b mod 2), with o for odd and e for even.
Scripts: `scripts/r10_2q_grammar.py` (output in `r10_2q_grammar_out.txt`) and `scripts/r10_2q_dinv.py` (output in `r10_2q_dinv_out.txt`).

Both readings of the task matter. A P_cop sandwich Cop ⊆ L ⊆ Q only ever supplies **containment** on a row, and containment is now
refuted on rows 2q. **Equality** is what L = Q supplies, so it is the form relevant to ¬P(Q) itself, and that form stays open.

## 1. The grammar G₂ (distance-2 gap witnesses)

L₂ = {#a = 2} ∪ {#a ≥ 4 even, γ not 2-periodic}.

**Lemma 1.** Let N ≥ 4 be even and w = b^s a b^{y_1} a ⋯ a b^{y_{N−1}} a b^t. Then γ(w) is 2-periodic iff
- y_i = y_{i+2} for every 1 ≤ i ≤ N−3, and
- y_{N−2} = s+t.

*Proof.* The internal equalities give y_odd ≡ X and y_even ≡ Y. Since N is even, y_{N−1} = X and y_{N−2} = Y.
So γ = (X, Y, …, Y, X, s+t), and it is cyclically 2-periodic iff s+t = Y. ∎

So only **one** wrap comparison is needed. Write Σ* for ST, b* for BS, and b⁺ for BP.
```
S    → TWOA | W1 | W2            TWOA → BS a BS a BS
W1   → ST a K a ST,  K → K1 | K2,  K1 → b K1 b | BP a BS a,  K2 → b K2 b | a BS a BP   (a b^x a b* a b^y a, x≠y)
Z    → a | a ST a                 (from the first a to the antepenultimate a)
A    → b A b | Z                  C → b C b | BP a BS a      E → b E b | a BS a BP      F → b F b | BP Z
W2   → A C | A E | F a BS a BS    (b^s Z b^x a b* a b^t with x = y_{N−2} ≠ s+t; the cases x>s+t, s≤x<s+t, x<s)
```
- *Language.* Intersected with "#a even", this grammar generates exactly L₂, by Lemma 1. W1 and W2 force ≥ 4 a's, and Z = a only occurs on odd rows.
- *Ambiguity.* W1 parses are in bijection with the internal witnesses i. W2 has at most one parse, because its three cases are disjoint and Z is fixed by the last two a's.
  So amb(w) ≤ N−2.
- [computational: exhaustive for \|w\| ≤ 16 on even rows. The language matches L₂ and amb ≤ max(1, N−2).]

## 2. Theorem N2 (containment form)

Let G_P and L_P be the grammar and language from r9, L_P2 the two-letter version from r9, and sw the letter swap a↔b. Define
```
L** = (oo ∩ L_P2)
    ∪ (eo ∩ ( [contains bb] ∩ L₂  ∪  [no bb] ∩ sw(L_P) ))
    ∪ (oe ∩ sw( same eo piece ))
    (ee: nothing)
```

**Theorem N2.**
- (a) L\*\* is a PCFL with amb(w) ≤ \|w\|.
- (b) Cop ⊆ L\*\*.
- (c) Every w ∈ L\*\* ∖ Q has #a(w), #b(w) ∉ P ∪ 2P ∪ {2^k}.
- (d) L\*\* ∩ row N ∩ {#b odd} = Q ∩ row N ∩ {#b odd} for N ∈ 2P.

*Proof.*

(a) The pieces are separated by regular conditions (parity, bb), so they are disjoint. Each piece is a linear-ambiguity grammar filtered by a DFA, and a Bar-Hillel product with a DFA keeps tree counts.
The bounds are: L_P2 ≤ max(#a, #b) − 1, G₂ ≤ #a − 2, and sw(G_P) ≤ #b − 1.

(b) Let w be coprime. Then w is primitive and not in ee.
- oo: Q ⊆ L_P2.
- eo with bb: #a = 0 would force w = b, which has no bb. So #a ≥ 2, and either #a = 2 or w is primitive and hence γ is not 2-periodic.
- eo without bb: Q ⊆ sw(L_P).
- oe: symmetric to eo.

(c) Let w = v^d ∈ L\*\*, with v primitive and d ≥ 2.
- oo: w ∈ L_P2 ∖ Q. By r9, #a and #b are both odd composite.
- eo: d is odd, since it divides the odd number #b, so d ≥ 3 and d | #a. Go through the possible values of #a and #b:
  - #a = 2^k is impossible, because d is odd and d ≥ 3.
  - #a = 2 is likewise impossible.
  - #a = 2q forces d = q and #a(v) = 2. Then γ is 2-periodic. With bb, L₂ excludes w. Without bb, v = b^x a b^y a with x, y ≤ 1, and #b = q(x+y) is odd. So
    {x, y} = {0, 1}, #b(v) = 1 and w ∈ N_b, which sw(L_P) excludes.
  - #b = p prime forces d = p and #b(v) = 1, so w ∈ N_b. Such words have no bb unless w = b^p, and b^p has #a = 0, which L₂ excludes. So sw(L_P) excludes w.
  - #b ∈ 2P or #b = 2^k is impossible, because #b is odd.
- oe: symmetric to eo.

(d) On eo ∩ row 2q, every primitive word lies in L\*\* by the argument in (b).

All four claims are checked by script. ∎

**Computational check** (`r10_2q_grammar.py 16 20`):
- Exhaustive for \|w\| ≤ 16: the tree-count language equals the definition of L\*\*, Cop ⊆ L\*\*, amb ≤ \|w\|, and no extra word of L\*\* ∖ Q lies on a special row.
- Rows #a ∈ {4, 6, 10, 14}, all words with \|w\| ≤ 20: L\*\* ∩ row ⊆ Q, with equality on #b odd.
- The results are in `r10_2q_grammar_out.txt`.

**Consequence (model-theoretic, as in r9 §3).** No argument whose hypotheses are only
- L is a PCFL,
- Cop ⊆ L, and
- L ∩ X ⊆ Q, where X = {#a or #b ∈ P ∪ 2P ∪ 2^ℕ}

can prove ¬P_cop. So r9's Requirement R sharpens: the deficits that a proof uses must sit on rows **outside P ∪ 2P ∪ 2^ℕ in both letters**.
The first rows still open are of the form 4q, q², pq, … .
Parity is the trick: on eo, any root exponent d is odd, so on row 2q only d = q (#a(root) = 2) survives, and that case has small structure.

## 3. Equality form: reduction and status (OPEN)

**Lemma D.** Let D(w) = #(b's in odd gaps) − #(b's in even gaps), where a b's gap parity is the parity of #a in its prefix. This is a one-counter quantity.
On row 2q with q an odd prime:
- (i) every square has D = 0, because γ_i = γ_{i+q} and i, i+q have opposite parity;
- (ii) w = v^q with #a(v) = 2 has D = ±q(x−y) ≠ 0. When #b is even, x ≡ y (mod 2), so |D| ∈ 2q·ℕ⁺ = #a·ℕ⁺.

Hence the even-#b half of row 2q decomposes as

  Prim ∩ row 2q ∩ {#b even} = {D ∉ #a·ℤ} ⊔ ({D = 0} ∩ NonSq) ⊔ ({D ∈ #a·ℤ∖0} ∩ Not2P).

- The band {#b even, 0 < |D| < #a} is entirely primitive, and it is an (unambiguous) one-counter CFL.
- [computational: `r10_2q_dinv.py 20`, rows 6, 10, 14, all words with \|w\| ≤ 20, 0 failures]

**The residual core.** Equality reduces to two sets: H₀ = {D = 0} ∩ NonSq and H₊ = {|D| ∈ #a·ℕ⁺} ∩ Not2P, both on even #b. Each is a one-counter
condition intersected with a witness language whose witness is an arch:
- NonSq: word-level length arches pre↔mid₁ around c and mid₂↔post around d;
- Not2P: a gap arch b^x…b^y with x ≠ y.

Why the obvious combinations fail [assessment, with exact sub-lemmas]:
1. *A gap arch inside a NonSq length arch* needs a 3-way count. Example: {a^x b^y c^{x+y} : x ≠ y} is not CF (Ogden on the a's, then pump to x = y) [proof].
2. *A gap arch concentric with a NonSq arch* (aligned at the mismatch letter c) is CF and sound, because the mirror stream reads x vs y when the two blocks are
   equidistant from c. It is **incomplete**, though: it requires c to be the midpoint of two a's of opposite index parity, and the Hamming-2 non-squares
   uu′ have only 4 admissible centres.
3. *D = 0 together with NonSq* is two global counters. The sub-slice analogue {u c v : |u| = |v|, #a = #b} is not CF (the a*b*cb*a* slice) [proof].
   Among b-weightings that depend on (#a mod k) of the prefix, or on (#a mod 2, #b mod 2), the only ones that vanish on all squares of all rows 2q are
   multiples of D [sketch: since q mod 2k ranges over all odd residues, the weight c must satisfy c(i+1) = c(i+3) = −c(i)]. So no second counter of this kind can be added.
4. *Fixed q* poses no obstacle in principle: Q ∩ (b*a)^{2q} is a bounded language, and the difficulty is purely the uniformity in q.

Status: **OPEN**. If no equality-L exists, then Q ∉ PCFL. The equality form is therefore a genuine sub-problem of ¬P(Q) and not of ¬P_cop.
For ¬P(Q) the hypothesis L = Q gives equality on every row for free. So, unlike the containment form, a row-2q argument for ¬P(Q) is **not** killed by any known model.

Conjecture (unproved): no PCFL agrees with Q on all rows 2q. Supporting evidence: items 1–3, and the fact that every certificate combination we tried needs either crossing arches or two counters.
