## 0. Where the mass is in M1, and why prefix counting fails
A subcritical T generates exponentially few words by itself: the audit example X → aXaa | bXaa | a has ~2^{n/3} words.
So M1 is never a rotation-dense L on its own. It is a **middle segment** of a tree:
- an outer context above it;
- a run ν₁…ν_r of π_h-nodes in T (with "spanning" meaning span ⊇ [h, n/4]);
- an inner subtree at ν_r, which is the exit material (critical, e.g. Z → aZ | bZ | a). This subtree carries the
  2ⁿ-mass.

The left siblings of ν₁…ν_{r−1} fill [0, h). In the example those are the letters a/b, and they range over all 2^{h−1}
words, so a count of length-h prefixes gains nothing.

The cost is paid elsewhere. Every left letter forces a **right companion** (aa)ⁱ. That companion sits beyond the centre,
where the prefix count does not look, but it is still part of the tree. A tree count sees it:
- the segment weight is 2^{−|left|−|right|} × #segments = 2^a · 2^{−3a} = 4^{−a};
- check (G1) below confirms this exactly.

## 1. Lemma TS (left-tilted segment count) [written proof]
**Setup.** Let T be an SCC. For each T-rule X → αYβ with a marked T-occurrence Y, let:
- B_α(x) = tree GF of the string α, restricted to a family 𝓑 of admissible left trees (here 𝓑 is either all trees or
  the left-bad trees);
- F_β(½) = full tree GF of β at ½.

Define M_θ := (Σ_rules B_α(e^θ/2) · F_β(½))_{X,Y∈T}.

**Hypotheses.**
- (H1) Every B_α is analytic at some x₀ > ½.
- (H2) Every F_β(½) < ∞, and ρ(M₀) < 1.

**Claim.** There are θ > 0 and C such that the following holds. Count the pairs (t, σ) where t is a derivation tree of
length n and σ = ν₁…ν_r is a downward T-path in t whose left-sibling subtrees lie in 𝓑 and have total yield ≥ a. The
number of such pairs is ≤ C·n^{k+3}·2ⁿ·e^{−θa}.

**Proof.**
1. *Cut.* Cut t into three pieces:
   - O = the context from the root to the hole at ν₁ (yield length ℓ_o);
   - Σ = the rule applications at ν₁…ν_{r−1} with their side subtrees, a T-context with a hole at ν_r (left yield a′,
     right yield b);
   - I = the subtree at ν_r (length ℓ_i).

   The map (t, σ) ↦ (O, Σ, I) is injective, and ℓ_o + a′ + b + ℓ_i = n.
2. *Outer and inner pieces.* Fix a filler tree X ⇒* f_X, and a context S ⇒* p_Y Y q_Y.
   - Plug f into O. This gives a tree of a word of length ℓ_o + |f|, plus the hole position. The plug node is the
     unique X-labelled node with that span, because there are no unit cycles.
   - So #O(ℓ_o) ≤ (ℓ_o + 1)(ℓ_o + c)^k 2^{ℓ_o+c}.
   - Likewise #I(ℓ_i) ≤ (ℓ_i + c)^k 2^{ℓ_i+c}.
3. *Segment.* Σ_Σ (e^θ/2)^{a′} 2^{−b} = ((I − M_θ)^{−1})_{XY}.
   - By (H1), M_θ is entrywise finite and continuous in θ on [0, θ₀].
   - ρ(M₀) < 1 by (H2), so ρ(M_θ) < 1 on some [0, θ₁], and the series is ≤ C_θ.
   - Hence #Σ(a′, b) ≤ C_θ·2^{a′+b}·e^{−θa′}.
4. *Sum.* Sum over the ≤ |T|² endpoint pairs, the ≤ n³ length splits, and a′ ≥ a. This gives
   ≤ C n^{k+3} 2ⁿ Σ_{a′≥a} e^{−θa′}. ∎

Only the **left** yield is tilted. That is why TS also covers T whose right material is heavy but finite at ½, such as
a Dyck side branch.

## 2. Lemma D (dichotomy at ½) [written proof]
Assume poly ambiguity. Let T be an SCC with one-step matrix J_T(z): the Jacobian for nonlinear T, and M_T(z) for
linear T.
- (i) J_T(½) is finite and ρ(J_T(½)) ≤ 1.
- (ii) If T is light, then ρ(J_T(½)) < 1.
- (iii) Suppose T is nonlinear and reaches an SCC Y with F_Y(½) = ∞. Then G is exponentially ambiguous. In particular
  this happens when Y is a lowest critical **linear** SCC, i.e. one with light tokens, since such Y has a simple pole
  at ½.

**Proof.**
- (i) If ρ(J_T(z₀)) ≥ 1, or J_T(z₀) = ∞, for some z₀ ≤ ½, then by continuity and monotonicity F_T diverges at some
  z < ½.
  - So the tree count limsup^{1/n} > 2. Words number ≤ 2ⁿ, so some word of each such length has ≥ (1 + ε)ⁿ trees
    (after embedding in a fixed context). This contradicts poly ambiguity.
  - An infinite entry of J_T lies on a cycle of the strongly connected T, so it has the same effect.
- (ii) Differentiate F = Φ(z, F): (I − J)F′ = Φ_z, where Φ_z ≥ 0 and Φ_z ≠ 0 (G is ε-free).
  - Here F′(½) < ∞ because ½ < radius.
  - Pair with the left Perron vector u > 0 of the irreducible J: (1 − ρ)uᵀF′ = uᵀΦ_z > 0. So ρ < 1.
- (iii) Some rule has two T-occurrences, and T is strongly connected. So there is c = 4^{−D} > 0 with F_X ≥ c F_X² on
  z ∈ [¼, min(r_T, ½)).
  - Hence F_X ≤ 1/c there.
  - But F_X ≥ c′ F_Y → ∞ as z ↑ ½. So r_T < ½, and (i) applies. ∎

## 3. Theorem M1 [written proof]
**Statement.** Let L(G) be poly-ambiguous, and let T be a **non-critical linear** SCC, i.e. ρ(M_T(½)) < 1, whose left
material is light or finite. Let Bad_T(n) be the set of words with some derivation whose π_h-run in T has left-sibling
yield ≥ h/c. Then:
- |Rot(Bad_T(n))| ≤ C n^{k+4} 2ⁿ e^{−θh/c} = o(2ⁿ) for h = log⁴n (in fact this is super-polynomially small);
- the mirror statement holds for the right end.

**Proof.**
- TS applies with 𝓑 = all trees.
  - (H1) holds because the left strings are light or finite.
  - (H2) holds by Lemma D(i): F_β(½) < ∞, and ρ < 1 by hypothesis.
- The left siblings of ν₁…ν_{r−1} on π_h lie in [0, h). Their letters are exactly the cycle left parts that M1
  attributes to the segment, so a ≥ h/c.
- Rotation multiplies the count by ≤ n. ∎

**Coverage.**
- This covers M1 as stated: subcritical, light/light, any cycle drifts. D(s) > 0 is irrelevant.
- It also covers every non-critical linear T with light or finite left material, whatever its right material (heavy
  right material is finite at ½ by D(i)).
- The left material of a left-bad T cannot be anything else:
  - heavy left material reaching a critical nonlinear SCC makes T left-good (LG(c));
  - heavy left material whose lowest critical SCC is linear has B_α(½) = ∞, so M_T(½) = ∞, which D(i) excludes.
- So the "non-critical linear" rows of the audit table, including caveat A2, are closed **without** RH or gend2.

## 4. Theorem M1′ [written proof]
Let T be a spanning nonlinear SCC on π_h of a bad-left derivation that is not critical. There are three cases.
- **T reaches a critical nonlinear SCC.** Then every T-node is left-good by LG(c): the left sibling Z₂ of a two-T rule
  derives into it. So T cannot occur in a bad-left word. (This case inherits LG(c)'s caveat A1.)
- **T reaches an SCC with F(½) = ∞.** This is impossible by Lemma D(iii).
- **Otherwise every SCC below T is light, and T is light.** The lowest SCC of radius ½ below T would be either a
  critical nonlinear SCC or a pole, and both are excluded above.
  - TS applies with 𝓑 = all trees. (H1) holds because F_T is analytic past ½, and (H2) holds by Lemma D(ii).
  - So the same bound as in Theorem M1 holds.
  - It is even cruder: the spanning node's subtree has length ≥ n/4 − h and is entirely light, so these trees are
    ≤ poly·2ⁿ·(2r)^{−n/5}.
