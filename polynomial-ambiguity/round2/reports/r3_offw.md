# r3_offw.md — can the off-W part (T1-P1) be realised by ONE grammar? (R3-E)

Scripts: `scripts/r3_offw_fold.py` (grammar G_fold, exact tree counts, exhaustive n ≤ 15 + random n ≤ 60),
`scripts/r3_offw_cover.py` (coverage n ≤ 20 exhaustive, Monte Carlo to n = 400, earlier counterexample
families, min support of W_n^⊥ by MILP).

## Verdict

- **Word-level Off is clean [written proof].** Off := {w : x̂_w(1) ≠ 0}, where x = b-indicator of w,
  n = |w| and x̂(1) = Σ_{w[k]=b} ζ_n^k. Equivalently Φ_n(z) ∤ B_w(z) = Σ_{w[k]=b} z^k, or the Möbius-cube
  transform ∏_{p|n}(1 − T^{n/p})x ≠ 0. Off ⊆ Q, and Off_n = Q_n whenever ω(n) ≤ 1.
- **T1-P1 is per-slice [reading].** It is not one grammar uniform in n.
- **Exposed linear certificates cannot be uniform [written proof].** Theorem X: no CFG that exposes a bounded
  support of a T1-type functional (any y ∈ (V_p+V_q)^⊥ ∖ 0) has an infinite language. Minimal supports have
  size exactly 2^{ω(n)} [written proof, MILP check].
- **A uniform grammar for part of Off exists [written proof + exhaustive check].** The *fold grammar* G_fold is
  one CFG with no counting. It has L(G_fold) ⊆ Off ⊆ Q for all lengths and amb(w) ≤ |w| (observed maximum
  exactly n − 1). It is the first uniform certificate in this campaign that works at lengths with any number of
  primes. It covers the Theorem W words a^{n−2}bb and the L₆ words U_k. It does this by certifying the
  frequency-1 Fourier coefficient directly, never a period chord.
- **G_fold is not the whole off-W part [computational].** It covers 100% of Off for n ≤ 8 and n = 10, and 81.5%
  at n = 20. For uniform random words its coverage vanishes: 1.2% at n = 64 and 0 out of 4000 at n ≥ 128.
- **The exact question stays OPEN.** Is there a poly-ambiguous CFG L with Off ⊆ L ⊆ Q? A negative answer would
  imply that Q has no poly-ambiguous grammar. So the "no uniform grammar" direction is the main problem again,
  as in T1-P2.

## 1. T1-P1, read exactly

**What it certifies.** Fix n and a regular S ⊆ (ab*)^n. Take a basis L_1..L_φ(n) of W_n^⊥. A canonical integer
choice is L_i(x) = [z^i](X(z) mod Φ_n), with X(z) = Σ x_k z^k. Then:
- x ∉ W_n ⇔ some L_i(x) ≠ 0;
- each sign language {±L_i(x) > 0} ∩ S is a DOC language: a one-counter automaton adds the integer weight
  c_{ik} = [z^i](z^k mod Φ_n) for each b in block k;
- a word lies in ≤ φ(n) of the 2φ(n) sign languages, since L_i has one sign. A DFA product keeps tree counts.

**Why it is not uniform.**
- The finite control must know the block index k ≤ n.
- The weights c_{ik} depend on Φ_n.
- The number of components, φ(n), is unbounded.
- So T1-P1 is a per-slice family of grammars, with Θ(n) states and φ(n) start rules.

**What the letter-level analogue needs.** Its natural analogue, "expose the support of one functional
y ∈ W_n^⊥", is killed by Theorem X (§3).

## 2. Word-level Off [written proof]

- **Equivalences.**
  - W_n = Σ_{p|n} V_p consists of exactly the vectors whose DFT vanishes at every j with gcd(j, n) = 1.
  - For integer x, x̂(j) = σ_j(x̂(1)) with σ_j ∈ Gal(ℚ(ζ_n)/ℚ). So x̂(1) = 0 ⇔ x̂(j) = 0 for all coprime j
    ⇔ x ∈ W_n.
  - Hence Off = {x̂(1) ≠ 0} = {Φ_n ∤ B_w}.
  - The ideal (z^n − 1)/Φ_n is generated by ∏_p(1 − z^{n/p}) modulo z^n − 1. So Off = {∏_p(1 − T^{n/p})x ≠ 0}.
    This was checked to agree with the Φ_n test for all words with n ≤ 20.
- **Off ⊆ Q.** If x is d-periodic with d | n and d < n, then x̂(1) = (Σ_{k<d} x_k ζ^k)·Σ_t ζ^{td} = 0.
- **Off_n vs Q_n.**
  - For n = p^a, W_n = V_p, so Off_n = Q_n.
  - For n = p^a q^b, the de Bruijn (1953) theorem applies: every nonnegative vanishing sum of n-th roots is an
    ℕ-sum of rotated p-gons and q-gons [cited, not re-verified]. When n = pq, every p-gon meets every q-gon (CRT).
    So binary x ∈ W_n are unions of polygons of one kind, and Off_n = Q_n.
  - Degenerate case n = 1: the word `a` is primitive but x = 0, so it is not in Off.
  - Exhaustive counts of |Q_n ∖ Off_n| for 2 ≤ n ≤ 20: 24 (n=12), 432 (n=18), 120 (n=20), and 0 for every other
    n ≤ 20, including 6, 10, 14 and 15.
- **Minimal certificates.** Every y ∈ W_n^⊥ ∖ 0 has |supp y| ≥ 2^{ω(n)}, with equality for the Möbius cubes
  {s + Σ_{p∈S} k_p n/p}.
  - *Proof.* By CRT, W_n^⊥ = ⊗_p W_{p^a}^⊥. The minimum weight of each factor is 2 (a chord), and the minimum
    weight of a tensor-product code is the product of the factors' minimum weights.
  - [MILP check] min support is 4 for n = 6, 10, 12, 15, 18 and 8 for n = 30, 42, 60.

## 3. Theorem X — exposed functional certificates are finite [written proof]

**Theorem X.** Let p ≠ q be primes, and let G′ be a CFG over Σ × {0,1}. Suppose every word of L(G′) has length
n ∈ pqℕ and ≤ K marks. Suppose also that its mark set contains distinct a, b, c with b ≡ a (mod n/p) and
c ≡ b (mod n/q). This holds whenever the marks contain supp y for some y ∈ (V_p+V_q)^⊥ ∖ 0, hence for every
y ∈ W_n^⊥ ∖ 0:
- a ∈ supp y has a class-mate b mod n/p;
- b has a class-mate c mod n/q;
- c ≠ a because lcm(n/p, n/q) = n.

Then L(G′) is finite.

*Proof.*
1. Erase letters, keep the marks, and pass to the gap vectors. By Ginsburg–Spanier this gives finitely many
   stratified linear sets. Every period P has support ≤ 2, say {g, h}.
2. Along a ray c₀ + jP, pigeonhole fixes the mark triple and integers κ, λ (0 < |κ| < p, 0 < |λ| < q) such that,
   for infinitely many j:
   - pos_β − pos_α = κ·n/p;
   - pos_γ − pos_β = λ·n/q.
3. Both sides are affine in j. So the P-mass between the marks equals κ|P|/p, and likewise λ|P|/q.
4. With support {g, h}, these masses lie in {0, ±P_g, ±P_h, ±|P|}. So |κ|/p and |λ|/q are each P_g/|P| or
   1 − P_g/|P|.
5. Then |κ|/p = |λ|/q or |κ|/p + |λ|/q = 1. Both force p | κ, which is impossible.
6. So every period is 0, the gap sets are finite, and L(G′) is finite. ∎

**Consequences.**
- No uniform grammar can realise T1-P1 by making its functional's support visible.
- Theorem X contains Theorem W (`uniform.md`) and the rectangle case of Theorem R (`l6.md`) as instances.
  It needs only *one p-step followed by one q-step*.
- It does not touch G_p (one prime) or G_fold (unbounded support, §4).

## 4. The fold grammar G_fold [written proof + exhaustive check]

Let x be the b-indicator, with b = 1 and a = 0. For each reflection R_m: k ↦ m − k of ℤ_n (m = 0..n−1), split
w = u·v with u = w[0..m] and v = w[m+1..n−1]. R_m reverses u and v separately.

**The weight.** Put g_m(k) = sin(2π(k − m/2)/n). Then:
- Σ_k x_k g_m(k) = Im(e^{−iπm/n} x̂(1));
- g_m ∘ R_m = −g_m;
- g_m < 0 on the left half of u and the right half of v, and g_m > 0 on the other halves. It vanishes only at
  the two centres.

So Σ x g_m is a sum over mirror pairs of the form ±|g|·(x_right − x_left) in u and ±|g|·(x_left − x_right)
in v.

**Fold certificate (m, +).**
- Every mirror pair of u is ≠ (a, b) (left, right).
- Every mirror pair of v is ≠ (b, a).
- At least one pair is strict: (b, a) in u or (a, b) in v.

Then Σ x g_m > 0, so x̂(1) ≠ 0 and w ∈ Off. The certificate (m, −) is the mirror image.

**Grammar.**
```
A  → aAa | bAb | bAa | ε | a | b        A1 → aA1a | bA1b | bAa        (u-pairs never (a,b))
B  → aBa | bBb | aBb | ε | a | b        B1 → aB1a | bB1b | aBb        (pairs never (b,a))
A0 → aA0a | bA0b | ε | a | b            A0p → aA0a | bA0b | a | b     (palindromes; B0, B0p are the same)
S  → A1 B | A0p B1 | B1 A | B0p A1
```

**Exact ambiguity.**
- amb(w) = #{(m, ±) : the fold certificate holds}.
- The four start rules are disjoint for each split, the split fixes m, and the sub-grammars are unambiguous
  (the outermost pair decides the rule).
- (m, +) and (m, −) exclude each other, since they force opposite signs of Σ x g_m. So amb(w) ≤ n.
- The maximum observed is exactly n − 1, at b a^{n−1}, for every n ≤ 20.
- **Uniform: yes.** One finite grammar works for all lengths, and it needs no ratio counters. The two centres
  m/2 and (n+m)/2 (a hidden chord of span n/2) come free from the palindromic structure.

**Checks [computational].**
- `r3_offw_fold.py`: the grammar tree count equals the certificate count for every word with n ≤ 15. Every
  derived word is in Off (exact Φ_n test), and Off ⊆ Q.
- 300 random words with n ∈ [15, 60]: 0 disagreements. The largest amb/n seen in this sample was 0.77.

**Coverage.**

| n | 9 | 11 | 12 | 13 | 16 | 18 | 20 | 32 (MC) | 64 (MC) | ≥128 (MC) |
|---|---|---|---|---|---|---|---|---|---|---|
| \|Fold_n\|/\|Off_n\| | .964 | .968 | .970 | .946 | .916 | .873 | .815 | .40 | .012 | 0 |

- n ≤ 8 and n = 10: 1.000.
- MC = fraction of uniform random words.
- Covered families:
  - the Theorem W words a^{n−2}bb have n − 1 certificates for every n;
  - the L₆ "locally 6th-power" words U_k = a⁶(b^k a^k)⁶ (k ≤ 5) have 2–8 certificates.

  These are exactly the families that blocked "one witness per prime" and C_k. So the hard near-periodic words
  are the *easy* case for the fold. Generic words fail it, because ~n/2 mirror pairs must all agree in sign.

## 5. What remains

- **(R1) Completing the off-W part uniformly.** Certify Σ_k x_k g_m(k) ≠ 0 when the folded differences
  z_k = x_k − x_{R_m k} have mixed signs. The pure fold uses equal |g| on mirror pairs only.
  - The natural upgrades need a ballot or Hall condition on the folded pair sequence: match each negative b to a
    positive b farther from the centre. That is a counter running along a nested pair sequence, which is not
    CF in general [assessment].
  - A finer weighting (triangle wave, i.e. moments) gives #ab-subsequences vs #ba-subsequences, which is also
    not CF [assessment].
  - Sign patterns for other coprime frequencies j sit at fixed fractions n/(2j). By Theorem X-type arguments
    these are visible only for one chord.
  - **OPEN:** a poly-ambiguous CFG L with Off ⊆ L ⊆ Q. A natural intermediate target is Fold⁺ = {∃m: the
    fold-weighted sum is certified by a non-crossing transport}.
- **(R2) Status of the sandwich.**
  - (main affirmative) ⇒ (sandwich affirmative).
  - "no sandwich grammar" ⇒ (main negative). So the impossibility direction is not separately provable (cf.
    T1-P2).
  - Off_n = Q_n for prime powers and for n = pq. So any sandwich grammar already handles all primitive words of
    prime-power lengths. That length set is not semilinear, so L must also contain other words.
- **(R3) The W part.** Q ∩ W_n is non-empty iff n has ≥ 2 primes and n ≠ pq (n ≤ 20 data: 12, 18, 20). Under
  de Bruijn, for n = p^a q^b these are the disjoint unions of rotated p-gons and q-gons that do not collapse into
  one period. This is the S_N core of `poly_T1.md` and `prompt.md` §4.4. G_fold contributes nothing there, since
  x̂(1) = 0.
- **Net.** The off-W part is *partially* uniform: one linear-ambiguity grammar, all lengths, all prime
  structures, covering a non-negligible but asymptotically vanishing share. Theorem X shows T1-P1's own
  mechanism cannot be made uniform. Full uniform realisation of Off: OPEN.
