Setting: prompt §4.3–4.4; PA/poly_G3.md §1, §4; PA/poly_LAM.md §2; PA/poly_T2b.md §1; PA/poly_S3H.md; PA/poly_S3F.md;

n = P_N², U = P_N-periodic, E_k = {period P_N p_k, zero fibre sums} (⊆ ∩_{j≠k}V_{p_j}, E_k ∩ V_{p_k} = 0),
work on the sub-slice (ab⁺)^n (a fixed 2-state DFA product, so K stays a grammar constant, recon §2).
**No use is made of d_σ = 0** (per recon §3); pieces keep ‖c_σ‖₁ ≤ nK, d_σ ≤ k.

## 1. Exactness on the S_N lattice (PROVED)
For ω ∈ U, δ = Σ_k δ_k, δ_k ∈ E_k: tω + δ ∈ V_{p_k} ⇔ δ_k = 0 (δ_j ∈ V_{p_k} for j ≠ k, U ⊆ V_{p_k},
E_k ∩ V_{p_k} = 0). And n's prime divisors are exactly p_1..p_N. So **tω+δ is primitive iff every δ_k ≠ 0,
globally**, not only near ω. (So no "near ω" approximation is needed for primitivity.)

## 2. Proposition BC: per-piece reduction of G3** (PROVED; usable only together with a TILE bound)
For a piece σ choose a basis B_σ ⊆ V_σ (full rank n). Put E_σ := exponent of ℤ^n/ℤB_σ and h_σ := max ‖ν‖₁
over the primitive integer facet normals ν of cone B_σ.
*Offset fix (no d=0 needed).* ℤV_σ/ℤB_σ is a finite group of exponent dividing E_σ generated by V_σ∖B_σ, so if
c_σ ∈ ℤV_σ there is r_σ ∈ ℕ(V_σ∖B_σ), ‖r_σ‖₁ ≤ k E_σ K, with c'_σ := c_σ + r_σ ∈ ℤB_σ; and c'_σ + ℕB_σ ⊆ L_σ.
(c_σ ∈ ℤV_σ holds whenever L_σ meets Lℤ^n with Lℤ^n ⊆ ℤV_σ, as in Lemma C.)

**Prop BC.** Let ω ∈ U ∩ ℤ^n_{≥1}, δ ∈ ⊕E_k ∩ ℤ^n with all δ_k ≠ 0, and S a set of pieces with c_σ ∈ ℤV_σ such
that for every facet normal ν of cone B_σ: ν(ω) ≥ 1, or (ν(ω) = 0 and ν(δ) ≥ 1)  [(b): δ lies in the OPEN
tangent cone of c'_σ + cone B_σ along ω; for integral ν, δ this is just ν(δ) > 0]. Let L := lcm_{σ∈S} E_σ,
h := max_S h_σ, C := nK + k·max_S E_σ·K, R := hC, t := h(C + R‖δ‖_∞). Then
  P := L(tω + Rδ) ∈ ∩_{σ∈S} L_σ,   ply(P) ≥ |S|,   ‖P‖₁ ≤ L·(t‖ω‖₁ + R‖δ‖₁).
*Proof.* P ∈ Lℤ^n ⊆ ℤB_σ and c'_σ ∈ ℤB_σ, so P − c'_σ ∈ ℤB_σ. For a facet ν: if ν(ω) ≥ 1,
ν(P − c'_σ) ≥ L(t − hR‖δ‖_∞) − hC ≥ 0; if ν(ω) = 0, ν(P − c'_σ) ≥ LR − hC ≥ 0. So P − c'_σ ∈ ℤB_σ ∩ cone B_σ = ℕB_σ. ∎
P is primitive by §1. **Consequence:** on S_N all three G3** numbers are absorbed: apex → t (poly in h, E, nK),
joint lattice → L, inradius θ_S → "δ is an integer point in the open tangent cones" (integrality of ν, δ
gives margin 1 for free, so no Lemma-H/thin-intersection term remains). What is left is:
 - (E,H) per-piece data: L = lcm(E_σ) and h. If E_σ ≤ E₀ and h_σ ≤ h₀ for σ ∈ S then L ≤ lcm(1..E₀) ≤ 3^{E₀}:
   **polynomial iff E₀ = O(log n)** (h₀ may be poly). Holds e.g. when every support-graph component of B_σ has
   ≤ s blocks with K^s = O(log n) (E_σ ≤ |det| ≤ K^s, h_σ ≤ sK^{s−1}), or for ratio-1 trees (a = b on all edges,
   as in LAM §2 when |μ_k| is constant on its support): E_σ ≤ K, h_σ ≤ n.
 - **TILE^ℤ** (open; integer form of TILE_k): an integer δ ∈ ⊕E_k, ‖δ‖_∞ ≤ n^{o(N)}, lying in the open tangent
   cones along ω of n^{ω(1)} pieces satisfying (E,H). **Conditional theorem:** TILE^ℤ for (E,H)-pieces ⇒ Lemma G*
   witness of length n^{o(N)}·poly(n).

## 3. Can a ply-set avoid exponential chains? — NO in general; but index is not the obstruction (PROVED)
(a) **Exact refinement.** Any piece c + ℕB can be replaced by a disjoint union of finitely many laminar pieces
with entries ≤ 3 whose lattices have index 2^ρ (Stanley decomposition of a triangulation using a chain cone; the
2-dim instance N² = ℕ{e1,e1+2e2} ⊔ ((1,1)+ℕ{e1,e1+2e2}) ⊔ ((0,1)+ℕ{e2,e1+2e2}) is checked in g3_checks.py (B)).
This leaves the ply function f = amb pointwise unchanged, but puts chain pieces (E_σ = h_σ = 2^ρ) into the ply-set
of every point of the refined region. Hence **no statement of the form "some ply-set S has poly per-piece/joint
data" can hold for all valid covers** (abstract-cover level; grammar realisability of the refinement NOT checked —
the offsets stay ≤ ‖c‖ + O(ρ), K ≤ 3). G3** as "bound the three numbers for some S" is therefore not
refinement-invariant; a proof must coarsen (merge pieces sharing a point) or work with f directly.
(b) **Index ≠ length.** Joint lattice of forward and backward chains on ρ+1 coordinates has index 2^{2ρ} but ℓ∞
covering radius 2 for ρ = 3..8 (g3_checks.py (C)); in general μ ≥ det^{1/dim} only, constant here. The genuine
exponential source in the chain examples is the facet height h = 2^ρ (apex/inradius, i.e. thin cone
intersections such as T2b's L₁∩L₂ = ℕ(1,2,…,2^ρ)), not μ(Λ_S). In Prop BC the joint lattice enters only via
L = lcm E_σ, and refinement-type chains are what make L, h large.

## 4. The requested ply-≥3 obstruction cannot exist (PROVED, via R2/recon Cor F′)
**Lemma F_S.** On (ab⁺)^n, n even, I = [1..r], r ≤ n/6, J = I ∪ (I + n/2), coordinates off J fixed to 1:
x is non-primitive ⇔ z|_I = z|_{I+n/2}. (If x is d-periodic with n/d even, it is n/2-periodic. If n/d is odd then
d ≤ n/3 ≤ n/2 − r, so every d-orbit starting in [1..r] (or in I+n/2) has a term in a non-J position, forcing z ≡ 1.)
Checked by brute force for n = 36, r ≤ 3 (g3_checks.py (A)). The induced order is x_1<…<x_r<y_1<…<y_r, so Lemma F
(repaired, offsets ≤ nK) gives a valid NE_r cover and **Cor F′ ⇒ every valid cover of Q∩(ab⁺)^n has ply ≥ p at
norm ≤ n + n·exp(O(p² log pK))**; ply 3 at O(n)·K^{O(1)}. So "every ply-≥3 point has norm 2^{Ω(n)}" is impossible
on the S_N slice; an obstruction can only live at ply ≥ ω(√(log n / log log n)) (Cor F′ is superpolynomial beyond).
