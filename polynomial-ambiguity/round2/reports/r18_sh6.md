# r18_sh6.md — settling candidate SH6 (C_exp? ambiguity degree, E_n[m], G⁻)

SH6: X → ab X ab | bb X a | X ba | a X B | B X bb | a X bb | ab X aa | ab, where B ranges over the prime Dyck
words (a = +1, b = −1). The token masses sum to 1, so SH6 is exactly critical (source: `scripts/r18_am_num.py`).

## Headline
- **(0) There is no general "Wich decision procedure" for C_exp.** The premise of the task is wrong.
  - `poly_WE.md` records Wich DLT'99 **Thm 5.2: C_exp is undecidable**, even for unambiguous-or-exponential grammars.
  - What *is* effective in Wich is the **dichotomy**, not the test: no C_exp ⇒ polynomially ambiguous.
  - For one linear nonterminal X → uᵢXvᵢ | w, C_exp holds iff the pair set {(uᵢ, vᵢᴿ)} is **not a code** in
    Σ*×Σ*. I recall that freeness of finitely generated submonoids of Σ*×Σ* is undecidable in general
    (Klarner–Birget–Satterfield; Cassaigne–Harju–Karhumäki). That citation is **not re-verified here**.
  - So only **instance-specific** methods are possible.
- **(1) C_exp for SH6: NOT decided.** There is an exact certificate up to a much larger depth, but no proof for all
  depths.
  - **Method.** `r18_sh6_dij.py` is an exact Sardinas–Patterson-type procedure on the pair monoid with *lazy* Dyck
    blocks. A pending block is stored only as its current height. Two aligned blocks are resolved jointly. It runs
    Dijkstra on cost |U|+|V|.
  - **What it proves.** It returns the **exact minimal** |U|+|V| of an IF violation. If the frontier passes K, it
    certifies that no violation has |U|+|V| ≤ K.
  - **Validation.** It reproduces the known violations at their exact minimal size:

    | candidate | minimal \|U\|+\|V\| | earlier bounded search (odd K only) |
    |---|---|---|
    | SH1 | 16 | first found at 17 |
    | SH4 | 18 | first found at 19 |
    | SH3 | 20 | first found at 21 |

    The SH1 witness was checked by hand. Take (ε,ba)(bb,a)(ε,bbb)(B=ab,aa)(a,baa) against
    (bb,a)(ab,ab)(a,B=aaabbb)(ε,ba). Both give U = bbaba and V = baaaabbbaba.
  - **SH6 result: no IF violation with |U|+|V| ≤ 30** (exact; 2.7·10⁶ SP states). A K = 34 run (over 4 GB, still running when
    this report was written; the K = 38 run was cancelled) writes to `scripts/r18_sh6_dij_out.txt`. If that file says
    `NONE`, the certificate depth is 34.
  - The reachable SP state space of SH6 is **infinite in practice**: about 2.8× more states per unit of surplus size.
    This is because pending blocks act as wildcards. So plain SP does not terminate, and a finite closure proof is not
    available.
  - **Status: OPEN for SH6, with exact certificate depth 30.** Before this, the certificate went only to 21.
- **(2) Ambiguity degree.**
  - If SH6 has no C_exp, its degree is **exactly 1**.
  - Upper bound: under IF, a tree is fixed by its exit position, so m(M) ≤ |M|.
  - Lower bound: m(bb(ab)^{2j+1}a) = j + 1 for every j. This is checked by exact DP at j = 1, 2, 3, 10, 30, 100,
    giving 2, 3, 4, 11, 31, 101.
  - If SH6 does have C_exp, the degree is 2^{Θ(n)}.
- **(3) E_n[m] grows linearly.** For each sampled word, m is the exact multiplicity (interval DP); the expectation over
  words is a Monte Carlo estimate (R = 1000 samples per n, `r18_sh6_samp_out.txt`):

  | n | E_n[m] | ± | max m | E_n[m] − 1 |
  |---|---|---|---|---|
  | 100 | 1.77 | 0.03 | 6 | 0.77 |
  | 200 | 2.51 | 0.05 | 11 | 1.51 |
  | 400 | 3.97 | 0.10 | 24 | 2.97 |
  | 800 | 7.00 | 0.19 | 48 | 6.00 |
  | 1600 | 12.70 | 0.37 | 80 | 11.70 |
  | 3200 | 24.18 | 0.71 | 123 | 23.18 |

  - E_n[m] − 1 doubles per doubling of n (ratios 1.96–2.02, exponent ≈ 0.99), so **E_n[m] − 1 ≈ 0.0073·n**, up to n = 3200.
  - By Lemma D (u ≍ n^{−1/2}, r ≍ n^{−1/2}), this means D₀(k) stays bounded below by a constant. So S₀(N) ≍ N ≫ R(N) ≍ N^{1/2}.
  - **The growth is pure exit slide, not hidden IF.** `r18_sh6_exitcheck.py` counts trees *per exit position* in every
    sampled word. Every sample at n = 100, 400, 800 and 1600 (300 each; E_n[m] = 1.74 / 3.80 / 6.98 / 12.98, max m up
    to 75) has **at most 1 tree per exit** (`r18_sh6_exitcheck_out.txt`).
  - So the observed multiplicity comes entirely from distinct exit positions, and no IF violation occurs in any
    sampled word.
- **(4) G⁻ inclusion: NO** [written proof].
  - Fix any context (p, q) and m > |p| + |q|. The family contains
    W = p·a^m b^m·a·ab·a^m b^m·bb·q. Its tree is (B = a^m b^m, bb), then (a, B = a^m b^m), then exit ab.
  - Put k = |p| + m ≤ n/2. The prefix of length k has at least m letters a.
  - The suffix of length k lies inside the last |p| + m letters (q, bb, b^m, then at most |p| letters of the second a^m), so it has at most |p| + |q| letters a.
  - Hence d_k(W) ≥ m − |p| − |q| > 0, and W ∉ G⁻.
  - More structurally, both Dyck-block sides push d_k upward: a block prefix on the U side has excess a, and a block
    suffix on the V side has excess b.
  - So SH6 cannot be a pair family inside G⁻. **SH6 is not a counterexample to T8_poly / G-trunk.**

## Implications (labelled)
- **If SH6 is IF-free** (open, certified only to |U|+|V| ≤ 30):
  - it refutes **(AM)**, **AM′-as-a-general-statement** and **Conjecture CR** exactly as CR is stated in r18_am §5
    (critical + IF-free ⇒ D < ∞, with no G⁻ hypothesis);
  - D₀(k) ↛ 0 and S₀ ≍ N.
- **Even if SH6 has a very deep C_exp:**
  - the multiplicities seen at n ≤ 1600 are all slide-type, as the per-exit check shows;
  - so IF-freeness to any modest depth does **not** control D₀;
  - the heuristic "surviving desync ⇒ IF violation" (CR heuristic) is not supported at the scales tested.
- **What is NOT implied.**
  - Nothing against T8_poly: SH6's family leaves G⁻ (point 4).
  - The two-sided-level case of G-trunk must therefore use the **G⁻ geometry**: the chord constraint d_k < 0 on the
    pair family, which forbids the block-driven drift. Criticality plus IF alone cannot settle it.
  - Recommended reformulation: **CR⁻** = CR restricted to pair families inside G⁻ with fixed context.
- **(5) Why bounded search could not settle SH6.**
  - SH6's SP surplus stays unbounded: pending blocks are wildcards.
  - By contrast, SH1, SH3 and SH4 have witnesses whose SP surplus is at most 4.

## Files
- `scripts/r18_sh6_sp.py`: lazy-block SP engine (BFS; `CODE` verdict only if the state space closes, which it does not
  for SH6). SH4 witness: (a,B)(B,aa) vs (a,bbb)(a,B)(a,B)(B,aa)(B,aa)(bb,a).
- `scripts/r18_sh6_dij.py`: exact minimal-IF-witness Dijkstra; output in `r18_sh6_dij_out.txt`.
- `scripts/r18_sh6_samp.py`: sampling plus exact m; output in `r18_sh6_samp_out.txt`.
- `scripts/r18_sh6_exitcheck.py`: per-exit tree counts; output in `r18_sh6_exitcheck_out.txt`.
