## 0. Statement, status, scope

**Notation.** Σ = {a, b}. For w ∈ Σⁿ and 1 ≤ k ≤ n let pre_k(w), suf_k(w) be the prefix and the suffix of length k, and
d_k(w) := #a(pre_k(w)) − #a(suf_k(w)). Put

  G⁻ := { w ∈ Σ⁺ : d_k(w) < 0 for every 1 ≤ k ≤ |w|/2 }.

For L ⊆ Σ*, let Rot(L)_n := { w ∈ Σⁿ : some rotation of w lies in L }. L is **rotation-dense** if there are δ > 0 and
n₀ with |Rot(L)_n| ≥ δ·2ⁿ for **all** n ≥ n₀.

> **Theorem T8_unamb.** No unambiguous context-free language L ⊆ G⁻ is rotation-dense.
> That is, no such L contains a rotation of a positive fraction of all words of length n for all large n.

The same holds if "for all n ≥ n₀" is weakened to "for infinitely many n" (Remark 3.2).

**Status.** [written proof; every link has passed a gated audit; modulo the cited theorems of §2]. Links and audits:
Thm M, Lemma F, Lemma Rn and the pair model (`audit_foundations_r9r10`); Lemma R (`audit_r14`); Lemma Bot, Lemma PC,
Prop HL and the citations (`audit_foundations_bot_cites`); Theorem SM (`audit_r16`); MS⁺, the quadrant bound and PR2⁺
(`audit_r17`); Lemma L, MS^in, Lemma D, Thm OH and the assembly (`audit_t8`). This consolidated text has **not** been
audited as a whole. Its new details (§1.4 F_XX = 1, Lemma 3.4, Lemma 2.1) are elementary.

No Denisov–Wachtel cone bound and no Drmota–Lalley–Woods theorem is used anywhere in the final chain.

**What it implies.**
- Context. G⁻ ⊆ Q (the primitive words; `r6_miss.md` Lemma M/A). Rot(G⁻) covers a 1 − O(n^{−1/2}) fraction of words
  (r6 Lemma A plus Monte Carlo; this part is not proved). So G⁻ is a natural fold-type candidate for a large part of Q.
- T8_unamb shows that **an unambiguous grammar cannot implement this fold**, even for a positive fraction of the words.
- The proof is **not** count-only. It uses the fold geometry of G⁻ (the chord form, §1.1) and not merely
  |G⁻_n| = o(2ⁿ) (F1 check, r9 §5 and r10 §5). Nothing here says anything about Q being non-context-free.

**What it does not imply.**
- It does **not** resolve the main problem (no polynomially ambiguous grammar for Q).
- The polynomially ambiguous version T8_poly is **open**. See `r17_lift.md` (squeeze ceiling), `r17_gstruct.md`,
  `r17_gword.md`, `r17_gwordp.md`, `r17_gtrunk.md` and Round 18 (`r18_*.md`).
- Even T8_poly would not settle the problem by itself. The planned "bridge" (step 5b: every grammar for Q contains a dense
  fold-type part inside G⁻) is **equivalent to the whole problem modulo T8_μ** (`r17_bridge.md`, Prop NR and Lemma
  Core). The bridge is not an easier sub-lemma.

## 1. Definitions and the pair model

### 1.1 Walks and the chord form
- Drift: D(a) = +½, D(b) = −½, extended additively to words.
- P_w(j) := D(pre_j(w)) is the centred prefix walk, with P(0) = 0.
- For w of length n: A(k) := P(k) and B(k) := P(n) − P(n−k) = D(suf_k(w)).
- Since #a(x) = |x|/2 + D(x), we get d_k = A(k) − B(k). Hence

  **w ∈ G⁻ ⟺ A(k) < B(k) for all 1 ≤ k ≤ n/2** (chord form, r10 §1).

- For a word x: depth(x) := max_{0≤j≤|x|}(−P_x(j)) ≥ 0, and the suffix excess sx(x) := max_{0≤j≤|x|} D(suf_j(x)) ≥ 0.
- **Symmetry.** Let φ swap a ↔ b and let R be reversal. Then d_k(φ(w^R)) = d_k(w), so φ∘R maps G⁻ onto G⁻. It swaps
  A ↔ −B and depth ↔ sx, and it maps unambiguous grammars to unambiguous grammars. Every "mirror" below is this map.

**Lemma 1.1 (G⁻ is thin).** 2^{−n}|G⁻_n| ≤ c·n^{−1/2}.
*Proof.* For k ≤ m := ⌊n/2⌋, A reads letters 1..m and B reads letters n−m+1..n. These sets are disjoint, so under the
uniform measure A − B is a lazy simple walk (steps ±1 w.p. ¼ each, 0 w.p. ½). Staying < 0 for m steps has probability
O(m^{−1/2}) (ballot). Numerically, 2^{−n}|G⁻_n|·√n → (2π)^{−1/2} (script `audit_found_r9_checks.py`). ∎

### 1.2 Grammars and measures
- L = L(G) with G a context-free grammar that is **unambiguous**, **reduced** (every nonterminal reachable and
  productive), and in standard form without ε-rules or unit rules. ε- and unit-rule elimination preserves unambiguity,
  and a unit cycle would itself be ambiguous (`audit_foundations_bot_cites` BD2).
- Since G is reduced, each nonterminal X sits in a terminal context S ⇒* sXt. So distinct derivation trees from X have
  distinct yields: **L(X) is unambiguously generated by X**, and the tree GF equals the word GF y_X(z) = Σ_{x∈L(X)} z^{|x|}.
- Since |L(X)_ℓ| ≤ 2^ℓ, every y_X has radius ≥ ½.
- Measure: μ(X) := y_X(½) ∈ (0, ∞]. Mean: mean(X) := Σ_{x∈L(X)} |x|2^{−|x|}. μ(L) := Σ_n |L_n|2^{−n}.
- **Heavy**: μ(X) < ∞ and mean(X) = ∞. **Light**: μ(X) < ∞ and mean(X) < ∞.
- Strongly connected components (SCCs) are taken in the dependency graph of G. An SCC is **linear** if every rule
  whose left-hand side lies in it has at most one right-hand occurrence of it. **Trivial** means a single nonterminal
  that does not reach itself.

### 1.3 Level families
Let H be a nonterminal.
- H is **U-(log-)level** if there are c₀ and words x₁, x₂, … ∈ L(H) with 1 ≤ |x_i| < |x_{i+1}| ≤ 2|x_i| + c₀ and
  depth(x_i) ≤ c₀(1 + log|x_i|).
- H is **V-(log-)level** if the same holds with sx in place of depth.
- **Level** (r13 §0) is the special case of a constant bound. Log-level is r14 §3. Working throughout with the log form
  is the fix of `audit_r17` C2.
- *Window property.* If H is U-(log-)level, then for every n ≥ |x₁| some x_i has n ≤ |x_i| ≤ 2n + c₀. (Take the least
  i with |x_i| ≥ n.) The same holds for V.

### 1.4 The pair model (r10 §2, r13 §0)
Let C be a linear SCC.
- **Context matrix.** M_{XY}(z) := Σ over loop rules X → αYβ (X, Y ∈ C) of z^{#terminals in αβ}·Π y_B(z), the
  product over the lower nonterminals B occurring in αβ.
- **Exit vector.** b_X(z) := the same sum over rules of X with no C-occurrence.
- Assume μ(B) < ∞ for every nonterminal B below C, and ρ(M(½)) = 1. (Lemma F supplies such a C.)

Fix X ∈ C, a terminal context S ⇒* pXq and an exit word w ∈ L(X).
- A **first-return loop** is a path X → Y₁ → ⋯ → Y_{s−1} → X in C, with Y_i ≠ X, together with a choice of a word for
  every lower nonterminal on it.
- It yields a **token** (u, v) of terminal words: u collects the left parts and v the right parts, outer to inner.
- Its weight is π := 2^{−|u|−|v|}, which is the product of the path weight (entries of M(½)) and the normalised block
  laws 2^{−|x|}/μ(B).
- A sequence of r tokens gives the **pair-model word** W = p u₁⋯u_r w v_r⋯v₁ q. Write U = u₁⋯u_r, V = v_r⋯v₁,
  n = |W| and m(W) := |Vq|.

**Facts.**
1. **Σπ = F_XX(½) = 1.** [added in write-up] Let M̃ be M(½) with row and column X deleted. M(½) is irreducible with
   ρ = 1, so strict Perron–Frobenius monotonicity gives ρ(M̃) < 1. By the Schur complement,
   det(I − M(½)) = det(I − M̃)·(1 − F_XX), where F_XX = M_XX + M_{X,·}(I − M̃)^{−1}M_{·,X} is the first-return weight.
   The left side is 0 and det(I − M̃) ≠ 0, so F_XX = 1.
2. **Geometric step count.** The number s of steps of a first-return loop satisfies P(s > t) ≤ cθ^t with θ < 1,
   since the loop stays in C∖{X} and ρ(M̃) < 1 (`audit_r14` C4: evaluated at weight ½ per letter, lower blocks at
   their finite μ). Given the path, the block words are independent with laws 2^{−|x|}/μ(B).
3. **No empty token.** |u| + |v| ≥ 1, since an empty loop would make G infinitely ambiguous.
4. **Injectivity.** By unambiguity, distinct token sequences (over all r jointly) give distinct derivation trees and
   hence distinct words. Two tokens with the same (u, v) cannot occur, because that word would have two trees.
   So π is a probability on string pairs, tokens are i.i.d. with law π, and (token sequence) ↦ W is injective.
5. **Mass identity.** Let X_i := |u_i| + |v_i|, S_r := X₁ + ⋯ + X_r, and let U(x) := Σ_{r≥0} P(S_r ≤ x) be the
   renewal mass. By 4,
   Σ_{n≤N} 2^{−n}·#{pair-model words of length n} = 2^{−|pwq|}·U(N − |pwq|).
6. **Every loop rule is used.** Every loop rule of C lies on some first-return loop at X (take shortest paths through
   C), so it carries positive π-probability.
7. **Outer walk.** For k ≤ min(|pU|, |Vq|), d_k depends only on pU and Vq (r10 §2).

**Sides.** A lower nonterminal occurring in α (resp. β) of a loop rule X → αYβ is on the **U side** (resp.
**V side**). Exit rules and the context do not contribute to tokens.

## 2. Cited results (exact references and hypotheses)

1. **Chomsky–Schützenberger.** The generating function of an unambiguous context-free language is algebraic over ℚ(z).
2. **Newton–Puiseux and transfer** (Flajolet–Sedgewick, *Analytic Combinatorics*, CUP 2009: §VII.7, Newton–Puiseux
   expansions of algebraic functions; §VI.5, transfer with finitely many dominant singularities).
   - An algebraic f has finitely many singularities.
   - At each one, f has a convergent expansion in powers (1 − z/ζ)^{j/m} with **no logarithmic terms**.
   - f continues analytically to a Δ-domain at each dominant singularity, so transfer applies.
   - Used only in Thm M(ii) (Remark 3.2). This replaces r9's paraphrased exponent list (`audit_foundations_r9r10` C1).
3. **Banderier–Drmota**, "Formulae and asymptotics for coefficients of algebraic functions", DMTCS proc. AS (FPSAC
   2013), 1065–1076, **Theorem 4**.
   - *Hypotheses.* f₁ is the first component of a well-defined N-algebraic (or R₊-algebraic) positive polynomial system
     y = P(z, y): non-negative coefficients, P(0, 0) = 0, ρ(P_y(0, 0)) < 1, and no polynomial components (finite
     blocks removed). The system need **not** be strongly connected.
   - *Conclusion.* There is M ≥ 1 such that, for each residue class j mod M, either f_n = 0 eventually, or
     f_n ∼ A_j ρ_j^{−n} n^{β_j} with β_j ∈ {−1 − 2^{−k} : k ≥ 1} ∪ {−1 + m2^{−k} : m ≥ 1, k ≥ 0}.
   - *Fit.* The GF of a nonterminal of a normalised unambiguous grammar is such a component, after reordering
     (`audit_foundations_bot_cites` §4(b), BD1–BD3).
   - Earlier reports cite "Thm 3" or "CPC 2015 Thm 3". The per-class statement is Thm 4 of the DMTCS version. The
     journal numbering was not checked. Used as a black box (BD3).
4. **Perron–Frobenius** for irreducible non-negative matrices, including strict monotonicity of ρ under a non-zero
   entrywise decrease (Seneta, *Non-negative Matrices and Markov Chains*, 2nd ed., Springer 1981, Ch. 1).
5. **Implicit function theorem** and **Pringsheim's theorem**: a series with non-negative coefficients is singular at
   its radius of convergence.
6. **Discrete renewal theorem** (Erdős–Feller–Pollard 1949; Feller, *An Introduction to Probability Theory and its
   Applications*, Vol. I, 3rd ed., Ch. XIII).
   - *Hypotheses.* i.i.d. X_i ∈ {1, 2, …} with span d and finite mean m.
   - *Conclusion.* u(ℓ) := P(∃r : S_r = ℓ) → d/m along ℓ ∈ dℤ.
   - Used only in Lemma Rn. This citation was not re-checked by an audit, but it is textbook.
7. **Elementary probability.**
   - Hoeffding's inequality.
   - Wald's identity.
   - Doob's L⁴ maximal inequality.
   - The ballot/reflection bound: for a simple walk S with i.i.d. ±½ steps, P(max_{k≤m} S_k ≤ g) ≤ c(g+1)m^{−1/2}
     for g ≥ 0. The same holds for the minimum by symmetry, and for the lazy walk of Lemma 1.1.

**Not used:**
- **Drmota–Lalley–Woods.** r9 Lemma F(a) cited it with hypotheses not met. It is replaced by the elementary bound
  (Lemma F), `audit_foundations_bot_cites` D1.
- **Denisov–Wachtel**, "Random walks in cones", Ann. Probab. 43 (2015). Its "uniform in the start point" bound used by
  PR2, PR2ˡᵒᵍ, PR1s, PR2^β and Lemma QW is **not in that paper** (only pointwise Thm 1, and (39) on K_{n,ε};
  `audit_foundations_bot_cites` W1). None of those results is used here.

**Lemma 2.1 (block dichotomy, from item 3)** [added in write-up; content = `audit_foundations_bot_cites` table (C4a–c)].
Let B be a nonterminal with μ(B) < ∞.
- (a) If B is light, then y_B has radius > ½. So |L(B)_ℓ|2^{−ℓ} ≤ cθ^ℓ with θ < 1, and the block length has an
  exponential moment.
- (b) If B is heavy, there is k ≥ 1 with c y^{−2^{−k}} ≤ Σ_{ℓ>y}|L(B)_ℓ|2^{−ℓ} ≤ c′y^{−2^{−k}}.

*Proof.*
- By Thm 4, each residue class either vanishes or has |L(B)_ℓ| ∼ A_j ρ_j^{−ℓ}ℓ^{β_j} with ρ_j ≥ ½.
- Classes with ρ_j > ½ are exponentially small against 2^ℓ.
- A class with ρ_j = ½ has β_j < −1, because μ < ∞. So β_j = −1 − 2^{−k_j} ≥ −3/2 > −2, and its mean diverges.
- Hence light means no class has ρ_j = ½, which is (a).
- Heavy means at least one class has ρ_j = ½. Summing the tails of those classes, the smallest 2^{−k_j} dominates,
  which is (b). ∎

## 3. Reduction: from rotation density to a critical pair model

**Theorem M(i)** (r9 §1). If L is rotation-dense, then μ(L) = ∞.
*Proof.* Each v ∈ L_n has at most n rotations, so |L_n| ≥ |Rot(L)_n|/n ≥ δ2ⁿ/n for n ≥ n₀. Hence
μ(L) ≥ Σ_{n≥n₀} δ/n = ∞. ∎

**Theorem M(ii)** (r9 §1, proof as repaired in `audit_foundations_r9r10` (b)). If f(z) = Σ f_n zⁿ is algebraic with
f_n ≥ 0 and f(½) < ∞, then f_n = O(2ⁿ n^{−1−β}) for some rational β > 0. In particular f_n = o(2ⁿ/n) along all n.
*Proof.*
- |f(z)| ≤ f(½) on |z| ≤ ½. So f is bounded and continuous on the closed disc, and its radius is ≥ ½.
- If the radius is > ½, the coefficients decay exponentially against 2ⁿ.
- Otherwise f has finitely many singularities ζ on |z| = ½. At each, its Puiseux expansion is analytic +
  Σ c(1 − z/ζ)^{β}, with β ∈ ℚ_{>0}∖ℤ. Negative exponents are excluded by boundedness, and there are no logarithms.
- Transfer at the finitely many ζ gives f_n = O(2ⁿ n^{−1−β_min}). ∎

**Remark 3.2 (i.o. form).** If |Rot(L)_n| ≥ δ2ⁿ only for infinitely many n, then |L_n| ≥ δ2ⁿ/n infinitely often.
By Chomsky–Schützenberger and M(ii) this gives μ(L) = ∞. The rest of the proof uses only μ(L) = ∞.

**Lemma F** (r9 §2; part (a) by the elementary bound of `audit_foundations_r9r10` C3 and `audit_foundations_bot_cites`
D1). Let L = L(G) with μ(L) = ∞. There is an SCC C such that μ = ∞ on C and μ < ∞ on every nonterminal strictly below
C. (Take a minimal one in the finite DAG of SCCs among those with μ = ∞. μ is constant-infinite on an SCC by mutual
reachability.) Then:
- (a) **C is linear.**
- (b) **ρ(M(½)) = 1**, and C is non-trivial.

*Proof of (a).*
- Suppose a rule X₀ → ⋯Y⋯Z⋯ has Y, Z ∈ C. Expand all other nonterminals to fixed words and use the paths of C. This
  gives a derivation X ⇒⁺ αXβXγ with α, β, γ terminal.
- Grafting is injective on trees, and trees are words by unambiguity. So y_X(z) ≥ z^{|αβγ|}y_X(z)² coefficientwise.
- For 0 < z < ½, y_X(z) is finite and positive (radius ≥ ½). So y_X(z) ≤ z^{−|αβγ|}.
- Monotone convergence as z ↑ ½ gives μ(X) ≤ 2^{|αβγ|} < ∞, a contradiction.
- No analyticity of the lower inputs is needed. DLW is not used.

*Proof of (b).*
- A trivial SCC has a GF that is a polynomial in z and lower GFs, so finite μ. Hence C is non-trivial and M is
  irreducible.
- The entries of M(z) are finite and left-continuous on [0, ½], by monotone convergence.
- For z < ½: y = M(z)y + b(z) with y finite, b ≥ 0, b ≠ 0 (C is productive). If ρ(M(z)) ≥ 1, the left Perron vector
  w > 0 would give wy ≥ wy + wb > wy. So ρ(M(z)) < 1, and by continuity ρ(M(½)) ≤ 1.
- If ρ(M(½)) < 1, then y(½) ≤ Σ_k M(½)^k b(½) < ∞, a contradiction. ∎

**Lemma R** (r13 §3; audited in `audit_r14`). For i.i.d. X_i ≥ 1, U(x) ≥ x/m(x), where m(x) := E[X ∧ x].
*Proof.*
- Let τ := min{r : S_r > x}. Since X_i ≥ 1, τ ≤ x + 1, and Eτ = Σ_{r≥0}P(S_r ≤ x) = U(x).
- Σ_{i≤τ}(X_i ∧ x) ≥ x: either X_τ > x, or every term is untruncated and the sum is S_τ > x.
- Wald's identity gives Eτ·m(x) ≥ x. ∎

**Lemma 3.4 (token tails)** [r13 §3, r16 PR2⁺ step 1, r17_oh_level step 4; assembled in write-up]. Consider the pair
model of §1.4.
- (a) If every lower nonterminal on loop rules is light, then E[X₁] < ∞.
- (b) If some are heavy, let β₀ := min 2^{−k} over the heavy ones (Lemma 2.1(b)). Then F̄(y) := P(X₁ > y) = O(y^{−β₀}).
  Hence m(x) = Σ_{y<x}F̄(y) = O(x^{1−β₀}) (β₀ ≤ ½ < 1), and U(x) ≥ c x^{β₀}.
- (c) If every lower nonterminal on the V side is light, then E e^{λ|v₁|} < ∞ for some λ > 0.
- (d) If a heavy H with exponent β₀ lies on the U side, then P(|u₁| > y) ≥ c_u y^{−β₀}.

*Proof.*
- Given the path, X₁ is at most K·s fixed letters plus at most K·s independent block lengths, where K is the maximal
  rule length. s has geometric tails (Fact 2).
- (a): E X₁ ≤ E[s]·K·(1 + max mean(B)/μ(B)) < ∞.
- (b): union bound, F̄(y) ≤ Σ_t P(s = t)·Kt·c(y/(Kt))^{−β₀} = O(y^{−β₀}). Only an upper bound is needed.
- (c): use the exponential moments of Lemma 2.1(a) and choose λ small enough that (E e^{λ·(block)})^{K}·θ < 1.
- (d): the loop through H's rule (Fact 6) has positive probability, and given it, |u₁| ≥ |x_H|. Then apply the
  lower bound of Lemma 2.1(b). ∎

**Lemma Rn** (r9 §3; `audit_foundations_r9r10` (d)). In the pair model, suppose every lower nonterminal on loop rules
of C is light. Then the pair-model words are not all in G⁻.
*Proof.*
- By Lemma 3.4(a) and Fact 3, the X_i are i.i.d. ≥ 1 with finite mean m and span d.
- The renewal theorem gives u(ℓ) → d/m on ℓ ∈ dℤ.
- By injectivity, |L_n|2^{−n} ≥ 2^{−|pwq|}u(n − |pwq|) ≥ c > 0 for infinitely many n.
- This contradicts Lemma 1.1. ∎

**Lemma Bot** (r14 §2, with the missing line B1 from `audit_foundations_bot_cites` §1). Let H be heavy. Then there are
a **non-trivial nonlinear** SCC C\* with Y ∈ C\*, a terminal context H ⇒* sYt, and a terminal binary form
Y ⇒⁺ αYβYγ. Moreover:
- y_Y has radius ½;
- every SCC strictly below C\* has radius > ½;
- μ(Y) ≤ 2^{|αβγ|} < ∞ (B2).

*Proof.*
1. **Radius ½.** μ(H) < ∞ and radius > ½ would give a finite mean. So y_H has radius exactly ½.
2. **C\* exists.** Among the SCCs reachable from H with radius exactly ½ (non-empty: H's own SCC), take a minimal C\*.
   SCCs strictly below it have radius ≥ ½ and ≠ ½, so > ½.
3. **(B1, the missing line.)** C\* is non-trivial. A trivial SCC has a GF that is a polynomial in z and lower GFs that
   are analytic past ½, so its radius would be > ½.
4. **C\* is not linear.** Suppose it were. Then M(z) and A(z) are analytic near ½ and Y = A + MY.
   - If ρ(M(½)) < 1, then Y = (I − M)^{−1}A is analytic at ½. This contradicts Pringsheim.
   - So ρ := ρ(M(½)) ≥ 1. If Y(½) were finite, then with the left Perron vector w > 0 we would get
     wY = wA + ρwY ≥ wA + wY, so 0 ≥ wA > 0. (A ≠ 0: a productive SCC has an exit rule.)
   - So μ(Y) = ∞, and μ(H) ≥ 2^{−|st|}μ(Y) = ∞, a contradiction.
   - (r14's word "pole" is replaced by this Perron argument; it is also the corrected form of Lemma ST(i), `audit_r16`
     C5.)
5. **Binary form.** So C\* is nonlinear: some rule has two C\*-occurrences. Strong connectivity and productivity give
   Y ⇒⁺ αYβYγ.
6. **Bound.** The bound on μ(Y) is the grafting argument of Lemma F(a). ∎

## 4. Levelness of heavy blocks

**Lemma PC** (r14 §1; re-derived in `audit_t8` §1 and `audit_foundations_bot_cites` §2). Let H ⇒* uYz,
Y ⇒⁺ vYy and Y ⇒* w, with u, v, w, y, z terminal and |vy| ≥ 1. Put x_i := u vⁱ w yⁱ z ∈ L(H).
- **(U)** If D(v) ≥ 0 and D(v) + D(y) ≥ 0, then depth(x_i) ≤ |uvwyz|/2 for all i. So H is U-level, and a fortiori
  U-(log-)level, since |x_{i+1}| = |x_i| + |vy|.
- **(V)** If D(y) ≤ 0 and D(v) + D(y) ≤ 0, then sx(x_i) is bounded and H is V-level.

*Proof of (U).* Bound P region by region.
- In u: P ≥ −|u|/2.
- In the j-th copy of v: P(u) + (j−1)D(v) + P_v(·) ≥ −(|u| + |v|)/2.
- In w: the shift iD(v) is ≥ 0.
- In the j-th copy of y: the shift iD(v) + (j−1)D(y) is ≥ 0. This is clear if D(y) ≥ 0. Otherwise it is
  ≥ (i−1)(D(v) + D(y)) + D(v) ≥ 0.
- In z: the shift i(D(v) + D(y)) is ≥ 0.

*Proof of (V).* Apply (U) to φ∘R. It maps the cycle (v, y) to (φ(y^R), φ(v^R)) and negates drifts. ∎

**Prop HL** (r14 §3; H1 fix). Let H ⇒* sYt and let Y ⇒⁺ αYβYγ be **any** terminal binary form (any form produced from
rules of the grammar is allowed; `audit_r16` C3). Put d := D(αβγ), pick w₀ ∈ L(Y) with **w₀ ≠ ε** (possible, as
L(Y) is infinite; H1), and set e := D(w₀) + d.

Define T₀ := w₀ and T_{k+1} := αT_kβT_kγ ∈ L(Y). Then D(T_k) = 2^k e − d and
|T_{k+1}| = 2|T_k| + |αβγ| → ∞.

| case | cycle used | conclusion |
|---|---|---|
| e > 0 | (αT_kβ, γ), k large: D(v) → +∞, total D(v) + D(y) = 2^k e ≥ 0 | PC(U) ⇒ H is **U-level** |
| e < 0 | (α, βT_kγ): D(y) → −∞, total = 2^k e < 0 | PC(V) ⇒ H is **V-level** |
| e = 0, D(α) ≥ 0 | (α, βT_kγ): total 0, D(v) ≥ 0, D(y) ≤ 0 | **U- and V-level** |
| e = 0, D(γ) ≤ 0 | (αT_kβ, γ): total 0 | **U- and V-level** |

- **Remaining e = 0 case.** D(T_k) = −d is constant. So depth(T_{k+1}) ≤ depth(T_k) + c and sx(T_{k+1}) ≤ sx(T_k) + c,
  with c = |αβγ| + 2|d|.
- The family x_k := sT_kt has |x_{k+1}| ≤ 2|x_k| + c and depth, sx = O(k) = O(log|x_k|).
- So H is **U- and V-(log-)level**. ∎

**Theorem SM** (r15_side, in the audited C3 form of `audit_r16`). Let C\* and Y be as in Lemma Bot, with some terminal
binary form (α, β, γ) and d = D(αβγ).
- **(U)** There are a terminal binary form (α′, β′, γ′) of Y and w₀ ∈ L(Y) with e = D(w₀) + D(α′β′γ′) ≥ 0.
- **(V)** There are a form and a w₀ with e ≤ 0.

*Proof of (U).* If some w₀ has D(w₀) + d ≥ 0, we are done. Otherwise D(w₀) < −d for all w₀ ∈ L(Y).
- **Step 0 (bounded above).** For every Z reachable from Y (Y ⇒* s′Zt′), D(z) ≤ −d − D(s′t′) on L(Z). So
  h(Z) := max D on L(Z) is finite and attained, since D takes values in ½ℤ.
- **Step 1 (potential identity).** For a rule r : Z → u₀Z₁u₁⋯Z_ℓu_ℓ, define the slack
  σ(r) := h(Z) − D(u₀⋯u_ℓ) − Σ_i h(Z_i).
  - σ(r) ≥ 0: substitute maximisers for the Z_i.
  - σ(r) ∈ ½ℤ.
  - Telescoping over a tree t of w ∈ L(Z) gives **h(Z) − D(w) = Σ_{nodes} σ(r_ν)**.
- **Step 2 (all C\*-rules are balanced).** Suppose a rule r with left-hand side in C\* had σ(r) ≥ ½. Let n_r(t) be
  its number of uses.
  - **Few uses are rare.** Mark r with weight v ∈ (0, 1). The lower SCCs are analytic at ½ (Lemma Bot).
    - The least fixed point satisfies y_v(½) ≤ y₁(½) < ∞, strictly at lhs(r) and hence everywhere by irreducibility.
    - Because C\* is nonlinear, J_v(y_v) ≤ J₁(y₁) entrywise, with J_v(y_v) ≠ J₁(y₁).
    - J₁(y₁(½)) is irreducible with ρ = 1, since otherwise IFT plus Pringsheim would put the radius above ½.
    - Strict Perron–Frobenius gives ρ(J_v) < 1. IFT then continues y_v past ½ (radius ρ_v > ½).
    - So #{w ∈ L(Y)_n : n_r < εn} ≤ v^{−εn}[zⁿ]y_v ≤ c(v^{−ε}/ρ′)ⁿ for ρ′ ∈ (½, ρ_v). Choose ε with
      v^{−ε}/ρ′ < 2 − δ.
  - **Many uses force negative drift, which is rare.** If n_r ≥ εn, then D(w) ≤ h(Y) − εn/2. By Hoeffding there are at
    most 2ⁿe^{−ε²n/2+O(1)} such words.
  - Together these give |L(Y)_n| ≤ (2 − δ′)ⁿ, so the radius is > ½. This contradicts Y ∈ C\*.
- **Step 3 (a new form with e = 0).** Rebuild the binary form of Lemma Bot. The path rules lie in C\* and have σ = 0 by
  Step 2. Expand every off-path nonterminal, and both Y-leaves, by maximiser subtrees, which have total slack 0 by
  Step 1.
  - The resulting word α′w\*β′w\*γ′ has total slack 0, so h(Y) = d′ + 2h(Y).
  - With w₀ := w\*, this gives e′ = h(Y) + d′ = 0.

*Proof of (V).* Apply (U) to φ∘R, which negates D and preserves unambiguity and radii. ∎

**Lemma L** (r17_oh_level §1; `audit_t8` §1, C3). **Every heavy H is U-(log-)level and V-(log-)level.**
*Proof.*
- Lemma Bot gives Y and a form.
- SM(U) gives a choice with e ≥ 0. HL then makes H U-level (e > 0) or U- and V-(log-)level (e = 0).
- SM(V) gives a choice with e ≤ 0, and HL makes H V-(log-)level.
- Levelness is a property of the word set L(H), not of the tape H sits on. ∎

*Consequences.*
- "Side mismatch" (r14 §5) is impossible.
- The "U-level but not V-level heavy block" scope of `audit_r17` C3 and r16 §5 is **empty**.
- A late-rise light block such as {(ba)^m a^m} is irrelevant, since only heavy blocks are used (`audit_t8` root
  question (i)).

## 5. Freezing lemmas and walk bounds

Throughout §5, (C, X, p, w, q) is a pair model as in §1.4 and the bounds hold for every **pair-model word** W
(`audit_r17` C1, `audit_t8` C1: not "every W ∈ L"). Constants may depend on the model. Small n are absorbed into the
constants.

**Lemma MS⁺** (r16 §1 = r13 §1 read on the full range; log form per `audit_r17` C2).
- (b) If some loop rule carries on its **U side** a U-(log-)level nonterminal, then there is c₁ with
  **B_W(k) ≥ −c₁(1 + log(n+2)) for all 1 ≤ k ≤ n/2**.
- (a) Mirror: if some loop rule carries on its **V side** a V-(log-)level nonterminal, then
  **A_W(k) ≤ c₁(1 + log(n+2)) for all 1 ≤ k ≤ n/2**.

*Proof of (b).*
1. **The flat word.** Fix a first-return loop ρ through that rule (Fact 6), with every block word fixed except one
   word x of the level nonterminal. Its token is (αxβ, v_ρ) with α, β, v_ρ fixed. By the window property, choose x with
   n + |v_ρ| ≤ |x| ≤ 2n + c and depth(x) ≤ K := c(1 + log(n+2)).
2. **The new word.** Prepend ρ as the **outermost** token: W′ = p αxβ M v_ρ q ∈ L, where W = pMq and M = UwV is
   contiguous in both.
3. **Suffix transport.** For |q| ≤ k ≤ n − |p|, suf_{k+|v_ρ|}(W′) = suf_{k−|q|}(M)·v_ρ q. Hence
   B_{W′}(k + |v_ρ|) = B_W(k) + D(v_ρ).
4. **Prefix frozen.** For k′ ≤ |pαx|, A_{W′}(k′) ≥ −(|p| + |α|)/2 − K.
5. **Window.** For k ≤ n/2, k′ := k + |v_ρ| ≤ |pαx| and 2k′ ≤ n′. G⁻(W′) gives
   −(|p| + |α|)/2 − K ≤ A_{W′}(k′) < B_W(k) + D(v_ρ).
6. **Small k.** For k < |q|, B_W(k) ≥ −|q|/2.

The fold centre of W′ lies to the right of every k′ used. (a) is (b) for φ∘R. ∎

**Lemma MS^in** (r17_oh_level §2; `audit_t8` §2). If some loop rule carries on its **U side** a V-(log-)level
nonterminal H, then there is c₂ with

  **A_W(k) ≤ max_{j≤m(W)} B_W(j) + c₂(1 + log(n+2)) for all k ≤ |pU|.**

*Proof.*
1. **The flat word.** Fix ρ through that rule, with token (αxβ, v_ρ). Choose x ∈ L(H) with n ≤ |x| ≤ 2n + c and
   sx(x) ≤ K = c(1 + log(n+2)).
2. **The new word.** Append ρ as the **innermost** token: W′ = p U αxβ w v_ρ V q ∈ L, with n′ ≥ 2n. Put m = |Vq| and
   c₁ := |v_ρwβ|.
3. **What is unchanged.** A_{W′}(k) = A_W(k) for k ≤ |pU|, and B_{W′}(k) = B_W(k) for k ≤ m.
4. **Suffix side.** For m ≤ k ≤ m + c₁, B_{W′}(k) ≤ D(Vq) + c₁/2. For k = m + c₁ + j with 0 ≤ j ≤ |x|,
   B_{W′}(k) = D(Vq) + D(v_ρwβ) + D(suf_j x) ≤ B_W(m) + c₁/2 + K.
5. **Window.** Every k ≤ |pU| ≤ n satisfies 2k ≤ n′ and k ≤ m + c₁ + |x|.
6. **Conclusion.** G⁻(W′) gives A_W(k) < B_{W′}(k) ≤ max_{j≤m}B_W(j) + c₁/2 + K. ∎

**Lemma Q (quadrant)** (r16 §2; `audit_r17` §2). Let Q_n(C) := {W ∈ Σⁿ : A(k) ≤ C and B(k) ≥ −C for 1 ≤ k ≤ ⌊n/2⌋}.
Then 2^{−n}|Q_n(C)| ≤ c(C+1)²/n.
*Proof.* A and B read disjoint letters, so they are independent ±½ walks of length ⌊n/2⌋. Apply the ballot bound to each.
(The exact DP gives n·density → 4/π at C = 0.) ∎

**Lemma D (barrier set)** (r17_oh_level §3; constant corrected per `audit_t8` C2). For n ≥ 4, 1 ≤ M ≤ n/4 and
C, a ≥ 0, put T := ⌊n/2⌋ and

  S_n(M; C, a) := {W ∈ Σⁿ : B(k) ≥ −C and A(k) ≤ max_{j≤M}B(j) + a for all 1 ≤ k ≤ T}.

Then 2^{−n}|S_n| ≤ c(C+1)^{1/2}(M + (a+C+1)²)M^{−1/4}/n.

*Proof.* A and B are independent. Let H_M := max_{j≤M}B(j) ≥ −½ and τ := min{k : B(k) < −C}.
1. Given B, ballot gives P(A ≤ H_M + a on [1, T]) ≤ c(H_M + a + 1)/√T.
2. By Markov at time M, given B(M) = h ≤ H_M, B stays ≥ −C on (M, T] with probability ≤ c(h + C + 1)/√(T − M), and
   T − M ≥ T/2.
3. So 2^{−n}|S_n| ≤ (c/T)·E[(H_M + a + C + 1)²; τ > M] ≤ (c/T)·‖(H_M + a + C + 1)²‖₂·P(τ > M)^{1/2}.
4. Doob L⁴ gives E H_M⁴ ≤ cM², so the norm is ≲ M + (a+C+1)². Ballot gives P(τ > M) ≤ c(C+1)M^{−1/2}. ∎

The true order is √M/n (exact DP in r17 §5, reproduced independently in `audit_t8` §3). M^{3/4} is enough.

## 6. Proof of Theorem T8_unamb

Let L ⊆ G⁻ be unambiguous and rotation-dense, and let G be as in §1.2.
- Thm M(i) gives μ(L) = ∞.
- Lemma F gives a linear SCC C with ρ(M(½)) = 1 and μ < ∞ below it.
- Fix the pair model (X, p, w, q) of §1.4. All of its words lie in L ⊆ G⁻, and the pair map is injective.

Classify the lower nonterminals on **loop rules** of C by side. A heavy nonterminal in the exit word w or in the
context p, q is irrelevant, since those words are fixed.

| case | heavy nonterminals on loop rules | contradiction from |
|---|---|---|
| (a) | none (all light) | Lemma Rn |
| (b) | on the U side **and** the V side | Thm PR2⁺ (log form) |
| (c) | on the U side only (any q_V := π(v ≠ ε) ≥ 0, including one-tape q_V = 0) | Thm OH |
| (d) | on the V side only | Thm OH applied to φ∘R |

The cases are exhaustive. Each one contradicts injectivity, or L ⊆ G⁻ directly in case (a). This proves the theorem. ∎

### 6.1 Case (b): Theorem PR2⁺ (r16 §3, log form per `audit_r17` C2)
*Claim.* If heavy nonterminals occur on both sides, the pair map is not injective.

*Proof.*
1. **Upper bound.** Lemma L gives a U-side heavy H₁ that is U-(log-)level and a V-side heavy H₂ that is
   V-(log-)level. MS⁺(b) and MS⁺(a) then put every pair-model word of length n in Q_n(C_n) with C_n = c(1 + log n).
   By Lemma Q,
   Σ_{n≤N} 2^{−n}#{pair-model words of length n} ≤ Σ_{n≤N} c log²(n+2)/n = O(log³N).
2. **Lower bound.** Under injectivity, Fact 5 and Lemma 3.4(b) give 2^{−|pwq|}U(N − |pwq|) ≥ cN^{β₀}.
3. These are incompatible for large N. ∎

Remarks.
- MS⁺ needs only long (log-)level words, not heaviness, so a light V-level block on the V side would also do. This is
  not needed here.
- The balance of the tapes, the tail exponents of the lighter side and the case k = 2 play no role.
- No cone bound is used.

### 6.2 Cases (c), (d): Theorem OH (r17_oh_level §4; `audit_t8` §3)
*Claim.* If heavy nonterminals occur on the U side only, the pair map is not injective. The mirror case (d) follows by
φ∘R.

*Proof.* Assume injectivity. Let β₀ be the heaviest exponent; it is attained on the U side. Fix γ with β₀ < γ < 4β₀/3
(γ < 2/3).
1. **Lower bound.** As in 6.1, the pair-model mass up to N is ≥ cN^{β₀}.
2. **Heights.** Lemma L makes a U-side heavy H both U- and V-(log-)level.
   - MS⁺(b) gives B_W(k) ≥ −C_n for k ≤ n/2.
   - MS^in gives A_W(k) ≤ max_{j≤m(W)}B_W(j) + a_n for k ≤ |pU|.
   - Here C_n, a_n = O(log n). Neither bound uses MS⁺(a) (`audit_t8` root question (iii)).
3. **Class 1: m(W) ≤ M_n := ⌊n^γ⌋.**
   - For n large, M_n ≤ n/4 − |w|, so |pU| = n − |w| − m(W) ≥ n/2 and MS^in covers all k ≤ T. Since
     max_{j≤m}B ≤ max_{j≤M_n}B, W ∈ S_n(M_n; C_n, a_n).
   - Lemma D bounds the density by c·n^{−1+3γ/4}·polylog(n).
   - Summed over n ≤ N this is O(N^{3γ/4} polylog N) = o(N^{β₀}).
4. **Class 2: m(W) > n^γ.** By injectivity, the mass of class 2 over all lengths is at most
   2^{−|pwq|}Σ_r [P(|V_r| > 2μ_V r) + P(|U_r| < (2μ_V r + |q| + 1)^{1/γ})], where μ_V := E|v₁|.
   - All V-side nonterminals are light, so Lemma 3.4(c) and Chernoff give P(|V_r| > 2μ_V r) ≤ e^{−cr}. (If μ_V = 0,
     this term vanishes.)
   - By Lemma 3.4(d), P(|U_r| < x) ≤ P(max_{i≤r}|u_i| < x) ≤ exp(−r c_u x^{−β₀}). With x ≍ r^{1/γ} this is
     exp(−c r^{1−β₀/γ}), which is summable because γ > β₀.
   - So class 2 has total mass O(1).
5. **Contradiction.** Steps 3 and 4 give mass o(N^{β₀}), contradicting step 1. ∎

One-tape models (v ≡ ε) are the special case m(W) = |q|. Class 2 is then empty, and Lemma D with M = |q| gives mass
O(polylog N). (r17_oh_level §4.1 also gives an alternative route via PR1ˡᵒᵍ. That route is not used here.)

### 6.3 Observation: the count form T8_μ [observation of this write-up; not separately audited]
After Thm M(i), no step uses rotation density, only μ(L) = ∞. Read literally, the chain of §§3–6 therefore shows:
**every unambiguous context-free L ⊆ G⁻ has μ(L) < ∞, and hence (Thm M(ii)) |L_n| = o(2ⁿ/n).**
- This is r9's T8_μ.
- `audit_foundations_r9r10` C2 describes T8_μ as "stronger than T8_unamb", which is correct as a comparison of
  statements. Nothing in the audited chain appears to need more than μ(L) = ∞.
- The headline claim remains T8_unamb. Promoting T8_μ requires an auditor to confirm this reading. See §7, item E22.
