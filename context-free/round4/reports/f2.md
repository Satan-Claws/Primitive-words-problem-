## 1. CL3 is false: the class-restricted certificate (PROVED + COMPUTER-CHECKED)

F_2 = {a(a^p b a^q b a b)^k}. Here K = 3k and x = (p+1, q, 1, p, q, 1, …). Write P_i = x_{3i−2}, Q_i = x_{3i−1}, and
M_i = x_{3i} (the "marker" blocks `ab`).

**Certificate.** L = { ∏_{i=1}^k a^{P_i} b a^{Q_i} b a b : k ≥ 2, P_1 = P_k + 1, P_i = P_{k+1−i} for 2 ≤ i ≤ k−1 }.
The Q_i are free.

Linear grammar:
S → a A Y;  A → a A a | N;  N → Y | Y B Y;  B → a B a | N | C;  C → a C | ε;  Y → b D b a b;  D → a D | ε.

COMPUTER-CHECKED (`class_cert.py 30`):
- L(G) equals the condition-defined set for all lengths ≤ 30 (36 304 words);
- every one of these words is primitive;
- all 58 members of F_2 of length ≤ 30 lie in L(G).

F_2 ⊆ L is immediate: P = (p+1, p, …, p).

**Theorem 1 (PROVED). L ⊆ Q.** Suppose σ_d x = x with 0 < d < 3k. There are two cases.
- **d mod k ≠ 0.** Then σ_{3d} gives a block shift j = d mod k ≠ 0 on the P-subsequence. So P is cyclically
  e-periodic with e = gcd(j,k) < k.
  - If e = 1, P is constant, which contradicts P_1 − P_k = 1.
  - Otherwise k ≥ 2e and 2 ≤ e+1 ≤ k−1. Then P_1 = P_{e+1} = P_{k−e} = P_k, using periodicity, then the palindrome
    condition, then periodicity again. Contradiction.
- **d mod k = 0, so d ∈ {k, 2k}.**
  - If 3 | k, then d is a multiple of 3 and a nonzero block shift. This is covered by the first case.
  - If 3 ∤ k, each orbit {j, j+k, j+2k} meets all three residue classes, so it contains a marker position. Hence
    x ≡ 1, and P_1 = P_k, a contradiction. ∎

**Why F_2 escaped cl1's class 𝓡:**
- 𝓡 bounds x − Rx on all coordinates.
- L constrains only one residue class, the P-class, which is fixed by the reflection i ↦ 3k−1−i.
- L leaves the swapped classes (Q ↔ markers) completely free.

cl1's later L_ℓ (cl1.md, CL3 section) puts sign constraints on the swapped classes instead of using a marker. That is
more general: it needs no marker and covers every one-a insertion into u^k with |u|_b = ℓ fixed.

**Theorem 2 (PROVED; exact criterion COMPUTER-CHECKED).** General marker version. Fix ℓ and a set M of "marker"
classes mod ℓ, where the blocks are forced to equal 1, and a defect class 0 ∉ M. Let y_i = x_{ℓi} (0-indexed), and
require y_0 − y_{k−1} = 1 and y_i = y_{k−1−i} for the inner i.
- **Hypothesis:** for every prime r | ℓ, the coset (ℓ/r)Z_ℓ meets M.
- **Claim:** under the hypothesis, no such x is shift-invariant.
- **Proof.**
  - Let g = gcd(d, K). If lcm(g, ℓ) < K, we get a block shift on y and the argument of Theorem 1 applies.
  - Otherwise put t = gcd(g, ℓ) < ℓ. The shifts by multiples of g reach every class in tZ_ℓ ⊇ (ℓ/r)Z_ℓ, which
    contains a marker class. So y is constant. ∎
- `general_marker.py`: for ℓ ≤ 6, k ≤ 5 and small entries, the hypothesis holds **exactly** in the cases with no
  periodic vector.
  - When the hypothesis fails, periodic vectors exist, e.g. (1,0,0,1,0,0) for ℓ = 2, k = 3.
  - So the marker condition is sharp for this certificate, which is why cl1's sign constraints are needed in
    general.

**Lemma 3 (PROVED; useful structural fact).** Let ρ_c(i) = c − i and ρ_{c−1}. The union of their chords
{i, c−i} ∪ {j, c−1−j} is non-crossing.
- **Proof.** Take intervals [α, c−α] and [α′, c−1−α′] with α ≠ α′.
  - If α < α′, then c−α > c−1−α′.
  - If α′ < α, then c−1−α′ ≥ c−α.
  - In both cases the intervals are nested. ∎
- So two classes can be reflected about **adjacent** axes at once, e.g. P_i ↔ P_{k+1−i} together with
  Q_i ↔ Q_{k−i}. This is a second stratified realisation of both directions h1, h2 in the coordinator's (ii).
- Answer to the coordinator's (ii): stratified realisations of the F_2 family exist uniformly in k. One example is
  reflection chords on the defect class plus singleton (free) periods on the Q-class. Another is cl1's
  sign-constrained reflection. So no constraint on the period configuration can prove CL3, as expected.

**Flaw check.** I never claimed a proof of CL3. The coordinator's hope in (ii) was "no stratified configuration
avoids shift-invariant vectors". Theorem 1 is an explicit counterexample to that hope, uniformly in k.

## 2. CL4: J = {a·u·u : u ∈ (a*b)^+}. Barrier for interchange-type arguments

The natural negative tool is the Interchange Lemma. LITERATURE: Ogden, Ross, Winklmann, SIAM J. Comput. 14 (1985).
- **Statement** (as I recall it; check the exact constants): for a CFL L there is c such that for all n, every
  R ⊆ L ∩ Σ^n and every 2 ≤ m ≤ n, there is Z ⊆ R with |Z| ≥ |R|/(c n²), and splittings z_i = w_i x_i y_i with:
  - common |w_i| and |x_i|;
  - m/2 < |x_i| ≤ m;
  - w_i x_j y_i ∈ L for all i, j.
- **How it would be used:** take R ⊆ J, so every interchanged word must be primitive, and look for a forced power.

**Lemma W (PROVED; COMPUTER-CHECKED by `cl4_window.py`: L = 10, 12, 13, 15 and windows up to 6, no violations;
62 powers found, all obeying the bound).** Setup:
- Let u ∈ Σ^L and let u″ differ from u only inside an interval W.
- Let w = a u u″ (0-indexed, w_0 = a), and D = {j ∈ [1, L] : w_j ≠ w_{j+L}}. Then |D| ≤ |W|. This also holds if
  the interval is in the first copy or straddles the middle.
- **Claim:** if w = z^k with k ≥ 2, then k is odd and ≥ 3, and the cyclic word z has at most 2|D| letter changes.

*Proof.*
1. |w| = 2L+1 is odd, so k is odd, k ≥ 3, and M = |z| = 2e+1.
2. L = M(k−1)/2 + e. So for j ∈ [1, L] \ D: w_j = w_{j+L} = w_{j+e}, using period M.
3. L ≥ M, so every residue mod M occurs in [1, L]. At most |D| residues have all their occurrences in D. So the
   cyclic word t = z satisfies t_r = t_{r+e} for all but ≤ |D| residues r.
4. gcd(e, 2e+1) = 1, so r ↦ r+e is one M-cycle, and t changes on at most |D| of its edges.
5. Since r+1 ≡ r−2e, each natural adjacency (r, r+1) is joined by a 2-edge path on that cycle. Each cycle edge
   serves ≤ 2 adjacencies, so there are ≤ 2|D| natural changes. ∎

**Corollary W′ (PROVED).** Say u is (λ, m)-complex if:
- (i) u has no unary factor of length λ, and
- (ii) u has no period P ≤ 2mλ.

Then no replacement of an interval of length ≤ m in a·u·u yields a non-primitive word.

*Proof.*
1. If w = z^k, then u = w[1..L] has period M, so M > 2mλ by (ii).
2. z is not unary, because w_0 = a and u ends in b. So by Lemma W, t has a cyclic run of length ≥ M/(2m) > λ.
3. Since L − M ≥ (M−1)/2 ≥ λ, this run occurs inside u, contradicting (i). ∎

**Consequence (barrier, PROVED).** Take λ = 3 log₂ n and m ≤ n/(8λ). Then all but a o(1) fraction of J ∩ Σ^n is
(λ, m)-complex, by a union bound. For such R, every interchange with windows ≤ m stays primitive. Hence:
- an interchange- or "local surgery"-based proof of CL4 must use windows of length Ω(n / log n), or
- it must use structured, low-complexity u (long unary runs or short periods).

This complements cl1's Proposition 7: certificates need unboundedly many classes.
