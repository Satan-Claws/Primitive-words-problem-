# Mixed projection certificates for six run pairs

These results concern the fixed regular slice `(a^+ b^+)^6`, not the full primitive-word language.

Write a word in this slice as `a^(x1)b^(y1)…a^(x6)b^(y6)`, all exponents positive. It is primitive exactly when the six-tuple of pairs `(xi,yi)` has neither divisor period 2 nor divisor period 3. If either scalar tuple x or y is primitive, the pair tuple is primitive. If both scalar tuples are imprimitive while the pair tuple is primitive, their minimal divisor periods must be 2 and 3 in some order. Indeed the possible scalar periods are 1,2,3; their least common multiple must be 6.

## Eight sufficient context-free certificates

The following conditions are sufficient for primitivity independently of any scalar periodicity assumptions:

* `C_j`, j=1,2,3: `x_j != x_(j+3)` and `y_j != y_(j+2)`.
* `C_4`: `x_1 != x_4` and `y_4 != y_6`.
* `D_1`: `x_1 != x_3` and `y_3 != y_6`.
* `D_j`, j=2,3,4: `x_j != x_(j+2)` and `y_(j−1) != y_(j+2)`.

Each certificate excludes both possible prime-exponent powers: one comparison refutes period 3 and the other refutes period 2. Their comparison intervals in the twelve exponent positions are either disjoint or strictly nested, and the endpoints of the two comparisons are different run variables.

If x has minimal period 2, then x=(A,B,A,B,A,B) with A!=B, so every `x_i != x_(i+3)`, i=1,2,3. If y has minimal period 3, it cannot also have period 2; hence some ordinary `y_j != y_(j+2)`, 1<=j<=4. The matching C certificate applies. Conversely, if y has minimal period 2 and x has minimal period 3, the same reasoning selects one of D_1,…,D_4. Therefore these eight sufficient languages cover all primitive pair tuples whose two scalar projections are both imprimitive.

## Explicit finite grammar scheme

Let P generate a^+ and Q generate b^+, with productions `P -> aP | a` and `Q -> bQ | b`. For a terminal c in {a,b} and a previously specified context-free language K, define E_c(K) by a fresh start nonterminal E and a nonterminal C generating c^+:

    C -> cC | c
    E -> cEc | cCKc | cKCc.

Here K denotes the start nonterminal of a fresh copy of a grammar for K. Exactly

    L(E_c(K)) = { c^r z c^s : r,s>=1, r!=s, z∈K }.

The recursive production adds equally to both outer lengths; the two base productions put a nonempty excess on exactly one side. This proves both inclusions directly. Every use of E below receives fresh nonterminals. Products mean concatenation with a fresh start production; fixed powers mean repeated concatenation.

The eight certificate languages are generated by:

    C_j = (PQ)^(j−1) E_a(E_b(PQP)) Q(PQ)^(3−j),  j=1,2,3;
    C_4 = E_a(QPQPQ) E_b(PQP);

    D_1 = E_a(QPQ) E_b(PQPQP);
    D_j = (PQ)^(j−2) P E_b(E_a(QPQ)) (PQ)^(4−j), j=2,3,4.

Thus these are genuinely finite CFGs, not intersections asserted to preserve context-freeness. A fresh start symbol with productions to the eight starts generates their union. Combining this union with lifted grammars for the two primitive scalar projections covers the full primitive six-pair slice. The scalar grammars are established independently in finite_stratified_run_slices.md; this note does not assume their existence for unbounded tuple lengths.

## Audit of the more general linear-projection transfer

Fix m and let r=ω(m). Suppose a finite CFG is available for the distinct-letter encoding of primitive scalar m-tuples. For positive pair tuples (a,b), consider the r+1 scalar tuples `a+t b`, t=0,…,r.

If the pair tuple is imprimitive, it has a maximal proper divisor period d=m/p shared by a and b, so every scalar projection has that period. Conversely, suppose the pair tuple is primitive. For a fixed p|m, at most one real t can make a+t b d-periodic: two distinct choices imply, by subtracting the period equations, that b and then a are both d-periodic, a contradiction. At most r choices are therefore bad, and at least one of 0,…,r gives a primitive scalar tuple.

For indexed input letters A_i,B_i and scalar output letters C_i, use the morphism

    h_t(A_i)=C_i,       h_t(B_i)=C_i^t.

Taking the inverse image of the scalar context-free language and intersecting with the regular language `A_1^+B_1^+…A_m^+B_m^+` gives the successful t-th projection. This includes t=0: erasing morphisms are allowed in inverse-morphism closure. Taking the finite union over t and then mapping A_i to a and B_i to b yields exactly the primitive part of `(a^+b^+)^m`. Positivity and alternation ensure the final binary run decomposition remains unique.

## No fixed finite set of these projections suffices for all m

Let T be any nonempty finite set of nonnegative integers. Assign a distinct prime p_t to every t∈T and put m=product_{t∈T} p_t. Identify cyclic positions with their CRT coordinates. Let f_t(i)=1 when the p_t-coordinate of i is zero, and zero otherwise. Define

    b_i = B + Σ_(t∈T) f_t(i),
    a_i = A − Σ_(t∈T) t f_t(i),

where B>=1 and A>Σ_(t∈T)t. Both tuples are positive. The pair tuple is primitive because changing any single prime coordinate changes b, so no maximal divisor period m/p_t is a period.

But for every chosen t,

    a_i+t b_i = A+tB + Σ_(s∈T)(t−s) f_s(i).

The coefficient of f_t is zero. Hence this projection is independent of the p_t-coordinate and has proper divisor period m/p_t. Every projection in T is imprimitive. This demonstrates why the finite-slice transfer does not automatically provide one fixed finite family of projections for all lengths. It does not prohibit a different PDA construction.

## No standalone context-free injective unary scalarization

There is no injective function f:N_(>0)^2→N whose graph has a context-free encoding

    L_f = { a^i b^j # c^(f(i,j)) : i,j>=1 }.

If L_f were context-free, Parikh's theorem and coordinate projection would make graph(f) a finite union of linear sets in N^3. Every component of that union lies within the functional graph. Therefore none of its period vectors can have first two coordinates zero and third coordinate positive: that would give different outputs at the same input.

Choose C at least as large as every base output coordinate and every period output coordinate in the finite representation. Every nonzero output period must increase the sum of input coordinates by at least one. Consequently every point in the graph satisfies

    f(i,j) <= C(i+j+1).

For 1<=i,j<=N there are N² inputs but at most C(2N+1)+1 possible outputs. This contradicts injectivity for sufficiently large N.

Thus replacing the variable linear multiplier by a different fixed, single-valued, injective unary code of each pair does not provide a standalone PDA/CFG subroutine either. This is stronger than merely observing that multiplication is not rational: it applies to every proposed local function f with this input/output encoding. It does not exclude globally chosen codes that depend on the entire tuple, a nondeterministic combined certificate, or a construction that never recognizes L_f independently.

## Finite checks of the eight mixed certificates

Exhaustive checks over scalar coordinates from {1,2} found 10 imprimitive scalar six-tuples and 24 primitive pairs of imprimitive projections; every such pair satisfied at least one certificate. Over {1,2,3}, the corresponding counts were 33 and 288, again with complete coverage. All 4096 binary pair tuples were checked for soundness: no certificate accepted an imprimitive pair. These computations supplement the general proofs above and do not extend their fixed-slice scope.
