## 0. Ginsburg's theorem and the reductions

**Stratified sets.** A finite set P ⊆ ℕ^m is *stratified* if
- (i) every π ∈ P has at most two non-zero coordinates, and
- (ii) there are no i<j<k<l and π, π' ∈ P with π_i π_k ≠ 0 and π'_j π'_l ≠ 0 (no crossing supports).

A linear set c + P* is stratified if P is.

**Theorem (Ginsburg–Spanier 1964, as stated in Ginsburg's book, 1966, §5.4 — numbering from memory).** Let c₁,…,c_m be distinct letters and L ⊆ c₁*⋯c_m*. Then L is context-free iff E(L) = {(n₁..n_m) : c₁^{n₁}⋯c_m^{n_m} ∈ L} is a finite union of stratified linear sets. (The book proves it for w₁*⋯w_m* with arbitrary words; I use only the letter case.)

**Reduction.** Let S_m ⊆ ℕ^m be the set of exponent tuples that are not d-periodic (cyclically) for any proper divisor d of m.

(a) *a\*b variant.* A word a^{x₁}b⋯a^{x_m}b equals u^k with k ≥ 2 iff u = a^{x₁}b⋯a^{x_{m/k}}b and x is (m/k)-periodic. So the exponent set of Q ∩ (a\*b)^m is exactly S_m.

(b) *Letter-bounded form.* Let L_m = {c₁^{x₁}⋯c_m^{x_m} : x ∈ S_m}.
- L_m is the image of Q ∩ (a\*b)^m under a gsm. The gsm keeps the block index in its state (≤ m+1 states), outputs c_i for each a, and outputs ε for each b.
- Conversely, Q ∩ (a\*b)^m = h(g⁻¹(L_m) ∩ c₁\*d c₂\*d⋯c_m\*d), where g erases d, h(c_i) = a and h(d) = b.
- All of these operations preserve CF. Hence **Q ∩ (a\*b)^m is CF ⇔ L_m is CF ⇔ S_m is a finite union of stratified linear sets.**

(c) *a⁺b variant.* The exponent set of F_m = Q ∩ (a⁺b)^m is S_m⁺ = (1,…,1) + S_m, because adding a constant does not change periodicity. Translating every constant by ±1 preserves stratified covers. So F_m is CF ⇔ S_m is stratifiable. The a⁺b and a\*b questions are the same at every m.

(d) If some S_m is not stratifiable, then Q is not CF: F_m = Q ∩ regular.

Notation: A_p denotes the (m/p)-periodic vectors, so S_m = ℕ^m \ ⋃_{p|m prime} A_p. For m = 6: P₂ = A₃ (2-periodic) and P₃ = A₂ (3-periodic).

## 1. The two-sided merge lemma (stratification machine)

**Setup.** Take left blocks ℓ = (i₁,…,i_a) and right blocks r = (j₁,…,j_b). Every i is smaller than every j. The orientation is one of:
- *inside-out:* i₁ > i₂ > … and j₁ < j₂ < …; or
- *outside-in:* i₁ < i₂ < … and j₁ > j₂ > ….

The remaining blocks are *free*. Define λ_k = x_{i₁}+…+x_{i_k} and ρ_k = x_{j₁}+…+x_{j_k}.

**Paths.** The breakpoints {λ_k} ∪ {ρ_k} cut [0, max(λ_a, ρ_b)) into elementary segments. Segment s lies in left block u_s (or past the left end, "∞") and in right block v_s (or ∞). The sequence π = ((u_s, v_s))_s is the *path* of x. Paths are exactly the sequences that are strictly increasing in the product order, with ∞ absorbing and never (∞, ∞).

**Lemma 1.** For every path π, the set X_π = {x : path(x) = π} is the linear set c_π + P_π*, where
- c_π = Σ_s v_s and P_π = {v_s} ∪ {e_f : f free};
- v_s = e_{i_{u_s}} + e_{j_{v_s}}, with an ∞ part omitted.

P_π is stratified. The sets X_π partition ℕ^m. Every sign of λ_k − ρ_{k'} (<, =, >) is constant on X_π.

*Proof.* The map x ↦ (segment lengths ℓ_s ≥ 1, free values) is a bijection from X_π onto ℕ₊^{#seg} × ℕ^{free}, and x = Σ_s ℓ_s v_s + Σ_f x_f e_f.

For non-crossing, take s < s'. Then u_s ≤ u_{s'} and v_s ≤ v_{s'}.
- Inside-out: i_{u_{s'}} ≤ i_{u_s} < j_{v_s} ≤ j_{v_{s'}}, so the support of v_s is nested inside (or shares an endpoint with) the support of v_{s'}.
- Outside-in: the mirror image of the same argument.

Singleton supports never cross. Finally, λ_k is the total length of the segment prefix {s : u_s < k}, and similarly for ρ_{k'}. Since all ℓ_s ≥ 1, the order between λ_k and ρ_{k'} is determined by the two prefix lengths, which are fixed by π. ∎

**Corollary.** Any predicate on the signs of the λ_k − ρ_{k'} defines a finite union of stratified linear sets. The PDA view: push the left blocks with a marker at each breakpoint, pop with the right blocks, and read the marker structure. The comparison distances need not be tied to anything; only the nesting matters.

## 2. m = 6: complete stratified cover (proved)

**W.** Let ν₁ = x₁+x₂−x₄−x₅ and ν₂ = x₂+x₃−x₅−x₆.
- Both vanish on the bases of P₂ and P₃.
- dim(P₂+P₃) = 2+3−1 = 4 and rank(ν₁,ν₂) = 2 (sympy-checked).
- Hence **P₂+P₃ = W = {ν₁ = ν₂ = 0}** as subspaces. This verifies the root agent's claim.

Lattice and cone versions also hold:
- Every integer point of W is x = (A+C, B+D, A+E, B+C, A+D, B+E) with A,…,E ∈ ℤ (take B=0, A=x₁−x₄, C=x₄, D=x₂, E=x₃−x₁+x₄).
- By computer: every point of W ∩ [0,6]⁶ is a sum of a nonnegative 2-periodic vector and a nonnegative 3-periodic vector (0 exceptions).

**The cover.**

|---|---|---|---|

**Soundness.**
- ν₁ and ν₂ vanish on P₂ ∪ P₃.
- C0: Σ₁³ = Σ₄⁶ on P₃, and x₂+x₃ = x₄+x₅ on P₂.
- C1: x₁ = x₄ on P₃, and x₁+x₂ = x₃+x₄ on P₂.

**Coverage.**
- If x ∉ W, then ν₁ ≠ 0 or ν₂ ≠ 0, so x ∈ N1 ∪ N2.
- If x ∈ W, use the parametrisation. The quantities A−B, C−D, D−E are invariants of x. On W:
  - x ∈ P₃ ⇔ A = B, and x ∈ P₂ ⇔ C = D = E.
  - C0 ∩ W = {A≠B, E≠C} and C1 ∩ W = {A≠B, D≠E}.
  - Their union is {A≠B, (C,D,E) non-constant} = W \ (P₂ ∪ P₃).

**Theorem.** S₆ = N1 ∪ N2 ∪ C0 ∪ C1, a union of 464 explicit stratified linear sets. Hence Q ∩ (a\*b)⁶ and Q ∩ (a⁺b)⁶ (translate by 1) are CF. ∎

## 3. General fixed m: gap frameworks, one witness per prime

**Gap framework.** For a cut c and gap g ≥ 0, define E_{c,g}(a) = Σ x[c+g .. c+g+a−1] − Σ x[c−a .. c−1] (indices mod m, 2a+g ≤ m).
- All E_{c,g}(·) come from one inside-out framework with the g gap blocks free. By Lemma 1, any conjunction of conditions on them is stratified, after rotating so the framework sits in linear order. Rotations are free, because S_m is rotation-invariant and CF is closed under cyclic shift (block-rotation closure followed by ∩ (a\*b)^m).
- Equal-length interval functionals and A_p: Σ_I − Σ_J lies in A_p^⊥ iff |I| = |J| = L and the residue multisets mod d = m/p agree. This happens iff d | L or d | shift. For E_{c,g}(a) the shift is a+g, so **E_{c,g}(a) ∈ A_p^⊥ ⇔ d_p | a or d_p | a+g.**
- The certificate at (c,g): for every prime p | m, some admissible a has E_{c,g}(a) ≠ 0. That is one witness per prime, all nested about one centre: a single one-turn PDA with markers.

**Exact coverage test.** The failure set is ⋂_{frames} ⋃_p Z_{frame,p} (each Z an intersection of kernels). This is a union of subspaces U_σ, one for each choice σ of an unrefuted prime per frame.
- Coverage ⇔ every U_σ lies inside some A_q (a subspace inside a finite union of subspaces lies in one of them).
- If some U_σ ⊄ ⋃A_q, it contains nonnegative integer points outside ⋃A_q: 𝟙 ∈ U_σ, so perturb around it.
- Computation is branch-and-bound or BFS with maximal-subspace pruning.
  - Exact arithmetic over ℚ for small m (`onecentre.py`).
  - Ranks mod P = 2147483629 or 33554393 elsewhere (`oc_mod.py`, `fastcov.py`); two implementations agree on all overlapping cases.
  - Failures are re-verified exactly by an explicit integer witness.

## 4. Uniformity in m (Q3)

**Proposition 4.1 (equivalence).** Q ∩ (a⁺b)⁺ is CF ⇔ Q ∩ (a\*b)⁺ is CF ⇔ Q is CF.

*Proof.* Let φ: a↦a, b↦ab. Then {a, ab} is a suffix code, so φ is injective.

Step 1: for w ∈ Σ\*b, φ(w) ∈ (a⁺b)⁺, and φ(w) ∈ Q ⇔ w ∈ Q.
- If φ(w) = u^k, then u ends in b and is a prefix of a word in (a⁺b)⁺. So u ∈ (a⁺b)⁺ and u = φ(v). Injectivity gives w = v^k.
- The converse is immediate.

Step 2: hence Q ∩ Σ\*b = φ⁻¹(Q ∩ (a⁺b)⁺) (a word ending in a maps to a word ending in a).

Step 3: Q = cyc(Q ∩ Σ\*b) ∪ {a}, since every primitive word other than a contains b and Q is rotation-closed.

Cyclic shift and inverse morphism preserve CF. The remaining implications are ∩ regular. ∎

So "uniform nested certificates for Q ∩ (a⁺b)⁺" *is* the main problem. Even Q ∩ (a^{≤1}b)⁺ = Q ∩ {b,ab}⁺ is as hard: it is Q_{x,y} under the prefix code x↦b, y↦ab.

**What breaks when m varies.**

(1) **Index matching.** By §3, a functional Σ_I − Σ_J vanishing on A_p needs |I| = |J| in *blocks*, and length or shift ≡ 0 mod m/p.
- For fixed m the block index is in the finite control, so the stack only carries a-mass.
- Uniformly, the number of b's on each side must be matched *and* the a-masses compared, in one stack.
- **Nested-matching lemma (certificate model).** Suppose a one-stack matching pairs letters of u (the left arc) with letters of v (the right arc), preserving letter type and non-crossing, with |u|_b = |v|_b. Then the i-th b from the cut is paired with the i-th b from the cut. The a's between consecutive b-pairs can only be matched within the same "annulus", which is the block pair x_{c−i} vs x_{c+i}.
  - So the only mass information is the *mirror* comparison x_{c−i} vs x_{c+1+i}, block by block.
  - Mirror inequality does not refute periodicity: (1,2,1,2) has a mirror mismatch at the middle cut.
  - The bounded slice (ab)^j a^i b · (ab)^j a^l b with i ≠ l is a crossing pattern, i.e. not CF.

  Either the stack carries the index (letters) and then compares mirrors, or it carries mass and loses the index.

(2) **Semilinearity (E's Lemma 2, transposed).** Suppose a CF certificate language exposes, by finite-state-markable arcs, an equal-length arc pair whose block length L satisfies (m/p) | L for a prime p. Then the set {(L, m)} is semilinear, and only finitely many primes p = m/L·j can occur. So a uniform scheme cannot use prime-tied arc lengths for unboundedly many primes. Its certificates must be sound against *all* periods at once.

(3) **Index-free certificates exist, but are swamped by mass.** I give a new family.

**Definition.** For fixed K ≥ 1, U_K consists of block sequences y ∈ ℕ₊^m (the word a^{y₁}b⋯a^{y_m}b) with a cut k such that, with weights w_i = y_i + K (a counts 1, b counts K):
- |Σ_{i≤k} w_i − Σ_{i>k} w_i| ≤ 2K+1, and
- no left breakpoint w_k + … + w_{k−a+1} equals any right breakpoint w_{k+1} + … + w_{k+b} (a, b ≥ 1).

**Theorem 4.2.** U_K is CF and contains no periodic sequence of any length. So the set a⁺b ∪ {aⁱbaʲb : i≠j} ∪ ⋃_{K≤K₀} cyc(U_K) is a CF subset of Q, uniformly in m.

*CF.* Use a one-turn PDA:
- Guess the cut.
- On the left, push 1 per a and K per b, then a marker after each block.
- On the right, pop 1 per a and K per b, skipping markers. After each right block, reject if the top is a marker or the bottom.
- Track a deficit ≤ 2K+1 in the finite control, and check the residue at the end.

*Soundness.* Let y be d-periodic with window weight s' and total weight n ≥ 2s'.
- If one side had fewer than d blocks, its weight would be ≤ s' − (K+1). The imbalance would then be ≥ n − 2s' + 2K + 2 ≥ 2K+2.
- So the balance condition forces both sides to have ≥ d blocks. Then λ_d = ρ_d = s' is a tie. ∎

**Coverage data** (`uniform.py`, `uniform_len.py`, `uniform_scaled.py`, `uniform12.py`), with K ∈ {1..6} plus the two-block family:
- **All primitive classes in (a⁺b)⁺ of length ≤ 21 are covered.**
- First misses: (1,1,8,8), i.e. abab a⁸b a⁸b at length 22. Then 9 misses at length 24, 42 at length 30 (for example (1,1,25)).
- **Scaled words t·x:** for m = 2..6, the misses grow to nearly 100% as t → ∞. For m=6 and entries ≤ 3: 0, 0, 6, 41, 92, 98 of 116 at t = 1, 2, 4, 8, 16, 32.
  - In the limit t → ∞ the criterion becomes: an *exact* unweighted halving cut with |2k−m| ≤ 2 and no index tie. This holds for only 18 of 116 necklaces at m=6.
- **{1,2}-sequences:** 6 classes at m=16 are rejected by U_K for **every** K ≤ 59, e.g. (1,1,2,1,2,2,1,1,2,2,1,1,2,2,1,2). In the K → ∞ limit U_K demands λ_a ≠ ρ_a for *all* a, because the PDA cannot know which a are divisor-related.

Two consequences:
- (α) The K-weighting is the only way I found to put index and mass on one stack. It is exact only while blocks are small compared with K. A finite union over K cannot cope with unbounded block lengths.
- (β) **Methodological warning:** a uniform candidate that passes check_grammar up to length 20–21 can still be wildly incomplete. Testers must include scaled families t·x and long {1,2}-sequences.

**Can the obstruction give a non-CF proof?** Not as it stands.
- (1) is a lemma about *matching certificates*, not about all PDAs. A grammar's derivation tree need not pair letters at all, and pumping-based arguments meet A's partner-loop escape.
- Every bounded slice is (conjecturally; computer-verified for every m ≤ 24, prime powers being trivial) CF. So a negative proof must use words with unboundedly many blocks *and* unbounded block lengths at once. In that regime Ginsburg's theorem is unavailable, and by A's Theorem A everything reduces to annotated Ogden OG(Q).
- The concrete target this suggests is a rigidity statement of theorem strength:

  > *Index-mass rigidity (open):* every CF L ⊆ Q ∩ (a⁺b)⁺ meeting all primitive classes contains, for infinitely many m and arbitrarily large scale t, words whose acceptance in L is certified only through equal-block-count comparisons.

  Together with (1) and (2), this would refute CF-ness. I see no way to prove it with pumping, because of the thin complement.
