# density: Sin'ya's density route for subclasses of CFLs

Agent "density". Status: complete (see Sec. 7 for the summary table).

## 0. Summary of results (updated as work proceeds)

- **Theorem 1 (PROVED).** Let L be a (p,q)-fixed-rate linear language (definition in Sec. 1; this class contains the regular languages, at rate (1,0), and the even-linear languages, at rate (1,1)).
  - Assume L has maximal growth rate, limsup |L ∩ Σ^n|^{1/n} = 2. Positive upper density implies this.
  - Then there are a word u0 ∈ L and an integer D ≥ 1 such that, for EVERY v ∈ Σ* and every j ≥ 0, u0 (v u0)^{Dj} ∈ L.
  - In particular u0^{Dj+1} ∈ L for all j ≥ 0, so L contains infinitely many non-primitive words.
- **Theorem 2 (PROVED).** The same conclusion holds for every language in the class FR, the closure of the finite languages under union, concatenation and "fixed-rate linear contexts". FR contains the fixed-rate metalinear languages and the finite-index (ultralinear) languages whose same-level rules have a fixed rate in each strongly connected component.
- **Corollary (PROVED).** Q is not in FR. In particular, Q is not a finite union of products of fixed-rate linear languages (for example, of even-linear languages). Every FR-language contained in Q has growth rate < 2, so its density decays exponentially.
- **Optimality (PROVED).** No fixed exponent k ≥ 2 is forced, even for regular languages: R_k = {w : |w|_a ≢ 0 mod k} has density (k−1)/k and contains no k-th power. In particular, positive density does not force a square. So "an arithmetic progression of exponents starting at 1" is the right form.
- **Entropy is not enough beyond FR (PROVED).** E' = {w : |w|_b = |w|_a + 1} is a deterministic one-counter (hence unambiguous) CFL. It has growth rate 2 and density 0, and it contains no non-primitive word. So for DCFL, unambiguous or one-counter CFLs, any proof of the density statement must use density itself, not just exponential growth.
- **General linear CFLs: OPEN.** We reduce it to a statement about mixed-rate strongly connected components (Sec. 6). No counterexample was found.

## 1. Definitions

Σ = {a,b}. Write L_n = L ∩ Σ^n.
- Upper density: δ̄(L) = limsup |L_n|/2^n.
- Growth rate: γ(L) = limsup |L_n|^{1/n} ∈ [0,2].
- δ̄(L) > 0 implies γ(L) = 2. The converse fails.

**Fixed-rate linear contexts.** Fix integers p, q ≥ 0 with p+q ≥ 1 and set Γ = Γ_{p,q} = Σ^p × Σ^q, so |Γ| = 2^{p+q}.
- Unfold map: for y = (u_1,v_1)…(u_t,v_t) ∈ Γ^t and a word c, put unf(y,c) = u_1 u_2 ⋯ u_t c v_t ⋯ v_2 v_1.
- For a regular R ⊆ Γ* and any language M, set Ctx_{p,q}(R, M) = { unf(y,c) : y ∈ R, c ∈ M }.

A **(p,q)-fixed-rate linear language** is a finite union of languages Ctx_{p,q}(R, {c}) with R regular and c a word. Equivalently, it is generated by a linear grammar with rules A → uBv (u ∈ Σ^p, v ∈ Σ^q) and A → c (c ∈ Σ*).

Proof of the equivalence (PROVED, standard). Read the rules A → uBv as an NFA over Γ with state set N and transitions A →(u,v)→ B. For each terminal rule B → c, let R_{B} be the set of pair sequences leading from S to B. Then L(G) = ⋃_{B→c} Ctx(R_B, {c}). The converse direction reverses the construction.

Special cases:
- (p,q) = (1,0): right-linear, that is, regular languages.
- (1,1): the even-linear languages (Amar–Putzolu; LITERATURE, standard).
- (1,2), (2,3), …: other fixed-rate languages, e.g. {x y : |y| = 2|x|, x_1 ≠ y_{|y|}}.

**Decoding (PROVED).** Fix c and t. The map Γ^t → Σ^{(p+q)t+|c|}, y ↦ unf(y,c), is injective. Its image is exactly the set of words of length n = (p+q)t+|c| that carry c at positions pt+1 … pt+|c|. The inverse is the fold:

  fold_c(w)_i = ( w[p(i−1)+1 .. pi] , w[n−qi+1 .. n−q(i−1)] ),  i = 1..t.

**Class FR.** FR is the smallest class of languages that
- contains all finite languages,
- is closed under ∪ and concatenation, and
- is closed under L ↦ Ctx_{p,q}(R, L) for every (p,q) and every regular R ⊆ Γ_{p,q}*.

FR contains all fixed-rate linear languages. It also contains all finite unions of products of fixed-rate linear languages ("fixed-rate metalinear"), where the rates may differ from factor to factor. Finally, it contains the languages of SCC-fixed-rate ultralinear grammars, defined as follows. Take a grammar in which every strongly connected component K of the nonterminal graph is linear. Each rule A → α with A ∈ K has at most one nonterminal of K in α. Every such rule that does contain one is of the form A → uBv with u ∈ Σ^{p_K}, v ∈ Σ^{q_K} (terminal, with a fixed rate (p_K,q_K) for the SCC K). Rules leaving K are arbitrary.

PROVED, by induction along the DAG of SCCs:
- L_A = ⋃ over exit rules B → α of Ctx_{p_K,q_K}(R_{A,B}, L(α)).
- R_{A,B} is the regular set of pair sequences of K-paths from A to B.
- L(α) is a product of single letters and languages L_C of lower SCCs, so it lies in FR by induction.

## 2. A monoid lemma

**Lemma M (PROVED; the standard fact behind it is LITERATURE, e.g. J.-E. Pin, *Mathematical Foundations of Automata Theory*, ch. on the minimal ideal, or Rhodes–Steinberg).** Let A be a complete DFA with state set Q, and let M be its transition monoid. Act on the right: q·w. Let r be the minimal rank |Q·w| over all words w, and put g = r!. Then there is a word κ with [κ] idempotent of rank r. Moreover, for every word Y and every j ≥ 0,

  [κ (Y κ)^{gj}] = [κ].

*Proof.*
1. Existence of κ. Pick w0 of rank r. Some power w0^h is idempotent, because M is finite. Since rank(w0^h) ≤ r and r is minimal, rank(w0^h) = r. Put κ = w0^h.
2. Put I = Q·κ, so |I| = r. Since κ is idempotent, κ acts as the identity on I.
3. Let f = [κ Y κ]. Then Q·f = ((Q·κ)·Y)·κ = (I·Y)·κ ⊆ I, and |Q·f| ≥ r by minimality, so Q·f = I.
4. Define φ: I → I by φ(s) = s·Y·κ. Its image is (I·Y)·κ = I, so φ is a permutation of I.
5. For every state s, s·f = (s·κ)·φ. Since φ maps into I, where κ acts as the identity, we get s·f^j = (s·κ)·φ^j.
6. The order of φ divides r! = g, so f^{gj} = [κ].
7. Finally κ (Yκ)^{m} = (κYκ)(κYκ)⋯ as transformations, because κκ = κ. Hence [κ(Yκ)^{gj}] = f^{gj} (read as [κ] when j = 0), which equals [κ]. ∎

**Lemma A (avoidance, PROVED).** Let κ ∈ Γ^ℓ. Then |{y ∈ Γ^t : κ is not a factor of y}| ≤ |Γ|^t (1 − |Γ|^{−ℓ})^{⌊t/ℓ⌋}.

*Proof.* Cut y into ⌊t/ℓ⌋ disjoint blocks of length ℓ. Each block must differ from κ, and the blocks are chosen independently. ∎

## 3. Theorem 1 (fixed-rate linear contexts)

**Theorem 1 (PROVED).** Let L = Ctx_{p,q}(R, M) with R ⊆ Γ* regular and M arbitrary. Let A be a complete DFA for R with initial state q0 and final states F, and let κ, g be as in Lemma M. Suppose some u0 = unf(y0, c) has c ∈ M and y0 ∈ R containing κ as a factor. Put D = (p+q)g. Then for every v ∈ Σ* and every j ≥ 0,

  u0 (v u0)^{Dj} ∈ L,  and in particular  u0^{Dj+1} ∈ L.

*Proof.*
1. Setup. Let t = |y0|. Then |u0| = (p+q)t + |c|. Put d = |v u0| ≥ |u0| ≥ t. Fix m = gj and set x = u0 (v u0)^{(p+q)m}, so |x| = n = (p+q)md + |u0|.
2. x has period d. This holds because x is a factor of (u0 v)^∞ that starts at a copy of u0.
3. Middle. We have n − |c| = (p+q)(md + t), so x has t' = md + t fold steps. Its middle positions are pt'+1 … pt'+|c|. Since pt' = pmd + pt ≡ pt (mod d), and pt + |c| ≤ |u0|, the period gives x[pt'+k] = x[pt+k] = u0[pt+k] = c_k. So x carries c in the middle, and fold_c(x) is defined.
4. Periodicity of the fold. Let Y_i = fold_c(x)_i. Replacing i by i+d shifts the left block by +pd and the right block by −qd. Both shifts are multiples of d, so by step 2, Y_{i+d} = Y_i whenever both are defined.
5. The first t steps. For i ≤ t, the left block lies in [1, pt] ⊆ the first copy of u0. The right block lies in [n−qt+1, n], and n − qt + 1 > n − |u0|, so it lies in the last copy of u0, at the same offsets as in u0. Hence Y_1…Y_t = fold_c(u0) = y0.
6. Shape of the fold. Write T = Y_1…Y_d = y0 X for some X ∈ Γ^{d−t}. By steps 4 and 5, fold_c(x) = T^m y0 = (y0 X)^m y0.
7. Run the DFA. Write y0 = P κ S. Then (y0 X)^m y0 = P κ (S X P κ)^m S. By Lemma M with Y = S X P, its transformation equals [P][κ][S] = [y0]. So q0·fold_c(x) = q0·y0 ∈ F, i.e. fold_c(x) ∈ R.
8. Conclusion. x = unf(fold_c(x), c) ∈ L. Taking v = ε gives u0^{1+Dj} ∈ L. ∎

COMPUTER-CHECKED. `scratchpad/scripts/density/check_thm1.py` draws random (p,q) ∈ {0,1,2}², random complete DFAs with 2–4 states, and random middle sets. It builds u0 exactly as in the proof and verifies membership of u0(vu0)^{Dj} for j = 0,1,2 and random v. It also checks the identity fold(x) = (y0X)^m y0. There were 507 non-degenerate trials (two seeds × 300 trials), all passed. Of the remaining trials, 18 had no κ-good word and 75 had empty final sets; both are expected.

**Corollary 1 (PROVED).** Let L be (p,q)-fixed-rate linear (a finite union of contexts Ctx(R_i, {c_i})) with γ(L) = 2, for instance with δ̄(L) > 0. Then the hypothesis of Theorem 1 holds for some i, so L contains u0^{Dj+1} for all j ≥ 0. Hence L contains infinitely many non-primitive words, assuming u0 ≠ ε, which can be arranged by choosing y0 long.

*Proof.*
1. Some i has γ(Ctx(R_i,{c_i})) = 2.
2. If no y ∈ R_i contained κ_i, then by decoding and Lemma A, |Ctx(R_i,{c_i})_n| ≤ |Γ|^t θ^{⌊t/ℓ⌋} with t = (n − |c_i|)/(p+q) and θ = 1 − |Γ|^{−ℓ} < 1.
3. So the growth rate would be ≤ 2·θ^{1/(ℓ(p+q))} < 2, a contradiction.
4. Taking y0 long, u0 is nonempty. ∎

Remarks.
- (p,q) = (1,0) recovers Sin'ya's regular theorem (z^{pn+1} ∈ R, arXiv:2008.01413) under the weaker hypothesis γ = 2.
- (1,1) gives the new statement for even-linear languages.

## 4. Theorem 2 (the class FR: fixed-rate metalinear / ultralinear)

Call L **pumpable** if there are u0 ∈ L and D ≥ 1 with u0 (v u0)^{Dj} ∈ L for all v ∈ Σ*, j ≥ 0.

**Theorem 2 (PROVED).** Every L ∈ FR with γ(L) = 2 is pumpable. In particular, every L ∈ FR with δ̄(L) > 0 contains u0^{Dj+1} for all j ≥ 0 (and u0 ≠ ε can be arranged).

*Proof.* The proof is by structural induction on the FR-expression. We use three facts.
- (F1) γ(L1 ∪ L2) = max(γ(L1), γ(L2)).
- (F2) If γ(A), γ(B) < 2, then γ(AB) < 2. Proof: pick β < 2 and C with |A_i|, |B_i| ≤ Cβ^i for all i. Then |(AB)_n| ≤ Σ_i |A_i||B_{n−i}| ≤ C²(n+1)β^n.
- (F3) Concatenation preserves pumpability. Suppose L' is pumpable via (u0, D), and let a ∈ A, b ∈ B be arbitrary words. Then A L' B is pumpable via (U = a u0 b, D). Indeed, for any v put v' = b v a. Then a·u0(v' u0)^{Dj}·b = U (v U)^{Dj}. This is a string identity; it is COMPUTER-CHECKED on 10^4 random instances in `check_examples.py`.

The cases:
- Finite L: γ = 0, so there is nothing to prove.
- L1 ∪ L2: by (F1) some Li has γ = 2. It is pumpable, and hence so is the union.
- L1 L2 with γ = 2: both factors are nonempty, and by (F2) one factor has γ = 2. It is pumpable by induction, and by (F3) so is L1 L2.
- L = Ctx_{p,q}(R, M) with γ(L) = 2:
  - Case (i): some unf(y0,c) ∈ L has y0 containing κ. Then Theorem 1 applies.
  - Case (ii): no such word exists. Then every y ∈ R avoids κ, and by Lemma A we get |L_n| ≤ Σ_t |Γ|^t θ^{⌊t/ℓ⌋} |M_{n−(p+q)t}|. If γ(M) < 2, this convolution has growth < 2, as in (F2), which is a contradiction. So γ(M) = 2, and M is pumpable by induction.
  - In case (ii), pick any y ∈ R (R ≠ ∅ since L ≠ ∅) and write ℓ, r for its left and right parts. Then L ⊇ ℓ M r, which is pumpable by (F3). So L is pumpable. ∎

**Corollary 2 (PROVED).** Let L ∈ FR with L ⊆ Q, where Q is the set of primitive words. Then γ(L) < 2, so |L_n| = O((2−ε)^n) and |L_n|/|Q_n| → 0 exponentially fast. In particular Q ∉ FR, since γ(Q) = 2 (indeed |Q_n| ≥ 2^n − 2^{n/2+1}).
- Hence Q is not a finite union of products of fixed-rate linear languages, e.g. of even-linear languages. Q is also not the language of any SCC-fixed-rate ultralinear grammar.
- Known before: Q is not linear (Horváth 1995, LITERATURE via scout.md). The scout found no result on Q and metalinear languages. The fixed-rate metalinear case is a new partial step. Novelty is CONJECTURED, since the literature was not checked beyond scout.md.

## 5. Optimality and limits

**O1: no fixed exponent is forced, not even squares (PROVED).** Fix k ≥ 2 and let R_k = {w : |w|_a ≢ 0 (mod k)}. It is regular and has density (k−1)/k > 0. If w = z^k then |w|_a = k|z|_a ≡ 0, so R_k contains no k-th power. (COMPUTER-CHECKED for n ≤ 18, k = 2..6, in `check_examples.py`.)

Consequences:
- Even for regular languages, positive density does not force squares, cubes, or any given exponent.
- The guaranteed object must be an arithmetic progression of exponents starting at 1 (Sin'ya's z^{pn+1}, our u0^{Dj+1}).

**O2: D cannot be bounded (PROVED).** Fix N ≥ 2 and let R'_N = {w : |w|_a ≡ 1 (mod N)}, of density 1/N. Then z^k ∈ R'_N forces k|z|_a ≡ 1 (mod N), so gcd(k,N) = 1. If R'_N ⊇ {u0^{Dj+1} : j ≥ 0}, then every prime ℓ | N divides D. Otherwise choose j with Dj+1 ≡ 0 (mod ℓ). So D must depend on L, with no uniform bound.

**O3: the "subtlety" asked about.** Is there a linear language of positive density with no non-primitive word?
- For fixed-rate linear languages, and all of FR: NO, by Theorem 2 (PROVED). This holds even under the weaker hypothesis γ = 2.
- For general linear languages: OPEN; see Sec. 6. We found no example, and every natural candidate tried reduces to Parikh-type counting. For instance, the mismatch parity #{i ≤ n/2 : w_i ≠ w_{n+1−i}} mod 2 equals |w|_a mod 2, which falls under O1.

**O4: growth rate 2 is not enough outside FR (PROVED).** Let E' = {w : |w|_b = |w|_a + 1}.
1. No non-primitive word: if w = z^k then 1 = |w|_b − |w|_a = k(|z|_b − |z|_a), so k = 1. (COMPUTER-CHECKED, n ≤ 18.)
2. Growth rate 2: |E'_n| = C(n,(n−1)/2) for odd n, which is ~ 2^n √(2/(πn)). So γ = 2 and δ̄ = 0. (Numerically, |E'_n|^{1/n} = 1.9990 at n = 10001.)
3. Class: E' is accepted by a deterministic one-counter automaton (the counter stores |#b − #a|, the state stores the sign), so it is a DCFL and hence unambiguous.
4. E' is not linear. Apply the linear pumping lemma to a^N b^{2N+1} a^N: the pumped parts lie in the two outer a-blocks.

Consequences:
- Theorem 2's hypothesis "γ = 2" cannot be used for DCFL, unambiguous or one-counter CFLs.
- Any density theorem for those classes must genuinely use density (polynomial-scale information), not entropy.
- This also shows E' ∉ FR. This is consistent with Theorem 2 and was not otherwise obvious.

## 6. General linear CFLs: reduction and obstacle

Put the grammar in normal form: A → xB, A → Bx, A → c with x ∈ Σ and c ∈ Σ ∪ {ε}.
- A derivation is a word over Δ = {L,R} × Σ, followed by one terminal rule. It is accepted by the NFA N whose states are the nonterminals.
- Let M be the monoid of Boolean transition matrices of N. M usually contains the zero matrix.
- Suppose u0 = ℓ c r is derived by ν ∈ Δ*. Here ν emits the left letters ℓ and the right letters, which spell r reversed.

**Lemma 6.1 (PROVED).** Suppose the following hold.
- ν = P κ S, where [κ] is an idempotent lying in a 0-minimal J-class of M (or in the minimal ideal, if M has no zero).
- For some v ∈ Σ*, there is a Δ-word X with two properties: its L-letters spell c r v, and its R-letters (in derivation order) spell (v ℓ c)^R.
- [κ S X P κ] ≠ 0.

Then u0 (v u0)^{2Nj} ∈ L(G) for all j ≥ 0, where N = |H_[κ]|.

*Proof.*
1. Put Π = νX. Then Π^m ν, followed by the terminal rule c, derives (u0 v)^m u0 (v u0)^m = u0 (v u0)^{2m}.
2. As relations, [Π^m ν] = [P](κSXPκ)^m[S], using κκ = κ.
3. y = κSXPκ lies in κMκ ∩ MκM. MκM is J ∪ {0}, and y ≠ 0, so y ∈ J ∩ κMκ = H_κ, a group. This step is LITERATURE (Pin, op. cit.: eMe ∩ J_e = H_e in a finite monoid).
4. Hence y^{N} = [κ], and [Π^{Nj} ν] = [ν], which is accepted. ∎

**Where it breaks.**
- In the fixed-rate case the pair-DFA is complete, so 0 never occurs. Lemma M then holds with X arbitrary.
- For a general linear grammar, the condition [κSXPκ] ≠ 0 asks for more. The grammar must be able to continue the derivation from the end of κ, through S, X and P, back into κ. This must happen with the prescribed letter content and some interleaving of left and right steps.
- If a strongly connected component has cycles of different rates |u|/|v|, the admissible interleavings depend on the letters. Positive density of L(G) does not obviously produce such a return path.
- We could not prove that it does, and we found no counterexample.

**Open Problem 6.2 (would settle linear, and then all finite-index CFLs).**
- Statement: if L is linear and δ̄(L) > 0 (or γ(L) = 2), then L is pumpable.
- What it would give: the proof of Theorem 2 uses only (F1)–(F3), pumpability, and the context case. So Problem 6.2 for linear contexts Ctx_G(M), with arbitrary linear "shells" around an arbitrary middle M, would make Theorem 2 hold for all finite-index (ultralinear) CFLs.
- Consequence: Q would then not be finite-index, which would be new.
- Caveat: for the γ = 2 version, a linear power-free language of growth rate 2 would refute it. E' is not linear (O4), so it is not such a language.
- Sufficient condition (CONJECTURED): every linear L with δ̄(L) > 0 contains an FR-sublanguage L' with γ(L') = 2.

**Remark 6.3 (CONJECTURED, sketch only).** The fixed-rate restriction can probably be relaxed to "bounded lag". This means each SCC has a constant λ = p/q and a potential function φ with |#L − λ#R| bounded along every path. A 2-head automaton with bounded lag can be simulated at rate (p,q) by buffering O(1) letters, which reduces this case to Theorem 2. Not written out in detail.
