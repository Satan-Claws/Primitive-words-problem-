# poly_S3P: where the p² in Theorem P / Cor F comes from, and a conditional Ω(log L / log log L)

Setting: poly_G4 (valid cover of NE_M, data ≤ K, ‖c_σ‖₁ ≤ C₁ ≤ nK, Lemma F, Cor F), poly_G3 §1 (Lemmas C, K, G),
poly_S2T §2, poly_S2L §3 (S2T′), poly_S3H §2 (Lemma H). On a face F_I, |I| = r = 2p−1, d := 2r, the restricted
cover is valid (Lemma F) and poly_P §3 gives qualitatively a set S of type-4 (full-dimensional) pieces,
|S| ≥ ⌈(r+1)/2⌉ = p, with C_S := ∩_{σ∈S} int A_σ ≠ ∅. Status: [written proof], unaudited.

## 1. Effective ply lemma with all constants separated (PROVED)
Parameters of S: h := max height (‖·‖_∞) of a primitive facet normal of A_σ, σ ∈ S; E_S := lcm over σ ∈ S of the
exponent of ℤ^d/ℤV_σ; s := max |V_σ| (≤ n+k); Δ₀ := (√d K)^d.

**Lemma D (effective Deep constant).** Let V ⊆ ℤ^d span ℝ^d, ‖v‖_∞ ≤ K, |V| = s, u_V := Σ_{v∈V} v,
Δ₁ := d(√dK)^{d−1}(dK + sKΔ₀). If x ∈ ℤV and x − Δ₁u_V ∈ cone V, then x ∈ ℕV.
*Proof.* y := x − Δ₁u_V ∈ cone V ∩ ℤV. Conic Carathéodory + extension inside V gives a basis B ⊆ V with
y = Σ_B μ_b b, μ ≥ 0. f := y − Σ_B ⌊μ_b⌋b ∈ ℤV, ‖f‖_∞ ≤ dK. G := ℤV/ℤB has order |det B| ≤ Δ₀ and is generated by
the classes [v], so [f] = Σ_V a_v[v] with 0 ≤ a_v < Δ₀; put ρ := Σ a_v v ∈ ℕV, ‖ρ‖_∞ ≤ sKΔ₀. Then f − ρ = Σ_B k_b b
with k = B⁻¹(f − ρ) ∈ ℤ^B, |k_b| ≤ d(√dK)^{d−1}‖f−ρ‖_∞ ≤ Δ₁ (adjugate/Hadamard, |det B| ≥ 1). Hence
x = Σ_B(⌊μ_b⌋ + k_b + Δ₁) b + Σ_{V∖B} Δ₁ v + ρ with all coefficients ≥ 0. ∎
So Deep costs only exp(O(d log dK))·s: it is **not** a p² source (Lemma K's K₀ made effective).

**Lemma P* (effective ply).** Some P has ply(P) ≥ |S| ≥ p and
  ‖P‖₁ ≤ d²·E_S·(√d h)^d · h·(C₁ + Δ₁sK) =: B*(S).
*Proof.* (i) Lemma H (poly_S3H) on the ≤ |S|·#facets normals of S, all of height ≤ h, with C_S ≠ ∅: there is
D ∈ ℤ^d with ν(D) ≥ 1 for every facet ν of every A_σ, σ ∈ S, and ‖D‖_∞ ≤ d(√d h)^d (count-free).
(ii) t := E_S·⌈dh(C₁ + Δ₁sK)⌉, P := tD. Lattice: E_Sℤ^d ⊆ ℤV_σ and c_σ ∈ ℤV_σ (Lemma C), so P − c_σ ∈ ℤV_σ.
Depth: for every facet ν of A_σ, ν(P − c_σ − Δ₁u_{V_σ}) ≥ t − dh(C₁ + Δ₁sK) ≥ 0, so P − c_σ − Δ₁u_{V_σ} ∈ A_σ and
Lemma D gives P − c_σ ∈ ℕV_σ, i.e. P ∈ L_σ for all σ ∈ S (Lemma G). ‖P‖₁ ≤ d·t·‖D‖_∞ ≤ B*(S). ∎
With Lemma F (pad by ones on the other M − r pairs): ply ≥ p at norm ≤ B*(S) + 2(M − r).

## 2. Where p² comes from (exact accounting)
With r = 2p − 1, d = Θ(p), C₁ ≤ 2mK, s ≤ n + k:
| term | unconditional bound | contribution to log B* |
|---|---|---|
| c_σ (Lemma S) | C₁ ≤ nK | O(log m) — additive |
| genericity count N | absent (Lemma H) | 0 |
| Deep (Lemma D) | Δ₁ s ≤ exp(O(p log pK))·m | O(p log pK) |
| depth (√d h)^d, h ≤ (√dK)^{d−1} (Cramer; Lemma T: K^{|C₀|}, chain attains 2^{Θ(p)}) | K^{O(p²)} | **O(p² log pK)** |
| lattice E_S = lcm of ≥ p exponents, each ≤ Δ₀ = K^{O(p)} | K^{O(p²)} | **O(p² log pK)** |
So the answer to "Lemma H + Lemma S + Lemma F ⇒ exp(O(p log pK))?" is **NO as stated**: Lemma H removes the count N
but not the height, and it is applied with h = K^{Θ(p)} in dimension Θ(p); independently, the joint lattice of p
pieces can need the lcm of p exponents of size K^{Θ(p)}. Each alone gives exp(Θ(p² log K)) in this method. Neither
is shown to be *forced* by a valid cover (no example of compounding heights across pieces of S, or of p pieces with
pairwise coprime quotient exponents K^{Θ(p)} sharing a type-4 ray, is known): that is the residue (OPEN), i.e.
G3** terms (2) μ(Λ_S) and (3) θ_S at component size Θ(p) — the apex term (1) and N are not the problem.
(Remark: poly_G3 §1(ii) states θ_S ≥ K^{−O(n)}; Lemma H with h = K^{O(n)} only gives K^{−O(n²)}. The p² of
Theorem E is carried by μ(Λ_S) there in any case; the θ_S claim is not used below.)

## 3. Conditional improvement (PROVED)
**Theorem P′.** Let G be cycle-free, L(G) = Q, polynomially ambiguous (else A_G = 2^{Θ(L)}). Suppose there are
constants a, b (depending on G) such that for every p and m = 2p, the R_m-cover has a face F_I, |I| = 2p−1, whose
forced set S satisfies (H′) h ≤ (pK)^{a} and (E′) E_S ≤ exp(b·p log pK). Then A_G(L) = Ω(log L / log log L).
In particular this holds if (H_g) all facet heights ≤ g and (E_g) all quotient exponents ≤ g for a constant g
(then E_S ≤ lcm(1..g) ≤ e^{1.04g}, independent of |S|; poly_S2T §2 note).
*Proof.* Lemma P*: log B* ≤ log(d²) + log E_S + d log(√d h) + log h + log(C₁ + Δ₁sK)
= O(p log pK) + O(p log pK) + O(p log pK) + O(log m) = O(p log p) (K fixed). Padding adds 2(M − r) ≤ 2m = 4p.
So some w ∈ Q ∩ R_{2p} has amb(w) = f(P) ≥ p and |w| ≤ L_p := exp(O(p log p)) (norm ≈ length, poly_T2b; skeleton
offsets add O(m)). Given L, take the largest p with L_p ≤ L: p = Ω(log L / log log L). ∎
**Tightness of the method under (H_g).** Lemma H is sharp up to the d log d: the laminar chain {e_1, e_i + 2e_{i+1}}
(h = 2, realizable, poly_R3a) forces x_d ≥ 2^{d−1} in its interior, so bounded heights alone cannot give better
than length exp(Ω(p)) for ply p, i.e. this route cannot beat A_G(L) = Ω(log L). The polynomial S2T′ bound needs the product
(c-local) structure, which is not forceable (poly_S2L §2 star cover); S2T′ without product structure is exactly
Lemma P* with h = g, giving exp(O(p log pg)), not poly.
