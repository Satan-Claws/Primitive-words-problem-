## 1. builder2.md

**Lemma O.** D_{i+d} = x_{i+d} − x_{c−i−d} = x_i − x_{c−i}, because x is σ_d-invariant. So every level set is a union
of σ_d-orbits, each of size K/gcd(K,d) > 1. Correct for any c.

**Cor. G.** I checked the points the brief asked about.
- **Pairs or positions.** m_c = #{i : D_i = +1}. Each mismatched pair contributes exactly one +1, so m_c counts both
  the +1 positions and the mismatched pairs.
- **Axis positions.** Positions on the axis have D = 0 and do not affect m_c. So both axis types (vertex or edge)
  are fine.
- **Even n, d = n/2.** Here p = 2. Orbits {i, i+n/2} have size 2, so 2 | m_c and 2 | n.
- **Equivalence.** gcd(m, n−2m) = gcd(m, n), so the two coprimality conditions agree.

**Cor. RG.** A non-unary power u^p has a cyclic run sequence equal to p copies of the cyclic runs of u, so it is
σ_{K/p}-invariant. Even c keeps parity. Correct.

**GB and RGB are CF.**
- A nested fold grammar keeps m capped and r mod lcm(1..B), or the reverse, in finite control.
- At run level, write the linear word as R_{f1} [R_{f1+1} … R_{f2} … R_{f1−1}]. The pairs j ↔ K−j are nested
  around R_{f2}.
- Run maximality is enforced by letter alternation.

**RD is sound and CF.**
- Lemma D applies on Z_K with H the half-arc of size K/2−1. A proper period d < K/2 satisfies d ≤ K/3 ≤ K/2−1 for
  K ≥ 6. For d = K/2, rotate to c = 0 and use the special case. K = 4 is handled the same way, and K = 2 gives an
  empty H.
- CF: {a^x M a^y : y ≥ x} is generated by A → aAa | Aa | aMa, plus a strictness flag.
- Both sides of the axis are reached by rotating the start to the other fixed run.

**Lemma S.** If two periods are linearly independent, the mod-q argument gives a point with both coordinates
divisible by q. A zero coordinate also gives gcd ≥ q. So all periods of a linear set inside Cop are collinear, and
since they are nonzero vectors of N², such a set meets each antidiagonal at most once. The statement "exactly one
period" should read "collinear periods"; the conclusion is unaffected.

**Prop. N: GAP (repairable).**
- **Failing inference.** "G_0 ∩ b*a* ∩ {j ≤ k} would be a bounded CFL." The set {j ≤ k} is not regular, which is a
  trap listed in the briefing.
- **Repair 1.** For j > k the central fold gives m = k, so in general m = min(j, k) and gcd(m, n) = gcd(j, k).
  Hence G_0 ∩ b*a* = {b^j a^k : gcd(j, k) = 1} with no order restriction. Its Parikh set meets j + k = N in φ(N)
  points, and Lemma S applies directly.
- **Repair 2.** Alternatively, intersect the semilinear Parikh set with the semilinear set {j ≤ k}.

## 2. cl1.md, section CL3

**Theorem 5: CONFIRMED.**
- **Fixed classes.** For ℓ odd, R(i) = K−1−i fixes exactly the class (ℓ−1)/2. For ℓ even, R(i) = K−2−i fixes exactly
  the classes ℓ/2−1 and ℓ−1.
- **R(f) ≠ f.** R(f) = f would force K = ℓ, which K ≥ 2ℓ excludes. This holds even when K is odd: the fixed point
  (K−1)/2 lies in class f but is not f.
- **Case ℓ | d.** D_{f+d} = 1 contradicts the exact condition on class f.
- **Case ℓ ∤ d.** The class f+d carries both +1 and −1. It is either g, where D ≡ 0, or a single-signed class.
  These are the only possibilities, because f and g are the only fixed classes.
- **CF grammar.** a^P b [inner] a^Q b is generated by Pair → U b, U → aUa | aU | b·inner (for P > Q), with i mod ℓ
  and a capped flag in finite control.

**Theorem 6: CONFIRMED.** A rotation of c^k + e_j by j − f gives c′^k + e_f. On class f the c-parts cancel because
R preserves the class, on g they also cancel, and on a swapped class D is the constant c_A − c_B.

**Prop. 7: CONFIRMED.**
- In class f, K/ℓ − 4 positions need c-equality.
- Distinct lengths force 2i ≡ s (mod ℓ′), which has ≤ 2 solutions mod ℓ′, hence ≤ 4 solutions in Z_{2ℓ′}.
- So 2ℓ′/ℓ ≤ 8.

## 3. f2.md

**Theorem 1: CONFIRMED, with one mis-worded case.**
- **Case d mod k ≠ 0.** σ_{3d} shifts the P-sequence by d mod k, which is nonzero. The steps e = 1 and
  P_1 = P_{e+1} = P_{k−e} = P_k are correct (k ≥ 2e ⇒ e+1 ≤ k−1).
- **Case d ∈ {k, 2k}, 3 | k.** The report says "covered by the first case". Literally that is false: there
  d mod k = 0, so σ_{3d} gives the zero shift. The correct argument is that σ_d itself shifts P by d/3 ∈ {k/3, 2k/3},
  which is nonzero, and the first-case argument then applies. The conclusion stands.
- **Case 3 ∤ k (the brief's focus).** k ≢ 0 (mod 3), so j, j+k, j+2k cover all three residues mod 3. Every orbit of
  ⟨d⟩ = kZ_{3k} therefore contains a marker. Hence x ≡ 1, so P_1 = P_k: contradiction. Correct.
- **Grammar.** S = a·a^t·N·a^t·Y gives P_1 = t+1 and P_k = t. The inner B gives the palindrome, and C gives the free
  middle P-block when k is odd. The derivation matches the stated set.

**Theorem 2 (proof part): CONFIRMED.**
- If lcm(g, ℓ) < K, there is a nonzero block shift on y.
- Otherwise t = gcd(g, ℓ) < ℓ, and the orbit of ℓi meets the classes tZ_ℓ ⊇ (ℓ/r)Z_ℓ, which contain a marker. So y
  is constant.
- I did not rerun the "sharp" (exact) computation.

**Lemma 3: CONFIRMED** for chords of one linear sequence; equal left endpoints are excluded.
- The example, P_i ↔ P_{k+1−i} with Q_i ↔ Q_{k−i}, is not literally an instance of Lemma 3. At block level its axes
  are 3k−1 and 3k−3, which differ by 2, and axes that differ by 2 can cross (when α = α′+1).
- Crossing is impossible here because P ≡ 1 and Q ≡ 2 (mod 3). The conclusion is true.

**Lemma W: CONFIRMED.** I checked each step.
- L = M(k−1)/2 + e ≡ e (mod M), and L ≥ M because k ≥ 3.
- r ↦ r+e is a single M-cycle.
- Each adjacency is joined by a 2-edge path, and each edge is used at most twice.

**Corollary W′: GAP (repairable).**
- **Failing inference.** Step 1 says "u = w[1..L] has period M". This needs the first copy to be intact. For a
  window in the first copy, use w[L+1..2L] instead, which is fine. For a window straddling the middle, neither copy is
  intact.
- **Repair.** Each half has an M-periodic part of length ≥ L − m, and the two parts overlap in L − m positions. If
  L − m ≥ M, u is M-periodic and the proof goes through.
- **When the overlap is short.** L − m < M forces m > M(k−3)/2 + e, which is above M/2.
- **Statement with the standard convention, |u| counts as a period.** (ii) forces m < L/(2λ). With λ ≥ 2 this
  contradicts m > M/2 for k = 3, and m > kM/5 for k ≥ 5.
- **Statement if only periods < |u| count.** It is false for m ≥ n: replace the whole word.
- **Barrier consequence.** Unaffected, since λ = 3 log n and m ≤ n/(8λ).

## 4. r6.md

**Setup.**
- Markers: every segment of a(ab⁺)⁺ starts with "aa", and the preceding segment ends in b, so there are exactly 6
  cyclic markers.
- Powers: k·c(root) = 6, so k ∈ {2, 3, 6}.
- Rotations: Cyc(P) ∩ R6 consists of segment rotations. Correct.

**(N) is CF and non-crossing: CONFIRMED.**
- **Arcs are length-only.** A → σAσ matches lengths and compares no letters. t need not be the first mismatch, so no
  copy constraint arises.
- **N(S,+2).** In the order S+3, S+4, S+5, S, S+1, S+2:
  - arc A runs from the start of the word to z_S[t];
  - then come the letters z_S[t..s];
  - arc B runs from after z_S[s] to the end of z_{S+2}.
  The arcs are disjoint exactly because t ≤ s.
- **N(S,−2).** The mirror case, in the order S+4, S+5, S, S+1, S+2, S+3.
- **Segment boundaries.** They are enforced by generating marked words, intersecting with a regular marked-R6 set, and
  erasing the marks.
- **Soundness.** The length-mismatch sentinels (|X| in StartMis, |S|−|X|−1 in EndMis) are sound.

**(C): GAP (literature).**
- C is the inverse image of K6 under a rational transduction, which is fine provided K6 = Q ∩ (ab*)^6 is CF.
- **What I could verify.** I fetched Kászonyi, Publ. Math. Debrecen 77 (2010) 313–330. Its Theorem 1 (Kászonyi–Katsura)
  is: "Let n = p1^f1 ⋯ pk^fk … Assume Σ 1/p_i < 4/5. Then Q ∩ (ab*)^n is context-free." For n = 6,
  1/2 + 1/3 = 5/6 > 4/5, so **this verified statement does not cover n = 6**.
- **What remains unverified.** The n = p^r q^s theorem of Dömösi–Horváth–Ito–Kászonyi–Katsura (FCT'93, LNCS 710,
  194–203) is attested only by OCR and abstract snippets (scout.md). Their 1999 abstract says "proved … n is a product
  of two prime-powers". It is plausible, but I could not see its exact statement.
- **Direct proof does not obviously work.** As r6 §2 shows, disjoint square/cube chords always cross, and a
  shared-vertex unary condition such as r < p < q is not CF. So a direct proof for n = 6 is not immediate.
- **Effect.** The reduction is "Cover Lemma + DHIKK(n = 6) ⇒ Q ∩ R6 CF".

- A cube pair {S, S+2} then has offsets in [0,T) ∩ (T,n) = ∅. So w is a cube, a contradiction.
