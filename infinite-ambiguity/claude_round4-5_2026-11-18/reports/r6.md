# Agent r6: is Q ∩ R6 context-free? (R6 = (a(ab⁺)⁺)⁶)

**Claim status: no proof of either resolution.** The evidence points to **Q ∩ R6 being CF**, which would push
the "two primes" barrier of uniform.md one step further, to slices needing three primes or more.
I prove a reduction: Q ∩ R6 is CF if a purely combinatorial Cover Lemma holds. I prove the lemma when all
six segments have equal length, and I checked it exhaustively by computer in small cases.
Scripts: `infinite-ambiguity/claude_round4-5_2026-11-18/scripts/r6/` (`cover.py`, `cover3.py`/`cover3lib.py`, `exhaust.py`/`exhaust_lib.py`,
`realcheck.py`). Each run takes ≤ 10 min on one core.

## 0. Setup (PROVED; identity confirmed by the audit)
w = z1⋯z6 ∈ R6, where each z_i ∈ a(ab⁺)⁺ is located by the cyclic `aa` markers.
- w is a square iff z_i = z_{i+3} for all i.
- w is a cube iff z1 = z3 = z5 and z2 = z4 = z6.
- A root must start at a marker, because the cyclic marker count is 6 = k·c(root).

Two facts I use:
- Q ∩ R6 is closed under **segment rotation**.
- For a CF language P, Cyc(P) ∩ R6 is CF (cyclic closure keeps a language CF). It equals the set of segment rotations of P ∩ R6.

Indices are taken mod 6.

## 1. Two certificate families, each CF

**(C) Commutative certificate.** Let β(w) = (|z_i|_b)_i and α(w) = (|z_i|_a)_i. If β(w) or α(w) is neither
3-shift- nor 2-shift-periodic, then w is primitive. This holds because any well-defined segment feature is
periodic on a square or a cube. The language
C = {w ∈ R6 : β(w) ∉ V2∪V3 or α(w) ∉ V2∪V3} is built as follows:
- K6 = {#1^{x1}⋯#1^{x6} : x ∈ N⁶ not 2- or 3-shift-periodic}. This is a renaming of Q ∩ (ab*)⁶ (bounded.md L2).
- C is the preimage of K6 under a rational transduction (mark the `aa` boundaries, erase a, map b ↦ 1; similarly for α), intersected with R6.

K6 is CF by LITERATURE: Kászonyi–Katsura give n = p^r q^s, so n = 6 is covered. I took this from repo snippets and did not re-verify it.
So C is CF. In particular C contains every w whose length vector is not in V2+V3.

**(N) Nested two-arc certificate.** For segments S, X define:
- StartMis(S,X) = {t < min(|S|,|X|) : S[t] ≠ X[t]}, plus the value |X| when |X| < |S|.
- EndMis(S,X) = {t : S[t] ≠ X[t+|X|−|S|]}, plus the value |S|−|X|−1 when |X| < |S|.

Pattern N(S,+2) holds if there are t ∈ StartMis(z_S, z_{S+3}) and s ∈ EndMis(z_S, z_{S+2}) with t ≤ s.
Pattern N(S,−2) holds if there are s ∈ StartMis(z_S, z_{S−2}) and t ∈ EndMis(z_S, z_{S+3}) with s ≤ t.

Each pattern certifies z_S ≠ z_{S+3} (so w is not a square) and z_S ≠ z_{S±2} (so w is not a cube).

Why each pattern language is CF (PROVED, construction):
- Rotate so that the segments read (S+3)(S+4)(S+5) S (S+1)(S+2). Then the square arc pairs the prefix (S+3)[0,t) with the prefix S[0,t).
- A → σAσ | c·(stuff) generates this arc, with c ≠ S[t] remembered in the nonterminal.
- After it comes S[t..s], then a second arc B → σBσ | (stuff)·d pairs the suffix S(s,end] with the end of z_{S+2}, with d ≠ S[s].
- The two arcs are sequential, so they do not cross. The length variants pair a whole segment with a prefix or suffix of the other segment.
- Intersect with the regular set that fixes where the markers fall, then apply Cyc(·) ∩ R6.

## 2. The configurational fact behind (N) (PROVED)
A square pair {i,i+3} and a cube pair {j,j±2} that share no segment always **cross** as chords of the hexagon, so in every linear cut they cross.
Every non-cube word has a cube defect that shares a segment S with a chosen square defect: the possible pairs are (1,3), (1,5), (2,4), (4,6) relative to the defect pair (1,4).
For a shared S, all three linear arrangements need the same thing: with partner S+2, the square arc must be start-aligned in S and lie left of the end-aligned cube arc. Partner S−2 is the mirror case.
This explains why only N(S,±2) appears.

## 3. Reduction (PROVED)
**Cover Lemma (CONJECTURED in general).** Every primitive w ∈ R6 is in C or satisfies some N(S,±2).
If the Cover Lemma holds, then Q ∩ R6 = C ∪ ⋃_S Cyc(N(S,±2)) ∩ R6 is **context-free**:
- every piece is sound;
- C is CF modulo LITERATURE (K6);
- the N-pieces are CF by §1.

**Lemma 3.1 (PROVED): the Cover Lemma holds whenever |z_1| = ⋯ = |z_6|.**
With equal lengths, start alignment and end alignment agree. Suppose no N(S,±2) holds.
1. Let T be the least column offset with z_S[T] ≠ z_{S+3}[T] for some S0.
2. Since no N pattern holds, every offset in D(S,S+2) is less than min Dsq(S), and every offset in D(S,S−2) is greater than max Dsq(S). Applied to S0 and S0+3, this gives z_{S0}[T] = z_{S0±2}[T] and z_{S0+3}[T] = z_{S0+3±2}[T].
3. So column T is (x,y,x,y,x,y) with x ≠ y. Hence T = min Dsq(S) for **every** S.
4. Fix a cube pair {S,S+2}. Seen from S, its offsets lie in [0,T). Seen from S+2, where it is the −2 pair, they lie in (T,n). So the pair has no offsets: z_S = z_{S+2}.
5. This holds for every cube pair, so w is a cube. Contradiction. ∎

**Computer evidence for the general Cover Lemma (COMPUTER-CHECKED, slack 0, i.e. t ≤ s exactly):**
- Abstract segments over {0,1}, all 6-tuples of nonempty words of length ≤ 5 whose two count vectors are both periodic (all others lie in C): 49 332 000 primitive tuples checked, **0 uncovered** (`exhaust.py 5 0`; L ≤ 4 also 0).
- Real R6 words: all 26 900 words of length ≤ 26. Primitive ⇔ (C or N) holds, with **0 mismatches** (`realcheck.py 26`).
- Without (C), unary-like families such as (0,00,00,00,0,000) are not covered (`cover.py`). These are Kászonyi–Katsura-type points that need "rigid" certificates, and (C) supplies those.

## 4. Direction (B), non-CF
- Every bounded sub-slice of R6 (a fixed block pattern per segment) is a face of some E_n whose only periods are 2- and 3-type. Ginsburg gives no obstruction there unless KK fails.
- Single-defect words v′v⁵ admit harmless pumps in segments 2, 3, 5, 6 (PROVED: changing one segment j ∉ {1,4} keeps the word primitive). So an Ogden argument would need marks forcing pumps into z1/z4, and the KK coverer (a+1,a,b,b,c,c) defeats it on the unary-like words.

I found no non-CF candidate. §3 makes one unlikely.
