### Inferences
Recommended title: **Primitive Words Have No Finitely Ambiguous Context-Free Grammar**. Recommended theorem: “For every context-free grammar G with L(G)=Q and every k in N, some word w in Q has more than k derivation trees in G.” If arbitrary grammars are allowed, interpret ambiguity in N union {infinity}. Alternatively state for cycle-free grammars, then give the unrestricted corollary. A uniformly bounded grammar can first be trimmed; a useful derivation cycle A =>+ A would give infinitely many trees of a terminal word by iteration, so the trimmed grammar is cycle-free. This removes the cycle-free hypothesis in the paper without asserting that an arbitrary untrimmed bounded grammar is cycle-free.

Safe consequence: **If Q is context-free, then it is inherently infinitely ambiguous.** This conditional avoids asserting context-freeness. Avoid the unqualified sentence “Q is inherently infinitely ambiguous,” because some conventions reserve inherent ambiguity for context-free languages.

A clean manuscript proof can consist of the following fully justified lemmas.

1. **Marked-square slice.** Put R_M = a(ab^+)^M a(ab^+)^M and encode a word by (x,y) in N_{>0}^{2M}. It is primitive exactly when x != y. A proper power must preserve the cyclic exponent vector of length 2M+2. Exactly two coordinates are zero, so the shift induced by one root maps one zero to the other and has length M+1. Hence the word is a square with equal halves. Conversely equal halves give a square. The word starts with a, so each copy of a root starts at an a-boundary; this detail justifies using exponent rotations.

2. **Ambiguity-preserving reductions.** Remove useless symbols; remove epsilon rules using a fixed original rule and fixed nullable derivation trees for each surviving rule; expand a new parse to an old parse, and recover the new parse by deleting empty-yield subtrees. Remove unit rules by fixed unit paths and recover by contracting maximal unit chains. Binarize using fresh symbols dedicated to individual rules and positions. Each step injects new parses into old parses; language is preserved away from epsilon. A complete DFA product gives exactly one state annotation for each old parse whose yield is accepted. Use both the slice DFA and the block-count DFA D_n, or explicitly their product. D_n states count a's, and b loops preserve the state. Trim the product.

3. **Multiplicity structure theorem.** For a uniformly finitely ambiguous reduced CNF grammar inside (ab*)^n, its parse multiplicity is a finite sum of characteristic functions of simple linear sets c+sum_j N v_j, with nonzero linearly independent nonnegative integer periods, each supported on <=2 coordinates, and pairwise noncrossing supports within each set.
   - In an SCC, a rule cannot have two children in the same SCC. Otherwise construct a two-hole return context. If its material or a terminal yield of the recurring nonterminal contains a, pumping violates the fixed number of a's. Otherwise every binary arrangement of r copies has identical unary yield, and Catalan-many distinct trees contradict bounded ambiguity. Distinct arrangements really are distinct: at their first different hole, a base tree and a context-filled tree have different yield lengths, because CNF yields are nonempty.
   - Every side child on a return path has unary b-yield, again by pumping a-count. All nodes in the SCC share D_n endpoints (s,t); left and right side yields live in blocks s and t.
   - Each nonterminal has exactly one first-return tree context. Two different ones can be concatenated in any sequence of N choices 12 or 21, producing 2^N distinct parses with the same b-counts. The first-return decomposition on the unique SCC path recovers the sequence. It follows that an SCC is a deterministic ring and every side child has exactly one derivation tree over its entire language. For each rule with an SCC child, obtain a first-return context by following a shortest return path; this proves uniqueness applies to every such rule.
   - A side tree contains no node from any cyclic SCC: one ring turn there would give a second tree. Delete complete ring turns from each maximal SCC path. The remaining skeleton has no repeated nonterminal along a root-to-leaf path, so finitely many skeletons exist. The original tree is uniquely reconstructed by the skeleton and a nonnegative number of turns for each cyclic path. Period vectors are the b-counts of ring turns.
   - A rational dependence of period vectors gives distinct q,q' in N^r with equal sums. The K+1 distinct vectors jq+(K-j)q' have the same yield, contradicting bounded ambiguity. Rational dependence follows from real dependence because periods are integer vectors. Thus periods are independent.
   - Cyclic paths are nested through exit subtrees or disjoint. They cannot lie in side subtrees, so their block intervals cannot cross. If s=0, discard that endpoint (no b is read in state 0). Passing from pairs to supports and deleting zero coordinates preserves noncrossing.

4. **Noncrossing rank lemma.** Let W={(u,u)} in R^{2M}. If nonnegative vectors of support size <=2 have noncrossing supports and span W, their span has dimension >=2M-1. Build the support graph. In each component C, spanning-tree edge vectors are independent by deleting leaves, so rank >=|C|-1. A component with rank |C|-1 has a one-dimensional annihilator whose nonzero coordinates propagate across edges; a loop would force that annihilator to vanish. Hence it contains no individual coordinate vector. Projection of e_i+e_{M+i} onto components implies each non-full component is a union of matched pairs. Distinct components cannot interleave: an edge of a path spanning a vertex of the other component traps the whole other component inside its interval, and reversing the argument gives an impossible nested trap. Two matched pairs from different components would interleave. Therefore at most one component is non-full, proving the bound. This is the key new geometric restriction; a diagram of crossing matched pairs versus noncrossing support edges would help.

5. **Near-diagonal half-space lemma and lower bound.** Apply the structure theorem to Q intersect R_M; each linear set avoids the diagonal. Choose a positive integral direction omega outside all boundaries of the cones {u:(u,u) belongs to cone(V)}. Choose a common integer scale F divisible by each lattice saturation index, and larger than all relevant translated-hyperplane constants and determinant-denominator thresholds. Examine P(t,delta)=(t omega,t omega+F delta), with t a positive multiple of F.
   - If a cone misses (omega,omega), it eventually misses P(t,delta), for every fixed finite set of deltas, by closedness and division by t.
   - Otherwise W lies in span(V). Every coefficient functional either vanishes on W or is positive at (omega,omega). The periods corresponding to the positive functionals still span W. The rank lemma implies there are at least 2M-1 of them, leaving at most one zero functional.
   - If rank is 2M-1, choose an integral annihilator lambda. A point in F Z^{2M} in the translated span forces lambda(c) divisible by F; choosing F>|lambda(c)| forces lambda(c)=0. Saturating the lattice then places a sufficiently large diagonal point in the linear set, contradiction. Full rank with no zero functional yields the same diagonal contradiction.
   - The only surviving case has full rank and one coefficient functional n_* vanishing on W. Its eventual membership condition is F psi(delta)>=gamma, where psi(delta)=n_*(0,delta) is nonzero rational and gamma=n_*(c)>0. The scale eliminates the translation: because psi(Z^M) lies in (1/D)Z and F/D>gamma, the condition is exactly psi(delta)>0. The other coefficients are eventually positive. Sets with no F-grid point contribute nothing; one grid point is sufficient to guarantee the lattice condition for all grid points in the affine span.
   - Thus the asymptotic multiplicity is a finite list of rational open half-spaces through zero, covering every nonzero integral delta. Their common nonpositive cone contains no nonzero integral point; rationality gives that this cone is {0}. At least M+1 forms are required: fewer than M have a common nonzero kernel, while M independent forms allow a vector with all values negative. Choose integral delta outside all their kernels. The numbers of positive forms at delta and -delta sum to the number of forms, at least M+1. One multiplicity is >=ceil((M+1)/2).
   - Set M=2k (k>=1) for a contradiction to k-ambiguity. The case k=0 is excluded because a is primitive. The existing Lean assembly chooses the looser M=2k+2; do not imply that its exact witness parameter matches the written proof's M=2k.

The lattice scale is essential; omitting it makes the half-space claim false because congruence classes can survive. The order of choices must be omega, F, then the finite perturbation window, then t. These are proof-critical details, not exposition that can safely be dropped.
