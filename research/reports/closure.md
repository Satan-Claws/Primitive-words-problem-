# Agent "closure": closure-property attack on "Q is not context-free"

**Claim type: (ii) a BARRIER theorem (plus small side results). No proof of the conjecture is claimed.**

Status tags: **PROVED** = full proof written below (by this agent, not independently refereed);
**CHECKED** = computer-checked, script named; **LIT** = standard literature fact; **CONJ** = conjectured.

Scripts: `scripts/closure/swap_lemma_check.py`, `bounded_rigidity_check.py`, `transducer_images.py`, `qq_check.py`.

## 0. Summary

* **Theorem B (Parikh barrier) — PROVED.** For every rational transduction τ, the Parikh image
  Ψ(τ(Q)) is semilinear. Equivalently: for every regular P ⊆ C\* and every morphism h : C\* → A\*,
  Ψ(P ∩ h⁻¹(Q)) is semilinear. (Any finite alphabet A.) So the whole full trio M(Q) generated by Q
  consists of languages with semilinear Parikh image, and the "find a transduction with a
  non-semilinear image" plan (item (3) of my brief) **cannot work**.
* **Theorem C (complete Parikh barrier) — PROVED.** Let 𝒯 be the class of languages all of whose
  rational images have semilinear Parikh image. 𝒯 contains Q and all CFLs and is closed under rational
  transductions (so: ∩ regular, morphisms, inverse morphisms, gsm maps, quotient by regular sets,
  shuffle with regular sets), union, concatenation, Kleene star, substitution, reversal and Cyc.
  So no composition of the standard CF-preserving operations, applied to Q and CFLs, ever produces a
  language with non-semilinear Parikh image. M(Q) itself is closed under union, reversal and Cyc.
* **Proposition P (pumping barrier) — PROVED.** Every infinite language in M(Q) contains an infinite
  regular set u v^{≥k} w (v ≠ ε). Hence {aⁿbⁿ} ∉ M(Q), {aⁿbⁿcⁿ} ∉ M(Q): Q-images can never *force* an
  equality, and "no infinite regular/CF subset" arguments cannot work either. (If Q is CF it is a
  non-generator of the CFL family.)
* **Consequences — PROVED.** No language with non-semilinear Parikh image is obtainable from Q by
  these operations: not {aⁿbᵐ : gcd(n,m)=1}, not {aᵖ : p prime}, not {aⁿ : n squarefree}, not {a^{n²}}.
  Every unary language obtainable this way is regular. Every bounded language in M(Q) ⊆ c₁\*…c_k\*
  has a semilinear exponent set.
* **Tools — PROVED**, reusable by other agents:
  Lemma W (swap lemma), Lemma OB, Lemma I (for any words xᵢ,yᵢ the set of exponent vectors e with
  x₀y₁^{e₁}x₁…y_r^{e_r}x_r non-primitive is semilinear, with an explicit description in the "rigid" case),
  Lemma RC (regular subsets of co-Q).
* **What survives of the closure route:** only obstructions finer than Parikh, i.e. Ginsburg
  stratification of *bounded* members of M(Q) (this is exactly the Kászonyi–Katsura question and its
  generalisations) or Ogden/interchange arguments on unbounded members. See §7.

## 1. Framework

A = {a,b} (nothing below uses |A| = 2). Q = primitive words, co-Q = A\* \ Q = {ε} ∪ {uᵏ : k ≥ 2}.
Ψ = Parikh map. "Semilinear" = Presburger-definable (Ginsburg–Spanier, LIT); semilinear sets are closed
under Boolean operations, projections, linear images and preimages under affine maps (LIT).

LIT facts used:
* (FW) Fine–Wilf: periods p,q and length ≥ p+q−gcd(p,q) ⇒ period gcd(p,q).
* (CJ) primitivity is invariant under conjugation; a primitive word of length n has n distinct conjugates.
* (CM) uv = vu ⇒ u,v are powers of a common word; if ρ is the primitive root of v ≠ ε then u ∈ ρ\*.
* (OV) if two intervals of a word both have period p and overlap in ≥ p positions, their union has period p.
* (NI) Nivat: every rational transduction is τ(L) = g(h⁻¹(L) ∩ R), g,h morphisms, R regular.
* (PA) Parikh: CFLs have semilinear Parikh images. (GI) Ginsburg: a bounded language over distinct
  letters c₁\*…c_k\* is CF iff its exponent set is a finite union of stratified linear sets.
* (EU) Euler: for a finite directed multigraph with edge multiplicities v, an s→t walk using every
  edge e exactly v_e times exists iff out_v(p) − in_v(p) = [p=s] − [p=t] for all vertices p and
  supp(v) is weakly connected and contains s (or v = 0 and s = t).

**Obstruction principle (LIT, trivial).** If Q is CF then every τ(Q) is CF, hence (PA) Ψ(τ(Q)) is
semilinear, and (GI) every bounded τ(Q) has a stratified exponent set. Theorem B says the first test
never fires.

**Not allowed** (reminder): Q ∩ h⁻¹(Q), complement, intersections of two members — CF is not closed
under them, so they prove nothing.

**Reduction to labelled graphs.** Let P be accepted by an NFA, h : C\* → A\*. Let G be the transition
graph (edges = transitions), λ(p,c,p') := h(c) ∈ A\*. Then Ψ_C(P ∩ h⁻¹(Q)) is a linear image of the
union over (initial s, final t) of Ψ_E(W(s,t) ∩ λ⁻¹(Q)), where W(s,t) is the set of walks s→t written
as edge words and Ψ_E counts edges. With (NI), Ψ(τ(Q)) is a linear image of Ψ(h⁻¹(Q) ∩ R). So Theorem B
follows from:

> **Theorem B′.** G finite directed multigraph, λ : E → A\*, s,t vertices. Then
> Ψ_E(W(s,t) ∩ λ⁻¹(Q)) is semilinear.

Notation: for v ∈ ℕ^E, P_v = {π ∈ W(s,t) : Ψ_E(π) = v}, ℓ(v) = Σ v_e|λ(e)| (= |λ(π)| for π ∈ P_v),
**N = {v : P_v ≠ ∅ and λ(P_v) ∩ Q = ∅}** ("forced non-primitive vectors"). Since
Ψ_E(W ∩ λ⁻¹(Q)) = Ψ_E(W) \ N and Ψ_E(W) is semilinear, Theorem B′ ⇔ **N is semilinear**.

## 2. Lemma W (swap lemma) — PROVED, CHECKED

> **Lemma W.** Let Y,x,y be words with |x| = |y|, x ≠ y and 6|x| ≤ |Yx|. Then Yx ∈ Q or Yy ∈ Q.

*Proof.* Put n = |Yx| ≥ 6. Suppose Yx = sᵐ, Yy = tˡ with m,l ≥ 2. |Y| ≥ 5n/6 ≥ n/2 ≥ |s|,|t|.
If m = l then s = Y[0,|s|) = t, so Yx = Yy, x = y: contradiction. Otherwise wlog m < l, so l ≥ 3,
|s| ≤ n/2, |t| ≤ n/3. Y is a prefix of sᵐ and of tˡ, so it has periods |s|, |t|, and
|s|+|t|−gcd ≤ 5n/6 − 1 < |Y|. By (FW) Y has period g = gcd(|s|,|t|). s = Y[0,|s|) has period g | |s|,
so s = r^{|s|/g} with r = Y[0,g), and Yx = r^{n/g}; likewise Yy = r^{n/g}. So x = y: contradiction. ∎

*Corollary W′.* If X g₁g₂ Z and X g₂g₁ Z have length n ≥ 6|g₁g₂| and g₁g₂ ≠ g₂g₁, at least one is
primitive. (Conjugate to ZX·g₁g₂, ZX·g₂g₁ and use (CJ).)

CHECKED: `swap_lemma_check.py 20` — exhaustive over {a,b}, n ≤ 20: 0 violations. The constant 6 is not
optimal: the largest observed ratio n/|x| with both Yx,Yy non-primitive is 18/7 ≈ 2.57
(Y = a⁵ba⁵, x = aaabaaa, y = baaaaab: Yx = (a⁵ba³)², Yy = (a⁵b)³).

## 3. Lemma OB (one-block equations) — PROVED

> **Lemma OB.** Let y,y' be nonempty primitive words and x,z,x',z' arbitrary. Then
> S = {(m,m') ∈ ℕ² : x yᵐ z = x' y'^{m'} z'} is semilinear.

*Proof.* All points of S lie on the line |xz| + m|y| = |x'z'| + m'|y'|, so for each m at most one m'.
Let C = |x|+|x'|+|z|+|z'| and M\* with M\*|y| ≥ C + 2|y| + 2|y'|. Take (m,m') ∈ S with m ≥ M\*, common
word w of length N. The block yᵐ occupies [|x|, N−|z|), the block y'^{m'} occupies [|x'|, N−|z'|); they
overlap in O = [max(|x|,|x'|), N − max(|z|,|z'|)), |O| ≥ N − C ≥ 2|y|+2|y'| . By (FW) O has period
g = gcd(|y|,|y'|). O contains a conjugate of y (primitive, period g | |y|) so g = |y|; likewise g = |y'|.
So |y| = |y'| =: p, the line is m − m' = κ, and by (OV) the union of the two blocks has period p.
Let o = start of O. Inserting the factor w[o,o+p) at position o turns yᵐ into y^{m+1} and y'^{m'} into
y'^{m'+1} (inserting, at an offset inside a p-periodic block, the p letters that follow that offset
yields the block prolonged by one period; the inserted letters are the same for both sides because both
blocks contain [o,o+p)). So (m+1,m'+1) ∈ S. Deleting w[o,o+p) gives (m−1,m'−1) ∈ S as long as m−1 ≥ M\*
(then the overlap after deletion is still ≥ 2p... in fact |O| ≥ 2p suffices for the deletion to turn
yᵐ into y^{m−1} and y'^{m'} into y'^{m'−1}). Hence S ∩ {m ≥ M\*} is empty or the whole tail
{(m, m−κ) : m ≥ M\*, m−κ ≥ 0}; S ∩ {m < M\*} is finite. ∎

## 4. Lemma I (bounded primitivity lemma) — PROVED; rigid case CHECKED

> **Lemma I.** For all r ≥ 0 and all words x₀,…,x_r, y₁,…,y_r (any alphabet), the set
> E = {e ∈ ℕʳ : W(e) := x₀ y₁^{e₁} x₁ ⋯ y_r^{e_r} x_r ∉ Q} is semilinear (effectively).

*Proof.* Induction on r; r = 0 trivial. Assume the statement for fewer than r parameters.

**(a)** If some yᵢ = ε, E is a cylinder over the set for r−1 parameters.
**(b)** If yᵢ = zᵏ, z primitive, k ≥ 2: E is the preimage of the set for (…, z, …) under e ↦ (…,k eᵢ,…).
So wlog all yᵢ are primitive and nonempty.
**(c)** By (CJ), W(e) ∉ Q iff y₁^{e₁}x₁⋯y_r^{e_r}(x_r x₀) ∉ Q. So wlog x₀ = ε and we regard
(y₁,x₁,…,y_r,x_r) as a cyclic sequence (indices mod r; for r = 1, i+1 = i).

Let Y = max|yᵢ|, X = max|xᵢ|, **c = Y+1**. Say i *merges* if xᵢ y_{i+1}ᶜ is a prefix of yᵢ^ω.

**(d1) Merge identity.** If i merges, then xᵢ = yᵢ^q p with p a proper prefix of yᵢ = ps, y_{i+1} = sp,
and for all e,f ≥ 0: yᵢᵉ xᵢ y_{i+1}ᶠ = yᵢ^{e+q+f} p.
*Proof.* xᵢ is a prefix of yᵢ^ω, so xᵢ = yᵢ^q p. Then y_{i+1}ᶜ is a prefix of z^ω, z := sp (primitive,
|z| = |yᵢ|). y_{i+1}ᶜ has periods |y_{i+1}| and |z| and length ≥ |y_{i+1}| + |z| (as c ≥ 1+|yᵢ|), so by
(FW) period g = gcd. y_{i+1} primitive with period g | |y_{i+1}| ⇒ g = |y_{i+1}|; z is the prefix of
y_{i+1}ᶜ of length |z|, primitive with period g | |z| ⇒ g = |z|. So y_{i+1} = z = sp, and
yᵢᵉ yᵢ^q p (sp)ᶠ = yᵢ^{e+q}(ps)ᶠ p. ∎
**(d2) Left/right symmetry.** i merges ⇔ yᵢᶜ xᵢ is a suffix of the left-infinite word ^ω y_{i+1}.
*Proof.* (⇒) by (d1) yᵢᶜxᵢy_{i+1}ᶜ = yᵢ^{2c+q}p is |yᵢ| = |y_{i+1}|-periodic and ends with y_{i+1}.
(⇐) mirror image of (d1) gives |yᵢ| = |y_{i+1}| and yᵢᶜxᵢy_{i+1}ᶜ is |yᵢ|-periodic and starts with yᵢ. ∎
**(d3)** If some i merges and r ≥ 2: rotate so that the pair (i,i+1) is not split; by (d1)
W(e) = ⋯ yᵢ^{eᵢ+e_{i+1}+q}(p x_{i+1}) ⋯, an (r−1)-parameter word evaluated at an affine image of e. So E is
an affine preimage of a semilinear set. If r = 1 and 1 merges: x₁ = y₁^q p and y₁ = sp = ps; y₁ primitive
and (CM) force p = ε, W(e) = y₁^{e+q}, E = ℕ \ {1−q}.
So wlog **no index merges**.

**(e) Small exponents.** Let A\* = X + cY and **T = 4Y + X + 2A\* + c + 2**. E is the union of the sets
{e ∈ E : eᵢ = t} (i ≤ r, t < T), each semilinear by induction (absorb yᵢᵗ into the constants), and
E^{≥T} := E ∩ [T,∞)ʳ. It remains to treat E^{≥T}.

**(f) Rigid case: no merges, e ∈ [T,∞)ʳ.**

*r = 1.* W = yᵉx with x yᶜ not a prefix of y^ω. If W = tᵐ, m ≥ 2: yᵉ has periods |y|, |t| ≤ |W|/2 and
e|y| ≥ |y| + |t| (as e ≥ T), so by (FW) and primitivity of y, |y| divides |t|, t = y^{|t|/|y|}, W ∈ y\*,
x ∈ y\*, so x yᶜ is a prefix of y^ω: contradiction. Hence E^{≥T} = ∅.

*r ≥ 2.* Let w = W(e), n = |w|, positions in ℤ/n, w⟨u,L⟩ := w[u]⋯w[u+L−1] (L ≤ n) the word on the arc
[u,u+L). s₁ = 0, s_{i+1} = sᵢ + eᵢ|yᵢ| + |xᵢ|, block arc Bᵢ = [sᵢ, sᵢ+eᵢ|yᵢ|).

**F1.** Let bᵢ (resp. aᵢ) be the largest b (resp. a) such that w⟨sᵢ, eᵢ|yᵢ|+b⟩ (resp.
w⟨sᵢ−a, a+eᵢ|yᵢ|⟩) has period |yᵢ|. Then bᵢ = lcp(xᵢy_{i+1}ᶜ, yᵢ^ω) < |xᵢ|+c|y_{i+1}| ≤ A\* and
aᵢ = (longest common suffix of y_{i−1}ᶜx_{i−1} and ^ωyᵢ) < A\*; both are independent of e ∈ [T,∞)ʳ.
(Because e_{i±1} ≥ c, the words yᵢ^{eᵢ}xᵢy_{i+1}ᶜ and y_{i−1}ᶜx_{i−1}yᵢ^{eᵢ} are read on the circle
next to Bᵢ; no merge at i and at i−1, with (d2), gives the strict bounds.)
Put **Rᵢ = [sᵢ−aᵢ, sᵢ+eᵢ|yᵢ|+bᵢ)**, tᵢ = sᵢ − aᵢ. |Rᵢ| ≤ n − 2 (n ≥ eᵢ|yᵢ| + T, aᵢ+bᵢ < 2A\* ≤ T−2).
**(M)** Every arc of length ≤ n−1 with period |yᵢ| that contains Bᵢ is contained in Rᵢ (sub-arcs of
periodic arcs are periodic; maximality of aᵢ, bᵢ).

**F2.** Let J be an arc with |J| ≥ 4Y+X having a period p ≤ Y whose length-p factors are primitive.
Then some sub-arc K ⊆ J ∩ B_j has |K| ≥ 2Y, and |y_j| = p.
*Proof.* Either J contains some B_j (take K ⊆ B_j of length 2Y ≤ T), or J lies inside
(end of B_j) ∪ (gap x_j) ∪ (beginning of B_{j+1}) and then |J∩B_j| + |J∩B_{j+1}| ≥ 4Y, so one of these two
arcs has length ≥ 2Y. On K, w has periods p and |y_j| and |K| ≥ p+|y_j|, so by (FW) period g = gcd.
The first |y_j| letters of K form a conjugate of y_j (primitive, period g | |y_j|) ⇒ g = |y_j|; the
first p letters are primitive by hypothesis ⇒ g = p. ∎

**F3.** Suppose rotation by d, 0 < d < n, fixes w. Then there is s ∈ {1,…,r−1} with tᵢ + d ≡ t_{i+s}
for all i.
*Proof.* Fix i, p = |yᵢ|, J = Rᵢ + d. w⟨J⟩ = w⟨Rᵢ⟩ has period p and its length-p factors are conjugates
of yᵢ, hence primitive; |J| = |Rᵢ| ≥ T ≥ 4Y+X. By F2 get j, K ⊆ J ∩ B_j, |K| ≥ 2Y ≥ p, |y_j| = p. Lift J
and B_j to integer intervals both containing a lift of K; by (OV) the periodic lift of w has period p on
their union Ĵ. If |Ĵ| ≤ n−1 then Ĵ is an arc with period p containing B_j, so Ĵ ⊆ R_j by (M). If |Ĵ| ≥ n,
a sub-interval of Ĵ of length n−1 containing B_j contradicts (M) and |R_j| ≤ n−2. Hence J ⊆ R_j.
Applying the same to the inverse rotation: R_j − d has period p and contains J − d = Rᵢ ⊇ Bᵢ, so by (M)
R_j − d ⊆ Rᵢ. Thus Rᵢ + d = R_j =: R_{π(i)}. The start points satisfy t_{i+1} − tᵢ ≥ T − A\* > 0 and
sum to n, so t₁ < ⋯ < t_r < t₁+n are distinct and in cyclic order; π is injective and the rotation
preserves cyclic order, so π(i) = i+s for a fixed s; s = 0 would give d ≡ 0. ∎

**Conclusion of (f).** Let U′ᵢ(e) := w⟨tᵢ, t_{i+1}−tᵢ⟩, so w⟨t₁,n⟩ = U′₁⋯U′_r. By F3 and (CJ):

> for e ∈ [T,∞)ʳ:  W(e) ∉ Q  ⇔  ∃ s ∈ {1,…,r−1} ∀i : U′ᵢ(e) = U′_{i+s}(e).

(⇐: rotation by t_{1+s}−t₁ ∈ (0,n) fixes w.) Moreover U′ᵢ(e) = αᵢ yᵢ^{eᵢ−c} βᵢ with constant words
αᵢ = suffix of length aᵢ of y_{i−1}ᶜx_{i−1}, βᵢ = yᵢᶜxᵢ minus its last a_{i+1} letters. By Lemma OB each
set {e : U′ᵢ(e) = U′_{i+s}(e)} is semilinear (a condition "eᵢ − e_{i+s} = const" or empty/finite), so
E^{≥T} is a finite union of finite intersections of semilinear sets. ∎

CHECKED (the displayed equivalence): `bounded_rigidity_check.py` seeds 1,2 — 6000 random merge-free
instances (r ≤ 4, |yᵢ| ≤ 3, |xᵢ| ≤ 3), 1.2·10⁶ exponent vectors in [T,T+12]ʳ (half of them biased to be
shift-invariant so that non-primitive cases occur): 0 mismatches against brute-force primitivity.

*Explicit form (useful for the bounded/KK route).* After merging, in the rigid range the non-primitive
exponent vectors are exactly ⋃_s {e : block data (yᵢ, gaps, eᵢ) invariant under the cyclic shift by s};
i.e. finitely many sets of the form {eᵢ − e_{i+s} = δᵢ ∀i}. For (ab\*)ⁿ this is the familiar
"(e₁…e_n) is periodic".

## 5. Proof of Theorem B′ (N is semilinear) — PROVED

Constants: n_V = |V|, Λ = max|λ(e)|, c(G) = number of simple cycles, **K₁ = 4n_V+1**,
**K₂ = 1 + c(G)(K₁−1)**, **B = (|E|K₂+1)(n_V+1)**, **L₀ = 24 n_V Λ**.

**Types.** For v with P_v ≠ ∅ let F(v) = set of simple cycles C with v_e ≥ K₁ for all e ∈ C ("free
cycles"), H(v) = union of their edges, type(v) = (supp v, F(v)). Finitely many types; each type class is
Presburger-definable. Fix a type and write H.
* (T1) every H-edge has v_e ≥ K₁; every simple cycle made of H-edges is free; H is a disjoint union of
  strongly connected pieces (its SCCs), every H-edge lies inside one.
* (T2) e ∉ H ⇒ v_e ≤ K₂. *Proof.* Take π ∈ P_v and delete simple-cycle factors repeatedly:
  v = Ψ(simple path) + Σ_C n_C Ψ(C). If e ∉ H, every simple cycle C ∋ e contains an edge f with v_f < K₁,
  so n_C ≤ K₁−1. ∎

For each SCC K of H fix a base vertex q_K and, inside K, simple paths α_p : q_K → p and β_p : p → q_K
(empty for p = q_K). Let
S_K = {λ(α_p e β_{p'}) : e ∈ E(K), e : p → p'} ∪ {λ(α_p β_p) : p ∈ V(K)}
(labels of closed walks at q_K with ≤ 2n_V − 1 edges). The type is **commuting** if for every K all pairs
of words in S_K commute.

**Step A (non-commuting types).** If type(v) is not commuting and ℓ(v) ≥ L₀ then v ∉ N.
*Proof.* Take closed walks γ₁,γ₂ at q_K in K, ≤ 2n_V−1 edges each, with g₁g₂ ≠ g₂g₁ (gᵢ = λ(γᵢ)).
v′ = v − Ψ(γ₁) − Ψ(γ₂): each H-edge is used < K₁ times by γ₁γ₂, so by (T1) supp v′ = supp v; the
balance conditions are unchanged; by (EU) P_{v′} ≠ ∅. A walk π′ ∈ P_{v′} visits q_K; inserting γ₁γ₂,
resp. γ₂γ₁, at that visit gives two walks in P_v with labels Xg₁g₂Z, Xg₂g₁Z of length
ℓ(v) ≥ L₀ ≥ 6|g₁g₂|. By Corollary W′ one is primitive. ∎

**Step B (commuting types).**

*B1 (coherence).* For each SCC K either all edges of K have empty label ("silent"), or there are a
primitive word ρ_K and conjugates ρ_p of ρ_K (p ∈ V(K)) such that every closed walk in K based at p has
label in ρ_p\*.
*Proof.* For a closed walk e₁⋯e_k at q = q_K through p₀ = q, p₁,…,p_k = q, in the free group on A:
λ(e₁⋯e_k) = ω₁θ₁⁻¹ω₂θ₂⁻¹⋯θ_{k−1}⁻¹ω_k, with ω_j = λ(α_{p_{j−1}} e_j β_{p_j}) ∈ S_K,
θ_j = λ(α_{p_j}β_{p_j}) ∈ S_K (telescoping). If S_K = {ε}, all edge labels are ε. Otherwise pick
s₀ ∈ S_K \ {ε} with primitive root ρ; by (CM) S_K ⊆ ρ\*; so λ(e₁⋯e_k) ∈ ⟨ρ⟩ ∩ A\* = ρ\*.
For p ∈ V(K) put u = λ(α_p), u′ = λ(β_p); uu′ = ρⁱ, so u = ρᵃx with ρ = xy, x a proper prefix; put
ρ_p = yx. For a closed walk γ at p, uλ(γ)u′ = ρʲ; cancelling ρᵃ on the left and comparing with
xu′ = ρ^{i−a} gives xλ(γ)y = (xy)^{j−i+1}, i.e. λ(γ) = (yx)^{j−i} (and λ(γ) = ρ^{j−i} if x = ε). ∎

*B2 (normal form of P_v).* Let Cl(q) be the set of closed walks at q all of whose edges are in H
(Cl(q) = {empty walk} if q ∉ V(H)). For a walk σ = f₁⋯f_k ∈ W(s,t) through q₀,…,q_k and γ_j ∈ Cl(q_j)
put σ⊕γ = γ₀f₁γ₁⋯f_kγ_k. Then for v of the fixed type

> P_v = {σ⊕γ : σ ∈ W(s,t), |σ| ≤ B, γ_j ∈ Cl(q_j), Ψ(σ)+Σ_jΨ(γ_j) = v}.

*Proof.* ⊇ is clear. ⊆: from π ∈ P_v delete, as long as possible, a factor that is a simple cycle of
H-edges; let σ be the result. Undoing the deletions inserts closed H-walks either between two edges of σ
or inside previously inserted material, so π = σ⊕γ with γ_j ∈ Cl(q_j). σ has no factor that is a simple
H-cycle, so every factor of σ made of H-edges has < n_V edges; σ has ≤ |E|K₂ non-H edges by (T2). Hence
|σ| ≤ B. ∎

*B3 (labels).* By B1, λ(γ_j) = ρ_{q_j}^{e_j} with e_j = ℓ(Ψ(γ_j))/|ρ_K| (K the SCC of q_j; put ρ_{q_j} = ε,
e_j = 0 if K is silent or q_j ∉ V(H)). So
λ(σ⊕γ) = W_σ(e) := ρ_{q₀}^{e₀} λ(f₁) ρ_{q₁}^{e₁} ⋯ λ(f_k) ρ_{q_k}^{e_k},
which depends only on σ and on the vectors w_j = Ψ(γ_j). By Lemma I, E_σ = {e : W_σ(e) ∉ Q} is semilinear.

*B4 (Presburger definition).* For v of the fixed commuting type:
v ∈ N ⇔ v ∈ Ψ(W(s,t)) ∧ ⋀_{σ ∈ W(s,t), |σ| ≤ B} ∀w₀,…,w_{|σ|} :
 [ ⋀_j w_j ∈ Ψ(Cl(q_j)) ∧ Ψ(σ)+Σ_j w_j = v ] → (ℓ(w_j)/|ρ_{q_j}|)_j ∈ E_σ.
Ψ(Cl(q)) is semilinear (PA for regular languages), E_σ is semilinear, the conjunction is finite. So
N ∩ (type class) is Presburger-definable, hence semilinear. ∎

**Step C (short labels).** {v ∈ N : ℓ(v) < L₀} = {v ∈ Ψ(W) : ℓ(v) < L₀} \ Ψ(W ∩ λ⁻¹(Q ∩ A^{<L₀})),
semilinear because Q ∩ A^{<L₀} is finite.

**Assembly.** N = (Step C set) ∪ ⋃_{commuting types} (N ∩ type class ∩ {ℓ ≥ L₀}); by Step A the
non-commuting types contribute nothing with ℓ ≥ L₀. N is semilinear. ∎ (Theorem B′, hence Theorem B.)

All steps are effective, so a semilinear representation of Ψ(τ(Q)) is computable from τ.

Illustration (CHECKED, `transducer_images.py`): for small random and hand-made transducers the set N,
computed exactly for outputs of length ≤ 7–9, is a finite set plus lines, e.g. N = {i=j=k} for
aⁱbaʲbaᵏb ↦ cⁱdʲeᵏ, N = {(n,n) : n ≥ 2} ∪ {(0,0)} for one random 3-state transducer.

## 6. Corollaries and extensions

**C1 (PROVED).** Every language in the full trio M(Q) = {τ(Q)} has a semilinear Parikh image. Every unary
language in M(Q) is regular. Every L ∈ M(Q), L ⊆ c₁\*⋯c_k\* (distinct letters), has a semilinear exponent set.

**C2 (PROVED). M(Q) is closed under union, reversal and Cyc.** Union: τ₁ ∪ τ₂ is rational. Reversal:
Qᴿ = Q. Cyc: let L = g(h⁻¹(Q) ∩ R). A word of Cyc(L) is vu with uv = g(x), x = x₁cx₂, g(c) = c′c″,
u = g(x₁)c′, v = c″g(x₂). Add letters L_{c,c′,c″}, R_{c,c′,c″}; R̃ = {L_{c,c′,c″} x₂ x₁ R_{c,c′,c″} : x₁cx₂ ∈ R}
is regular; put h̃(L_…) = h(c), h̃(R_…) = ε, g̃(L_…) = c″, g̃(R_…) = c′. Then h̃(L x₂x₁R) = h(c)h(x₂)h(x₁)
is a conjugate of h(x), so by (CJ) Cyc(L) = g̃(h̃⁻¹(Q) ∩ R̃) ∈ M(Q). ∎

### Theorem C (complete Parikh barrier) — PROVED

> Let 𝒯 = {L : Ψ(τ(L)) is semilinear for every rational transduction τ}. Then
> (i) Q ∈ 𝒯 and CFL ⊆ 𝒯;
> (ii) 𝒯 is closed under rational transductions, union, substitution (σ(L) with L ∈ 𝒯 and all σ(b) ∈ 𝒯),
> hence concatenation and Kleene star, and under reversal and Cyc.
> Consequently every language obtained from Q and CFLs by these operations has a semilinear Parikh
> image; every unary such language is regular.

*Proof.* (i) Theorem B; (PA) + closure of CFL under rational transductions.
Rational transductions: composition of rational transductions is rational. Union: τ(L₁∪L₂) = τ(L₁)∪τ(L₂).
*Substitution.* Let τ′ be a transducer with state set S, initial states I, final states F, and
τ′_{p,p′}(u) the set of outputs of runs p → p′ reading u. A run on u₁⋯u_m (uᵢ ∈ σ(bᵢ)) splits at the
block boundaries, so
 τ′(σ(L)) = σ′(τ″(L)),
where τ″(b₁⋯b_m) = {[b₁,p₀,p₁]⋯[b_m,p_{m−1},p_m][$,p_m,p_{m+1}] : p₀ ∈ I, p_{m+1} ∈ F} (rational) and
σ′([b,p,p′]) = τ′_{p,p′}(σ(b)), σ′([$,p,p′]) = τ′_{p,p′}({ε}). Ψ(τ″(L)) is semilinear (L ∈ 𝒯) and each
Ψ(σ′(c)) is semilinear (σ(b) ∈ 𝒯). Ψ(σ′(L″)) depends only on Ψ(L″) and the sets Ψ(σ′(c)); replacing L″
and the σ′(c) by regular languages with the same Parikh images (LIT: every semilinear set is the Parikh
image of a regular language) gives a regular language with the same Parikh image. So Ψ(τ′(σ(L))) is
semilinear, i.e. σ(L) ∈ 𝒯.
*Concatenation, star.* L₁L₂ = σ({b₁b₂}), L\* = σ(b\*).
*Reversal.* Ψ(τ(Lᴿ)) = Ψ(τᴿ(L)) with τᴿ = rev∘τ∘rev rational.
*Cyc.* Ψ(τ(Cyc L)) = Ψ(τ̂(L)) where τ̂, on input uv, guesses a state p₁ and the cut, runs τ from p₁ to a
final state on u (output o_u), then runs τ from an initial state on v, checks that it ends in p₁ (output
o_v), and outputs o_u o_v; this is rational and o_u o_v has the Parikh vector of o_v o_u ∈ τ(vu). ∎

(The closure part (ii) is in the spirit of Ginsburg–Spanier, "AFL with the semilinear property", 1971;
the new input is Q ∈ 𝒯.) Examples covered: τ(Q#Q#⋯#Q), τ((Q#)\*), the full AFL generated by Q, its
substitution closure with CFLs, Cyc of any of these followed by further transductions.

**C5 (PROVED). Non-obtainability.** None of {aⁿbᵐ : gcd(n,m) = 1}, {aᵖ : p prime}, {aⁿ : n squarefree},
{a^{n²}}, {aⁿb^{n²}} can be obtained from Q and CFLs by the operations of Theorem C; in particular none
is a rational image of Q, of Q ∩ R, or of h⁻¹(Q) ∩ R. (Answers items (1) and (3) of the brief negatively.)

### Lemma RC and Proposition P (pumping barrier) — PROVED

**Lemma RC′ (dichotomy).** For words X,Y,Z with Y ≠ ε there is k₀ such that either XYᵏZ ∈ Q for all
k ≥ k₀, or there is a primitive ρ, |ρ| ≤ |Y|, with XYʲZ ∈ ρ⁺ for all j ≥ 0 (XZ ≠ ε or j ≥ 1).
*Proof.* Let k₀|Y| ≥ 2|Y| + |XZ|. Suppose XYᵏZ = uᵐ, m ≥ 2, for some k ≥ k₀. Yᵏ has periods |Y| and |u|
and k|Y| ≥ |Y| + |u|; with ρ₀ the primitive root of Y, (FW) gives |ρ₀| | |u|; uᵐ contains the factor Yᵏ
of length ≥ |u|, so a conjugate of u is a power of a conjugate of ρ₀, and XYᵏZ = ρᴹ for a conjugate ρ of
ρ₀. Inserting or deleting copies of Y (length a multiple of |ρ|) inside the block Yᵏ of a |ρ|-periodic
word whose length is a multiple of |ρ| leaves a power of ρ. ∎

**Lemma RC (probably known, cf. Ito–Katsura–Shyr–Yu).** If L ⊆ co-Q is accepted by a DFA with s states,
then L ⊆ A^{<s} ∪ ⋃{ρ⁺ : ρ primitive, |ρ| ≤ s}. (Pump w = xyz, |xy| ≤ s, and apply RC′.)

**Proposition P.** Every infinite L ∈ M(Q) contains a set {u vᵏ w : k ≥ k₀} with v ≠ ε.
*Proof.* L = out(valid walks) for a graph with input labels λ and output labels out, a walk being valid
if its λ-label is primitive. L infinite ⇒ there is a valid walk π with ≥ 2(n_V+1) edges carrying
nonempty output; by pigeonhole π = x y₁ z′ y₂ z″ with y₁,y₂ closed walks, out(yᵢ) ≠ ε. If λ(yᵢ) = ε for
some i, pumping yᵢ keeps the label: L ⊇ out(·)out(yᵢ)ᵏout(·), k ≥ 0. Otherwise apply RC′ to y₁ with
X = λ(x), Y = λ(y₁), Z = λ(z′y₂z″) ≠ ε: in the second alternative λ(π) ∈ ρ⁺ ∩ Q = {ρ}, so
|XYZ| = |ρ| ≤ |Y|, contradicting Z ≠ ε. Hence XYᵏZ ∈ Q for all k ≥ k₀ and
L ⊇ out(x)out(y₁)ᵏout(z′y₂z″), k ≥ k₀. ∎

**Corollary P′ (PROVED).** {aⁿbⁿ : n ≥ 0} ∉ M(Q) and {aⁿbⁿcⁿ} ∉ M(Q) (they are infinite and contain no
u v^{≥k₀} w with v ≠ ε). So M(Q) ⊉ CFL: if Q is context-free, it is a *non-generator* of the CFL family;
and Q-images cannot force an equality between two unbounded counters.

**Q·Q (CHECKED, `qq_check.py`, n ≤ 16).** {a,b}^{≥2} \ Q·Q = {aⁿ, bⁿ : n ≥ 3}; so Q·Q is regular and
products of Q with itself carry no information.

## 7. Answers to the four questions of the brief, and what is left

1. *Simple rational images of Q.* M(Q) contains all regular languages, {aⁱbʲ : i ≠ j},
   {aⁱbʲcᵏ : not i=j=k}, all Kászonyi–Katsura languages Q ∩ (ab\*)ⁿ, and by C2 is closed under Cyc.
   It contains no language with non-semilinear Parikh image (C5) and not {aⁿbⁿ} (P′). Structural reason
   (from §5): a vector can be "forced non-primitive" only if the input is rigid (labels of all free
   cycles commute), and then non-primitivity is a *finite union of systems of equalities* between block
   exponents (§4, explicit form). Q-images therefore only ever express **negations of conjunctions of
   linear equalities**, universally quantified over the residual freedom of the transducer.
2. *Combinations.* Union, concatenation, star, substitution, reversal, Cyc do not help for Parikh
   (Theorem C). Q ∩ h⁻¹(Q) and similar are not legitimate.
3. *Arithmetic encodings.* Impossible (Theorems B, C; C5).
4. *Barrier.* Theorem B, Theorem C, Proposition P.

**Remaining viable closure-type obstruction.** By (GI), Q is non-CF as soon as one *bounded* L ∈ M(Q)
has a non-stratifiable exponent set. By §4–§5 these exponent sets are complements (inside a semilinear
set) of sets of the form {v : ∀ residual choices, some cyclic shift s leaves the block data invariant}.
For (ab\*)ⁿ this is exactly the Kászonyi–Katsura question (CF for n with ≤ 2 prime factors, per the
scout). Combined with the scout's reduction (Q CF ⇔ ⋃ₙ Q ∩ (ab\*)ⁿ CF) the picture is: Parikh-type
arguments are dead in the whole closure of Q under CF-preserving operations; bounded-type arguments
reduce to stratification questions of KK type; anything else must use the *unbounded* structure
(Ogden/interchange/rectangle arguments on members of M(Q)).

**Honest limitations.** The proofs in §§2–6 are written in full but have been checked only by me plus
the scripts for Lemma W (exhaustive, n ≤ 20) and the rigid case of Lemma I (random). Nothing here proves
or disproves the conjecture.
