# Results index

Every proved result, lemma, conjecture, working method and failed method in this repository, with the file that holds it. Q = primitive words over {a,b}. "CF" = context-free.

**Status labels**
- **Lean** — machine-checked in Lean.
- **Audited** — written proof, re-checked by an independent audit agent (audit file named).
- **Proved** — written proof, not independently audited.
- **Computer** — finite computation only; evidence, not proof.
- **Known** — already in the published literature.
- **False / Flawed** — refuted, or the proof has a confirmed gap.
- **Open** — stated but unresolved.
